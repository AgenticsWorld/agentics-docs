# 生成参考图

手头没有能说明意图的图片时，就生成一张。[参考文件](/zh/videoagents/world/reference-files)页上的 **✨ 生成** 按钮，用你为这个页面选的图像模型，按提示词出图。你先看结果，合适了才加入参考。

## 开始之前 {#before-you-start}
- 在 **🎨 生成模型** 页配置好一个图像模型。见[图像模型](/zh/videoagents/models/image-models)。
- ✨ **生成** 出现在图片类板块：视觉风格、封面、角色、场景、生物、道具和其他。

::: warning 注意
每生成一次，就付费调用一次你选的图像模型。
:::

## 为这个页面选图像模型 {#pick-the-image-model-for-this-page}

参考文件页顶部的 **🎨 图像模型** 决定 ✨ **生成** 使用的渠道和模型。

- **跟随全局（…）** 使用生成模型页上的图像设置，这是默认值。
- 选一个渠道和模型，只给参考图换用别的模型。这个选择只保存在本页，不改变全局设置，也不影响其他预览页。
- 没有 Key 的渠道显示为「（未配置）」，不能选。

## 生成图片 {#generate-an-image}

1. 在图片要放的板块上点 **✨ 生成**。**✨ 生成图片** 窗口打开，标题里带着板块名。
2. 在 **提示词** 里描述画面，例如「商代青铜鼎特写，正面平视，浅灰背景」。
3. 可以点 **🎨 风格库**，再点一种风格。它的提示词会加进提示词框（见下文）。
4. 选择 **画幅**：16:9、9:16、1:1、4:3 或 3:4。选择会记在浏览器里。
5. 点 **生成**，或按 Ctrl+Enter（Mac 上是 ⌘+Enter）。状态行显示渠道、模型和已用秒数。
6. 图片出来后，点它可以看大图。然后：
   - **加入「*板块名*」** 把它复制进板块。按钮变成 **✓ 已加入**。
   - **重新生成** 丢掉这张图，按当前提示词重新出一张。

![视觉风格板块的生成图片窗口：提示词描述阳光下的维多利亚时代河岸，有风格库按钮、设为 16:9 的画幅菜单和生成按钮](/images/videoagents/world/generate-reference-images-dialog.webp)

出图过程中可以关掉窗口，生成会继续。在同一页面再次打开 ✨ **生成** 就能看到结果。

## 使用风格库里的风格 {#use-a-style-from-the-style-library}

**🎨 风格库** 打开的风格库，和项目[美术风格](/zh/videoagents/world/art-style)选择器、[画板](/zh/videoagents/world/image-canvas)用的是同一个。可以按 **真人**、**3D** 或 **2D** 筛选，也可以按名称搜索。

![生成图片窗口里的风格库：一格格真人和 3D 风格卡片，带分类标签和搜索框](/images/videoagents/world/generate-reference-images-styles.webp)

- 点一种风格，它的提示词会加到你的提示词末尾，并显示一个带风格名的 🎨 标签。
- 再点另一种风格，会替换掉前一种。
- 点标签上的 **✕**，去掉这个风格的提示词。

在这里选风格只影响这张图，不会改变项目的美术风格。

## 保存了什么 {#what-gets-saved}

- 点 **加入** 之前，`refs/` 里什么都不会多。图片暂存在 `assets/refs_gen/`，一天后删除。**重新生成** 会立即删除上一张。
- 加入后，图片复制到 `refs/<section>/gen_<job>.<ext>`。扩展名按图片的实际格式，因为很多渠道返回的是 JPEG。
- 提示词、渠道、模型、画幅和风格保存在 `refs/annotations.json`。卡片显示 **✨ AI 生成** 以及渠道和模型；鼠标悬停在这一行上可以看到提示词。
- 像其他参考一样，给新文件写一条 **✏️ 注释**，让 Agent 知道它做什么用。

## 常见问题 {#troubleshooting}

**「这次生成的记录已经不在了（服务重启过？），请重新生成」**
生成任务保存在内存里。服务重启后，重新生成这张图。

**「生成失败：…」**
这条消息来自图像渠道。在生成模型页检查模型和 Key，或在页面顶部换一个模型。

**出图很久都没有结果。**
超过 35 分钟还没有出图，任务会放弃并给出提示。
