# 参考文件

**🖼 参考文件** 页用来告诉团队成片应该是什么样子、什么声音。上传图片、音乐、参考视频、字体和文档，给每个文件写一条简短注释。视觉和配乐 Agent 开工前会先查看这些文件，并按你的注释执行。

这个页面上的所有内容都放在项目的 `refs/` 文件夹里。

## 打开页面 {#open-the-page}

打开 **预览设定产物** 菜单（控制台顶栏的图片图标），选择 **🖼 参考文件**。新项目初始化后，总制片也会引导你来这里，并等你确认参考已备好、或说明要跳过。

![参考文件页：视觉风格板块里有一张图，下面是封面、角色和场景板块](/images/videoagents/world/reference-files.webp)

## 板块 {#sections}

每个板块对应 `refs/` 下的一个子文件夹。板块标题栏显示文件夹名、文件数和一句说明。

| 板块 | 文件夹 | 放什么 |
| --- | --- | --- |
| 🎨 **视觉风格** | `style/` | 整体画风、渲染质感、色调和构图参考 |
| 🖼 **封面** | `thumbnail/` | 你喜欢的封面：构图、版式和文字风格 |
| 👤 **角色** | `characters/` | 角色形象。在注释里写明是哪个角色（角色名或 ID） |
| 🏔 **场景** | `scenes/` | 建筑、地貌和氛围 |
| 🐎 **生物** | `creatures/` | 生物、坐骑和异兽。在注释里写明是哪一个 |
| 🗡 **道具** | `props/` | 道具、法宝和服装。在注释里写明是哪件道具或服装 |
| 🧊 **3D 模型** | `models3d/` | GLB 模型（v1.0.45 之后新增）；见 [3D 模型](/zh/videoagents/world/3d-models) |
| 🎵 **音频** | `music/` | 希望使用的音乐；配乐 Agent 优先从这里选 |
| 🎞 **视频** | `video/` | 参考视频：动作、运镜、节奏和转场 |
| 🔤 **字体** | `fonts/` | 字体（`.ttf`、`.otf`、`.ttc`），用于花字、封面、片头片尾和字幕 |
| 📝 **文本** | `text/` | 设定资料、文案等需要 Agent 阅读的文字 |
| 📎 **其他** | `other/` | 其他任意格式（PDF、表格、压缩包）。请加一条注释说明用途 |
| 📂 **根目录散图** | `refs/` | 直接散放在 `refs/` 文件夹里的文件，一律视为整体风格参考 |

另有两个板块只在用到它们的项目类型里出现：**🎙 讲述音频**（影视剧以外的所有项目类型）和 **🗣 克隆声音**（数字人项目）。在这些项目里，它们排在最前面。在用不到它们的项目里，只有已经有文件时才会显示。

## 添加文件 {#add-files}

往板块里添加文件有几种方式：

- **📤 上传** 打开文件选择框，可以一次选多个文件。
- **拖拽** 文件到板块上。
- **✨ 生成** 用 AI 生成一张图。见[生成参考图](/zh/videoagents/world/generate-reference-images)。
- **🔎 图库** 搜索免费图库。见[图库搜图](/zh/videoagents/world/stock-images)。
- **🎞 素材库** 从你的[素材库](/zh/videoagents/project-types/footage-library)视频里截一帧：选一个素材项目，播放或逐帧找到需要的画面（◀ **上一帧** / **下一帧** ▶，或按 `,` 和 `.` 键），点 **📸 截图加入参考文件**。这一帧从原片截取，保持原片分辨率。

✨ **生成**、🔎 **图库** 和 🎞 **素材库** 只出现在图片类板块：视觉风格、封面、角色、场景、生物、道具和其他。

需要知道的：

- 单个文件最大 100 MB。
- 有些板块只收特定文件：**字体** 收 `.ttf`、`.otf` 和 `.ttc`；**3D 模型** 收 `.glb`；讲述音频和克隆声音板块收 `.mp3`、`.wav`、`.flac`、`.m4a`、`.aac` 和 `.ogg`。
- 文件名会改成只含字母、数字、`.`、`-` 和 `_`。如果已有同名文件，会加上 `_1`、`_2`……
- 文件直接放进板块的文件夹，不按角色或道具分子文件夹：靠注释说明文件属于哪一个。

## 给每个文件写注释 {#write-a-note-for-each-file}

注释用来告诉 Agent 这个文件做什么用，例如「主角青年时期的发型以这张为准」或「这首曲子想用在决战段」。

1. 点文件下方的 **✏️ 注释**。
2. 写好注释，点 **保存**。

![正在编辑注释的参考图卡片，下方有取消和保存按钮](/images/videoagents/world/reference-files-note.webp)

注释保存在 `refs/annotations.json`，同时写进 `refs/NOTES.md` 里一个带标记的区块，Agent 必须读这个文件。你也可以自己在 `NOTES.md` 里写内容，只要写在标记区块之外，页面不会动那部分。

## 文件的其他操作 {#other-actions-on-a-file}

| 按钮 | 作用 |
| --- | --- |
| 点图片 | 放大显示。再点一次关闭 |
| **🖌 画板** | 在[画板](/zh/videoagents/world/image-canvas)里打开 PNG、JPG 或 WebP 图片进行编辑 |
| **⧉** | 复制文件在项目中的路径，例如 `refs/style/alice.jpeg`，方便粘贴到对话里 |
| **🗑** | 删除文件及其注释 |

::: warning 注意
删除参考文件后无法恢复。
:::

音频文件的卡片上有播放器，视频可以直接播放，字体会用该字体显示一段示例文字，3D 模型显示一张静态图，点击后可以旋转查看。从图库添加、用 AI 生成或从素材库截取的文件，会在文件名下方注明来源。

## Agent 怎么使用你的参考 {#how-the-agents-use-your-references}

- **你的参考优先。** 风格决定（画风、色调、渲染）和参考图冲突时，以参考图为准。参考图和[世界圣经](/zh/videoagents/world/world-bible)里的文字设定冲突时，Agent 会报告给你，不会自己选。
- **谁读哪些文件。** 美术总监读 `style/` 和根目录文件；角色、服装、生物、道具和场景设计 Agent 读各自的板块，并根据你的注释找到对应文件；配乐 Agent 试听 `music/`，决定每首曲子用在哪里；视频 Agent 查看 `video/`；封面和片头片尾工作使用 `thumbnail/` 和 `fonts/`。
- **其他和 3D 文件按需使用。** **其他** 和 **3D 模型** 里的文件，只有在注释指明与当前任务有关、或总制片在工单里点名时才会被读取。
- **会留下记录。** 基于参考完成的产物会记下用了哪些文件（`user_refs`）。美术总监会在[美术风格](/zh/videoagents/world/art-style)里写明哪张参考图影响了哪项决定。
- **不放也可以。** 没有参考时，Agent 会自行设计。在美术风格锁定签字点（H2），美术总监会提醒你仍可以补充参考并重做风格。

## 常见问题 {#common-questions}

**工作开始后我才加了参考，会被用上吗？**
新的工作开始时会读 `refs/`。已经完成的工作不会自动重做：在控制台对话里请总制片处理，或在预览页用 **✏️ 修改**，重做应该参照新参考的部分。

**我有旧的子文件夹，例如 `refs/characters/<name>/`。**
仍然有效。已有子文件夹里的文件按文件夹名匹配。
