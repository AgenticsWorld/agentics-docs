# 3D 场景

3D 场景是一个场景的简单米制模型，用方块、球体和圆柱体铺在俯视图上搭成。这个场景里的每个镜头组都在同一个 3D 场景里调度，所以人物、摄像机、全景图和分镜背景图共用一个一致的空间。

界面里把 3D 场景叫作 **3D 白模**，开启它的项目选项是 **白模**。

## 开始之前 {#before-you-start}
- **必须开启白模。** 检查 **🎛️ → 输出设置 → 白模**。在新建项目向导里，它跟随模型限制那一步：选 Seedance 2.5 预设时勾选（生效视频模型是 Seedance 2.5 时默认就是这个预设），选其他预设时不勾。两种情况你都可以手动改。
- 关闭白模时没有 3D 场景，场景改为出正向和反向场景图（见[分镜背景图](/zh/videoagents/create/background-plates#projects-with-whitebox-off-scene-plates)）。
- 场景要先有俯视图才能建模（见[场景和俯视图](/zh/videoagents/world/scenes)）。

## 3D 场景是怎样做出来的 {#how-a-3d-set-is-made}

1. 每一集开始时，**场景概念** Agent 为这一集用到的每个新场景画俯视图。
2. 然后 **场景建模** Agent 把每张新俯视图变成 3D 场景，保存为 `bible/scenes/<SCN-ID>/whitebox.json`。一个 3D 场景包括：
   - 以米为单位的整体尺寸（宽 × 高 × 深）；
   - 墙、门窗洞口、家具、树木和地形等物体，每个都是方块、球体或圆柱体；
   - 一段说明尺寸是怎样定出来的文字。
3. 墙、门和窗按平面图测量。平面图上没有的墙不会加，即使描述里提到了。
4. 原文没有给出真实尺寸时，Agent 用已知大小的东西（例如门、桌子或人）定比例，并把尺寸标为推断值。
5. 布局检查会把 3D 场景和平面图对比，保存 `whitebox_overlay.png`：平面图上叠加 1 m 网格，墙用红线勾出，家具占地用蓝色，地标是黄点。它出现在场景的 **🖼 场景图** 图库里，紧挨着 `layout_top.png`。

每个场景只建模一次，在第一个需要它的集里完成，之后各集复用。人物不属于场景模型：它们在 [3D 白模预演](/zh/videoagents/create/whitebox-previs)时按镜头组加入。

## 查看 3D 场景 {#look-at-a-3d-set}

1. 打开 **🏔 场景预览**，选一个场景。有 3D 场景的场景在列表里显示 **🧊**。
2. **3D 白模** 面板就在图片图库下方。

![茶桌场景的 3D 白模面板，旋转视角：1 m 网格上的房子、树、长桌和椅子](/images/videoagents/world/3d-sets-orbit.webp)

视图上方一行显示尺寸（宽 × 深、高）、1 m 网格、画幅，以及尺寸是 **推断尺寸** 还是 **已标定尺寸**。

在右上角的菜单里选择查看方式：

| 视图 | 看到什么 |
| --- | --- |
| **旋转视角** | 可以在场景里自由飞行的摄像机（默认） |
| **俯视图** | 从正上方看场景 |
| **实景图** | 俯视图平铺在地面上，灰色几何体隐藏。用它检查 3D 场景是否与平面图一致、背景图朝向是否正确。 |

![同一个面板的实景图视图：俯视图平铺在场景地面上](/images/videoagents/world/3d-sets-real-view.webp)

旋转视角里的移动方式：

| 动作 | 操作 |
| --- | --- |
| 环视（原地转头） | 拖动 |
| 沿视线方向前进 | 滚轮 |
| 前进 / 后退 | 先点一下画面，再按 W / S |
| 左 / 右 | A / D |
| 上升 / 下降 | Q / E |
| 加速 | 按住 Shift |

面板里还有：

- **状态** 显示场景模型文件是否存在：**已有**、**未生成** 或 **未知**。如果提示文件状态未知，重启服务后刷新页面。
- **建模依据与检查**（点击展开）显示 Agent 关于尺寸怎样定出的说明，以及检查 3D 场景时发现的警告。

## 按当前视角创建全景图 {#create-a-panorama-from-the-current-view}

面板标题栏里的 **➕ 创建全景图** 会在旋转视角摄像机当前所在的位置拍一张 360° 全景图：

1. 切换到 **旋转视角**，飞到要拍的位置，面向你希望放在全景图中央的方向。
2. 点 **➕ 创建全景图**。确认框列出位置（x、y、z）、朝向（yaw）和光照方案。
3. 确认。进度显示在下方的 **🌐 全景图** 面板里。完成后页面重新加载，3D 视图回到同一个位置。

摄像机必须在 3D 场景的地面范围之内（离边缘至少 0.5 m），并且在地面以上。每张全景图消耗一次图像生成。见 [360° 全景图](/zh/videoagents/world/panoramas)。

## 修改 3D 场景 {#change-a-3d-set}

在控制台里给 **场景建模** Agent（在 **05-场景资产** 分组里）或 **总制片** 发消息。写明场景并说明哪里不对，例如「SCN-mad-tea-party：桌子应该长 6 m，并且与房子平行」。修改 3D 场景后，Agent 会重新渲染已经在里面调度过的镜头组的白模视频。

::: warning 注意
如果在你签了白模确认（H3W）之后 3D 场景发生变化，受影响的镜头组需要重新检查并签字，它们的分镜背景图也要重做。重做背景图会消耗图像生成。
:::

## 几点说明 {#good-to-know}
- **坐标。** 1 个单位是 1 米。Y 轴朝上，X 轴指向平面图右侧，Z 轴指向平面图下方。原点是场景中心，平面图上方是北。全景图的位置使用同一套数字。
- **地面与平面图一致。** 3D 场景的宽和深与俯视图的比例相同（16:9 的平面图对应 深 = 宽 × 9/16），因为平面图覆盖整个地面。
- **开放空间。** 竖井、悬崖边或半空中的位置，可以不建地面、不显示网格。
- **一个场景一个 3D 场景。** 如果一个地点有两种无法共用一张俯视图的形态，会拆成两个场景。
- **不产生生成费用。** 3D 场景在你的浏览器里绘制，在你的电脑上渲染。
- **和 3D 模型不是一回事。** 角色或道具的 GLB 模型放在参考文件里。见 [3D 模型](/zh/videoagents/world/3d-models)。
