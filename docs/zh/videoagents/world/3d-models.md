# 3D 模型

[参考文件](/zh/videoagents/world/reference-files)页的 **🧊 3D 模型** 板块存放角色、生物和道具的 GLB 模型。你可以在查看器里旋转模型，也可以用一张或多张参考图生成模型。Agent 把模型当作各个角度形体和比例的参照。

::: tip 提示
v1.0.45 之后新增。如果看不到，请更新 VideoAgents。
:::

![参考文件页的 3D 模型板块：显示 models3d/ 文件夹、说明文字，以及生成和上传按钮](/images/videoagents/world/3d-models-section.webp)

## 开始之前 {#before-you-start}
- 上传只需要一个 `.glb` 文件（二进制 glTF 2.0）。
- 要生成模型，先在 **🎨 生成模型 → 🧊 3D 模型** 里配置至少一个 3D 服务商。见 [3D 模型服务商](/zh/videoagents/models/3d-model-providers)。

## 上传模型 {#upload-a-model}

1. 在参考文件页滚动到 **🧊 3D 模型**，点 **📤 上传**，或把文件拖到这个板块上。
2. 写一条 **✏️ 注释**，说明模型对应哪个角色、生物或道具。

只接受 `.glb` 文件，服务端会检查文件确实是二进制 glTF 2.0。`.gltf` 文件通常还需要单独的 `.bin` 和贴图文件，所以不接受。

## 查看模型 {#look-at-a-model}

每张卡片显示模型的一张静态图。点卡片打开查看器：

- 拖动旋转，滚轮缩放，右键拖动平移，双击重置视角。
- **自动旋转**、**线框**、**灰模**（去掉贴图只看形体）、**地面网格** 和 **重置视角** 切换显示选项。
- **下载** 保存文件。底部一行显示三角面数、贴图数和文件大小。

Draco 和 meshopt 压缩的 GLB 可以预览；KTX2 贴图不行。没有材质的模型（例如不带纹理的生成结果）以哑光灰色显示。

## 用参考图生成模型 {#generate-a-model-from-reference-images}

1. 在 **🧊 3D 模型** 板块点 **✨ 生成**，打开 **生成 3D 模型** 窗口。
2. 填好 **参考图** 的各个格子：
   - **正面** 必填。**左侧**、**背面** 和 **右侧** 选填。
   - 填格子的方式：点格子上传图片，把图片拖到格子上，或点 **🖼** 从参考文件页已有的图片里选一张。
3. 在 **3D 模型** 里选一个模型。菜单按服务商分组（Tripo、Fal、RH、本地 Hunyuan3D）。没有 Key 的服务商是灰色的，能收多个视角的模型标有 **多视图**。默认是生成模型页上的生效渠道；上次的选择会记在浏览器里。
4. 要带纹理的模型就保持勾选 **生成纹理**，取消勾选则只出不带纹理的白模。云端服务商默认勾选；本地 Hunyuan3D 服务按生成模型页的设置。
5. 点 **生成**。生成通常需要 1–5 分钟。可以关掉窗口，任务会继续。
6. 结果在窗口内的查看器里打开。点 **加入「3D 模型」** 保留它，或点 **重新生成** 丢掉它再试一次。

![生成 3D 模型窗口：正面格子已从参考文件填入图片，左侧、背面和右侧格子为空，3D 模型菜单选的是 Hunyuan 3D 3.1 Pro（多视图），下方是生成纹理复选框](/images/videoagents/world/3d-models-generate.webp)

::: warning 注意
云端生成的费用记在你在服务商（Tripo、Fal 或 RunningHub）的账户上。窗口里会显示每个模型按哪个账户计费。
:::

### 视角越多，背面和侧面越准 {#more-views-better-backs-and-sides}

3D 生成器不是随便收几张图就行，它要的是同一物体的固定视角：正面，加上左侧、背面和右侧。多出的视角让背面和侧面更准确；只放正面也能生成。各模型的支持情况不同：

| 服务商 | 多视角 |
| --- | --- |
| **Tripo** | 每个模型都有多视图模式。需要正面加至少一个其他视角 |
| **Fal** | Hunyuan 3D 3.1 Pro、Tripo H3.1、Meshy 7.1、Rodin 2.5 和 Hi3D 3.0 收多个视角。Hunyuan 3.1 Rapid、Tripo P2、TRELLIS 2 和 Idol Max / Max Turbo 只收一张图。Fal 上的 Tripo H3.1 按位置读取视角：没有左侧图时，背面和右侧会被丢弃 |
| **RH** | 按视角数自动换用对应的多视图端点；`meshy6` 只收一张图 |
| **本地 Hunyuan3D** | 一张图 |

对只收一张图的模型，窗口会把其他格子置灰。模型用不上的视角不会发送，结果里会说明。

## 保存了什么 {#what-gets-saved}

- 生成的模型在加入之前暂存在 `assets/refs_gen3d/`。加入后复制到 `refs/models3d/gen3d_<job>.glb`。
- 没有加入的模型，以及在窗口里上传的图片，一天后删除。
- 服务商、模型、纹理设置和每个视角用的图片保存在 `refs/annotations.json`。卡片显示 **🧊 AI 生成** 以及服务商和模型。

## Agent 怎么使用 3D 模型 {#how-agents-use-3d-models}

- 只有当模型的注释指向 Agent 正在做的对象（角色、生物、道具或场景），或总制片在工单里点名这个文件时，Agent 才会使用它。
- Agent 用它来理解各个角度的形体、比例和部件。
- GLB 不是图片，所以永远不会作为参考图发给图像或视频模型。如果 Agent 需要某个特定角度，它会告诉你。在查看器里把模型转到那个角度，截图，上传到对应的图片板块（例如 **👤 角色**）。

## 常见问题 {#troubleshooting}

**「没有可用的 3D 模型」**
还没有配置 3D 服务商。在 **🎨 生成模型 → 🧊 3D 模型** 里填入 Key 或服务地址。

**本地 Hunyuan3D 开着纹理时任务失败。**
本地服务必须带 `--enable_tex` 启动才能生成纹理。用这种方式启动，或取消勾选 **生成纹理**。

**「超过 35 分钟没出模型，已放弃」**
服务商没有按时返回模型。再试一次，或换一个模型。

**「这次生成的记录已经不在了（服务重启过？）」**
任务保存在内存里。重启后重新生成。
