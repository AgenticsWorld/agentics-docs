# 道具

武器、信件、钥匙、瓶子、手机：故事依赖的每件物品都有一张道具卡和一张参考图，所以它在各个镜头之间保持同样的样子和大小。你在 **🗡 道具预览** 页审阅它们。

## 道具是怎样做出来的 {#how-props-are-made}

道具分两步制作。

1. **道具卡（第 4 阶段）。** 道具 Agent 通读小说，找出每件武器、物品和法宝，并标出 **剧情道具**，也就是推动情节、或角色反复使用、反复提到的道具。每件剧情道具在 `bible/props.json` 里有一张卡片，带一个 ID（`PROP-…`）。这时还不画图。
2. **道具图（按集）。** 每一集开始时，在分镜表定稿之后，道具 Agent 只为这一集里出现、而且还没有图的剧情道具画图。图片在之后各集复用。按集画图意味着，第一集之后改了美术风格，也不会浪费整本书的道具图。

每集故事板签字之前，美术总监还会检查这一集里的每件剧情道具是否都有卡片和图片，并为缺的下单。

## 道具卡里有什么 {#what-a-prop-card-holds}

| 页面上的小节 | 字段 | 含义 |
| --- | --- | --- |
| **外形描述** | `visual` | 形状、颜色和细节，写法可以直接放进提示词 |
| **材质** | `material` | 用什么做的 |
| **尺寸定义** | `scale` | 三个部分，见下文 |
| **剧情作用** | `plot_role` | 这件道具为什么重要（显示为名称下方的说明） |
| **象征意义** | `symbolism` | 它象征什么（如果有） |
| **持有者/易主链** | `owners` | 谁持有它、什么时候易主 |
| **原文出处** | `source` | 出自哪一章、哪句原文 |
| **推断字段** | `inferred_fields` | 哪些细节是设计出来的，而不是取自小说 |

### 尺寸 {#size}

尺寸靠文字传达，不靠图片。每件剧情道具都有三个尺寸字段：

- `canonical_size`：一个测量值，例如「高约 10 cm」。它给人和审核检查用，不进提示词。
- `relative_anchor`：与身体部位或日常物品比较的大小。
- `prompt_token`：一个简短短语，自带比较对象和道具的拿法，例如「一个约一手高的小玻璃瓶，瓶颈系着写有 DRINK ME 的纸标签」。展示这件道具的每条视频提示词，都会原样写进这个短语。

### 只有一面有字的道具 {#props-with-writing-on-one-side}

拿在手里、只有一面能读的道具（信件、合同、照片、手机、地图），会有一条 `readable_face` 说明，描述正面和背面。它们的图片会画出两面并加标注，这样每个镜头都能写明哪一面朝向镜头。

## 道具图 {#the-prop-image}

- 每件道具一张图 `main_01.png`。它也是视频生成时附上的那张图。
- 道具是唯一的主体，放在纯色中性背景上，画面里没有别的东西：图里多出来的东西往往会出现在视频里。
- **不出现人。** 没有手、身体或剪影，也从不把角色图当作道具的参考。画面里有人会抢走主体，还可能让图片被渠道的内容审核拒绝。
- `refs/props/` 里注释写明这件道具的图片，会作为参考。见[参考文件](/zh/videoagents/world/reference-files)。

较早的项目可能还有 `scale_ref_01.png`，显示道具和尺寸参照物放在一起。现在不再画这类图，也不再附到新的提示词里，但已有的会保留。

## 在道具预览页审阅道具 {#review-props-on-the-prop-preview-page}

打开 **预览设定产物** 菜单（控制台顶栏的图片图标），选择 **🗡 道具预览**。

![PROP-box-of-comfits 的道具预览：左侧是带剧情标记的道具列表，右侧是道具图和一张旧的尺寸参照图，以及外形描述、材质和尺寸定义小节](/images/videoagents/world/props.webp)

**左侧列表** 显示每件道具，剧情道具带 **剧情** 标记，**🖼** 加图片数。**搜索道具…** 匹配 ID、名称和类别。分集菜单只显示某一集里的道具。

**右侧详情：** 名称、ID、类别、**剧情道具**、**✏️ 修改**；**首次出场** 和 **出场**；剧情作用；图片（点一张看大图）；然后是卡片的各个小节，其中 **推断字段** 默认折叠。

顶部的 **🎨 图像模型** 决定绘制道具图时使用的渠道和模型。**跟随全局** 使用 **🎨 生成模型** 页上的图像设置。见[图像模型](/zh/videoagents/models/image-models)。

完整的 `props.json` 也可以在 **🌍 世界观预览 → 道具** 里查看。

## 提出修改 {#ask-for-a-change}

- 名称旁边的 **✏️ 修改** 把关于道具卡的意见发给修改师，修改师会按道具 Agent 的方式处理。例如：「钥匙应该是铁的，不是金的，大小和手掌差不多」。
- 图片下方的 **✏️ 修改** 发送关于这张图的意见。
- 图片下方的 **🖌 画板** 在[画板](/zh/videoagents/world/image-canvas)里打开它。

见[修改师和修改意见](/zh/videoagents/concepts/reviser)。
