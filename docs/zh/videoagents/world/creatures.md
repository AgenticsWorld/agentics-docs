# 生物

动物、怪物、龙、坐骑和人造生灵都按角色的方式处理：每一个都有登记条目、足以照着画的描述，以及一张让它在每个镜头里保持一致的设定图。你在 **🐎 生物预览** 页审阅它们。

## 生物是怎样做出来的 {#how-creatures-are-made}

| 步骤 | Agent | 结果 |
| --- | --- | --- |
| 登记和描述 | 生物图鉴 | 小说里的每个生物在 `bible/creatures/index.json` 里有一个 ID（`CRE-…`），在 `bible/creatures/creature.json` 里有一张卡片：相对常见参照物的体型、体表（鳞片、羽毛、毛皮和颜色）、头部、眼睛和显著特征；习性和栖息地；能力和强弱；以及它的 **形态**（例如幼年、成年或变身后），每种形态注明从哪一章开始 |
| 坐骑 | 坐骑 | 用于被骑乘或驾驭的生物：主人、何时以何种方式得到、鞍具等装备、速度、可载几人、怎样移动、怎样骑乘。保存在 `bible/creatures/mount.json` |
| 设定图 | 生物概念 | 每个生物一张设定图，在某一集需要时绘制（见下文） |

卡片在[工作流](/zh/videoagents/concepts/workflow)的第 3 阶段写出，属于 **角色与资产确认**（H1A）的一部分。和世界圣经里的其他内容一样，每个条目都注明出自哪一章，小说没写明的细节会被设计出来并标记 `inferred: true`。

## 设定图逐集绘制 {#reference-sheets-drawn-per-episode}

生物设定图不是一次全部画完的。每一集开始时，在分镜表定稿之后，生物概念 Agent 只画这一集里出现、而且还没有设定图的生物。为某一集画的设定图，之后各集都会复用。这样，如果第一集之后改了美术风格，不会白白浪费整本书的生物图。

- **设定图**（`sheet.png`）和角色设定图版式相同：整只生物的正面、侧面和背面，再加一个大的头部特写。一张图，至少 2560×1440，只画一次，不会被切开。
- **阶段变体。** 生物在故事中外观有明显变化时（长大、受伤、配上鞍具），每个阶段一张设定图 `sheet_<stage>.png`，在处于该阶段的某一集需要时绘制。外观没有明显差别的阶段不出图。
- **坐骑画的时候不带骑手。** 鞍具和装备画在动物身上，但不出现人。动物和骑手相比有多大、怎样骑乘，改为写进视频提示词。
- `refs/creatures/` 里注释写明这个生物的图片，会作为参考。见[参考文件](/zh/videoagents/world/reference-files)。

## 在生物预览页审阅生物 {#review-creatures-on-the-creature-preview-page}

打开 **预览设定产物** 菜单（控制台顶栏的图片图标），选择 **🐎 生物预览**。

![CRE-001（现实世界里的白兔）的生物预览：左侧是生物列表，右侧是四视图设定图和卡片里的形态阶段小节](/images/videoagents/world/creatures.webp)

**左侧列表** 显示每个生物的类型，以及 **🖼** 加图片数。**搜索生物…** 匹配 ID、名字和类型。分集菜单只显示某一集里的生物。

**右侧详情：**

- 名字、ID、类型，人造生灵显示 **造物**，以及 **✏️ 修改**。
- **出场章节**、技术引用和词典引用，以及一句话概述。
- 图片。`candidates/` 这类子文件夹显示为文件夹卡片。点图片看大图。
- **详情卡：** 先显示卡片出自哪个文件，然后卡片的每个部分一个可折叠小节。已知的部分排在前面：**解剖结构**、**运动方式**、**归属**、**鞍具装备**、**载具性能**、**状态日志**、**保养维护**、**狂暴行为**、**镜头用途**、**视觉识别特征**、**形态阶段**、**习性**、**战力**、**出场** 等；其余的排在后面。
- **登记信息**（默认折叠）：这个生物在 `index.json` 里的条目。

顶部的 **🎨 图像模型** 决定绘制生物设定图时使用的渠道和模型。**跟随全局** 使用 **🎨 生成模型** 页上的图像设置。见[图像模型](/zh/videoagents/models/image-models)。

## 提出修改 {#ask-for-a-change}

- 名字旁边的 **✏️ 修改** 把关于生物卡片的意见发给修改师，修改师会按生物图鉴和生物概念 Agent 的方式处理。
- 图片下方的 **✏️ 修改** 发送关于这张设定图的意见。
- 图片下方的 **🖌 画板** 在[画板](/zh/videoagents/world/image-canvas)里打开它，让你精确标出要改的地方。

见[修改师和修改意见](/zh/videoagents/concepts/reviser)。

## 是生物还是角色？ {#a-creature-or-a-character}

会说话的动物可以是生物，也可以是角色，或者两者都是。在示例项目 *alices* 里，Alice 梦中的白兔是一个有声音、有服装的角色；她在河岸上看到的真兔子是生物 `CRE-001`；鹰头狮既有角色条目，也有一张与之关联的生物卡片。如果某个对象的登记方式不适合你的故事，用 **✏️ 修改** 或在控制台对话里说明。
