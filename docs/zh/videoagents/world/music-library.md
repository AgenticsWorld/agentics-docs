# 音乐库

每个项目都有一个配乐库。每交付一集的配乐，新曲目就会连同情绪、曲风和节奏一起入库。之后的各集先在库里找：反复出现的主题可以原样回归，也可以以变奏形式出现，只有在库里找不到合适的曲目时才做新音乐。

**音乐库** 页让你试听每首曲目、查看它用在哪里，并把关于它的意见发给 **配乐** Agent。

::: tip 提示
音乐库 v1.0.37 起可用。主题、变奏和复用配额在 v1.0.38 加入。
:::

## 曲目怎样进入音乐库 {#how-tracks-get-into-the-library}

1. **配乐** Agent 为一集配乐。每个配乐点按这个顺序选曲：你自己放在 `refs/music/` 里的音乐（参考文件页的 **🎵 音频** 板块）、项目音乐库里的曲目，或用音乐模型生成新音乐。
2. 交付这一集时，它新加的曲目（新生成的，以及用到的你提供的音乐）会连同数据一起复制进音乐库：情绪、曲风、节奏、乐器、时长、生成提示词和许可。
3. 这一集的每个配乐点都记为对应曲目的一次使用：哪一集、哪个配乐点、入点和出点、场景。

第一集开始时音乐库是空的，所以它的音乐全部是新的。

## 主题曲、一次性曲目和变奏 {#themes-one-offs-and-variations}

曲目分两类：

| 类型 | 是什么 | 之后各集能原样复用吗？ |
| --- | --- | --- |
| **主题曲** | 贯穿整季的动机（一个主角、一个反派、一个地点、一种情绪）。它有一个主题 ID（例如 `T-MAIN`）、一个名称和一段对动机的简短描述。 | 能 |
| **一次性** | 为某一集某个时刻写的配乐 | 不能 |

对每个配乐点，配乐 Agent 在三种做法中选一种，并写明理由：

- **复用** 一首主题曲，原样使用，让主题回归。
- **做一个变奏**：同一个动机，换节奏、配器、强度或时长重新生成。变奏是一首属于同一主题的新曲目，并记录它变奏自哪一首。
- **做新音乐**：库里没有合适的曲目时。

每一集都要保持平衡，不平衡的集会被配乐检查退回：

| 规则 | 限制 |
| --- | --- |
| 原样复用的配乐点 | 最多占这一集配乐点的 40%（至少总能复用一个） |
| 新音乐和变奏 | 至少占配乐点的 30% |
| 同一首曲目在一集里 | 只用一次 |
| 一首曲目跨集使用 | 最多 3 集，之后只能做变奏 |
| 可以复用什么 | 只有主题曲 |
| 复用配乐点的长度 | 至少是曲目的 60% |
| 情绪 | 配乐点的强度与曲目相差不超过 0.25 |

## 打开音乐库 {#open-the-music-library}

在控制台顶栏打开 **🎛️**（项目设置），选择 **音乐库**。页面显示顶栏所选项目的音乐库。

![一个第一集已配乐但还没同步的项目的音乐库页：筛选器、合计、复用配额和同步入库提示条](/images/videoagents/world/music-library.webp)

## 页面显示什么 {#what-the-page-shows}

顶部的筛选器：

| 筛选器 | 选项 |
| --- | --- |
| 分集 | **全部分集**，或某一集：这一集新增或用到的曲目 |
| 来源 | **全部来源**、**新生成**、**用户提供**、**跨集复用过的**、**主题变奏** |
| 主题 | **全部主题**、某个主题，或 **一次性曲目** |
| 搜索 | 情绪、曲风、乐器、标签或提示词里的文字 |
| **显示已被替换的旧曲** | 同时列出某一集重做配乐后不再使用的曲目 |

下面一行显示合计（曲目数、复用数、主题曲、一次性、变奏）和复用配额。

每首曲目一行：

| 列 | 含义 |
| --- | --- |
| ▶ | **试听**。再点一次停止。 |
| **曲目ID** | `MUS-0001`、`MUS-0002`…… |
| **情绪** | 曲目针对的情绪和强度 |
| **主题** | 主题 ID 和名称，或 **一次性** |
| **曲风 / 节奏 / 乐器** | 风格、bpm 和配器 |
| **曲目时长** | 时长，单位秒 |
| **来源** | **新生成** 或 **用户提供**；变奏显示 **变奏自 MUS-…**；适用时显示 **已被替换** 或 **文件缺失** |
| **入库分集** | 让它入库的那一集 |
| **使用的分集** | 使用它的分集。入库那一集以外的分集显示为绿色。 |
| **使用次数** | 使用它的配乐点数 |
| **复用集数** | 原样复用它的集数，满额为 3。达到上限时显示为红色。 |
| **修改** | 在右下角打开一个意见浮窗，已填好这首曲目，发给 **配乐** Agent |

点一行打开详情：音频播放器，曲目的标题、情绪、曲风、节奏、乐器、强度、标签和备注，所属主题及其变奏来源，生成提示词，库内文件，在哪一集、什么时候入库，音频格式，许可记录，以及一张 **使用记录** 表，列出使用它的每个配乐点（分集、配乐点、入点和出点、铺乐时长、场景、情绪段，以及是首次使用还是复用）。

## 同步入库 {#sync-to-library}

右上角的 **同步入库** 把每一集的配乐点表和音乐库对比：把缺的配乐曲目复制进来，并重新统计每首曲目被哪些分集使用。它不生成任何东西，也不花钱。

音乐库出现之前就已配乐的分集需要用到它。某一集的配乐还没进音乐库时，会出现一条黄色提示条，写明是哪一集，并提供同一个按钮。

## 文件 {#files}

| 路径 | 内容 |
| --- | --- |
| `assets/audio/library/music/index.json` | 音乐库：曲目、曲目数据、主题和使用记录 |
| `assets/audio/library/music/MUS-NNNN.<ext>` | 曲目文件 |
| `assets/audio/bgm/<ep>/cue_sheet.json` | 一集的配乐点及其使用的曲目 |

## 几点说明 {#good-to-know}
- **库内文件永远不会被改动。** 复用的曲目会复制到这一集自己的音乐文件夹。如果为某个配乐点做了裁剪或循环，这一集用的是改过的副本，在使用记录表里标为 **派生文件**。
- **被替换的曲目会保留。** 某一集重做配乐后，它不再使用的曲目标为 **已被替换**。文件留在磁盘上，但不会再提供给新的分集。
- **较早的分集。** 复用规则出现之前配乐的分集，按原样可能通不过配乐检查。要不要重新配乐由你决定。
- **动效短片。** 动效短片项目可以从项目音乐库或你自己的音乐里取配乐，而不是作曲。见[动效短片](/zh/videoagents/project-types/motion-graphics)。
