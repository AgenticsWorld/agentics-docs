# 审核与缺陷单

一集发布之前，最多有八个审核 Agent 从各自的角度审查它：剧情逻辑、角色、时间线、世界观、画面、声音、内容安全和版权。它们发现的问题会变成缺陷单，你可以在 **🧾 缺陷单** 页查看和移交。

## 质量是怎样检查的 {#how-quality-is-checked}

工作要通过三层检查：

1. **机检**：对每个结果做自动检查，包括文件格式、时长、必填字段、参考素材数量等很多项。
2. **质量评委**：按评分标准给每个任务打分。低于合格线的工作带着意见退回。
3. **审核**：检查完成的一集，每项审核各管一个维度。

第 2 层和第 3 层的严格程度，按项目在 **🎛️ → 审核设置** 里设置。见[审核设置](/zh/videoagents/console/review-settings)。

## 八项审核 {#the-eight-reviews}

| 审核 | Agent | 检查什么 | 通过条件 |
| --- | --- | --- | --- |
| 逻辑 | **逻辑审核** | 剧情逻辑，以及对小说关键事件的偏离 | 没有 blocker 级缺陷 |
| 角色 | **角色一致性审核** | 整集中的脸、服装和嗓音 | 一致性评分不低于 85，且每个主要角色都能认出来 |
| 时间线 | **时间线审核** | 时间、季节和年龄前后一致 | 没有冲突 |
| 世界观 | **世界观审核** | 画面符合世界圣经：建筑、服饰、体系 | 没有 blocker |
| 画面 | **画面质量审核** | 变形、闪烁、瑕疵、分辨率 | 有瑕疵的镜头不超过 2%，且都不是关键镜头 |
| 声音 | **音频质量审核** | 响度、削波、口型错位 | 各项指标都在限值内 |
| 内容安全 | **内容安全** | 暴力血腥等平台红线，以及明确的年龄分级 | 没有违禁内容 |
| 版权 | **版权审核** | 素材、音乐和字体的授权 | 每一项都有记录在案的来源 |

报告保存在 `qa/reports/<ep>/`，每项审核一个 JSON 文件。其他项目类型还有各自的终审，例如音频配画项目的音画同步审核和混剪项目的终审。

## 审核有多严格 {#how-strict-the-reviews-are}

每项审核在 **审核设置** 里都有一个 0–100 的力度（**逻辑审核**、**角色一致性审核**、**时间线审核**、**世界观审核**、**画面质量审核**、**音频质量审核**、**内容安全**、**版权审核**）：

| 力度 | 效果 |
| --- | --- |
| 0 | 跳过这项审核 |
| 1–39（宽松） | 只有 blocker 会叫停工作；评分门槛降低 10 分 |
| 40–69（正常） | 按上面写的门槛执行 |
| 70–89（严格） | 门槛提高 5 分；blocker 和 major 级缺陷会叫停工作，minor 级也会开单 |
| 90–100（最严格） | 门槛提高 10 分，任何缺陷都零容忍 |

所有审核力度默认都是 0，所以只有你调高的维度才会审核。同一个对话框里的 **质量评委** 是任务评分的合格分（默认 60）；设为 0 则跳过评分。

审核在质量关口进行，而不是每份草稿都审：工作在起草和返工期间，不派审核。每个关口之前，总制片会派出力度大于 0 的审核。

## 缺陷单 {#defect-tickets}

发现的每个问题都会在 `qa/defects/` 里变成一张缺陷单，文件名形如 `DEF-ep01-visual-0042.json`。缺陷单记录：

- **严重度**：`blocker`（阻断）、`major`（严重）或 `minor`（轻微）。
- 违反了什么，以及证据（例如一张截帧）。
- 目标产物、报告它的 Agent，以及被指派修复的 Agent。
- **状态**：`open`、`fixing`、`verify`、`closed` 或 `waived`。缺陷单只有写明处理结果、并由修复者以外的人验证后才能关闭。豁免（`waived`）的缺陷单必须链接到接受它的那次关口决定。

如果原因出在上游（例如世界圣经里的一个设定错了），缺陷单会交给负责它的 Agent，下游只重做受影响的工作。

### 缺陷单与关口 {#defects-and-gates}

还有 blocker 或 major 级缺陷单未关闭时，质量关口不能通过。它要么暂停，要么带着豁免清单通过，清单逐条列出被接受的缺陷单、理由和签字人。八份报告都没问题后，你签字发布（H5）。见[签字点](/zh/videoagents/concepts/sign-off-gates)。

### 返工 {#rework}

Agent 自动重做失败工作的次数，是 **⚙️ → 高级 → Agent 高级设置** 里的 **重跑次数**（或用 `/retry` 命令设置）。默认是 0：第一次失败就交给你，不会自动重做。见[Agent 高级设置](/zh/videoagents/console/agent-advanced-settings)。

## 缺陷单页 {#the-defects-page}

从 **🎛️ → 缺陷单** 打开。

![筛选为 ep01 的缺陷单页，其中一张缺陷单已展开，显示影响、指派的 Agent 和工单文件](/images/videoagents/create/qa-reviews-defects.webp)

1. 在下拉框里选择一集、**全部分集**，或 **未标注集数的通用工单**。勾选 **只看未关闭** 隐藏已关闭的缺陷单，旁边的计数显示还有多少未关闭。
2. 表格显示每张缺陷单的 **缺陷ID**、**严重度**、**类型**、**状态**、**对象 artifact**、**提出方**、**日期** 和 **问题描述**。
3. 点一行展开它：**违反约定**、**证据**、**影响**、**修复建议**、**指派**、**处理结果**、**豁免 waiver** 和 **工单文件**。
4. 点 **处理**，会打开一个发给总制片的消息框，里面已填好这张缺陷单的详情。补充你的指示后发送。总制片会把缺陷单交给负责的 Agent，修好后更新它的状态。

缺陷也会在别处显示：在 **🎚️ 后期处理** 页，有未关闭缺陷单的组会在列表和本集时间线上显示一个红点，**有缺陷** 筛选只显示这些组。
