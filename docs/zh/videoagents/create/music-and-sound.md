# 音乐与音效

一集的声音有三个来源：视频模型随每段组视频生成的音效和环境声，后期加入的背景音乐（BGM），以及人声（对白、画外台词和旁白）。**混音师** Agent 把它们合成每集一条音轨。本页说明每一部分怎么做出来，以及你能在哪里修改。

## 开始之前 {#before-you-start}
- 音乐和补充音效的渠道在 **⚙️ → 生成模型** 里设置。见[音乐与音效模型](/zh/videoagents/models/music-and-sound-models)。
- 如果有想用的音乐，把文件放进项目的 `refs/music/` 文件夹（或在 **🖼 参考文件** 页添加）。见[参考文件](/zh/videoagents/world/reference-files)。

## 音效与环境声 {#sound-effects-and-ambience}

默认情况下，音效和环境声不是单独的文件。它们被写成声音提示，和画面一起生成：

- **音效** Agent 逐一查看分镜表和走位节拍，为每个能听到的事件写一条提示，例如「厚书翻过一页，干脆清脆的一声」。至少 90% 的关键动作有提示。
- **环境音** Agent 为每场戏写一条环境声提示，例如安静的夏日午后，有蜜蜂声和远处的羊铃声。
- **Prompt 工程师** 把这些提示逐字抄进每个组的提示词，由视频模型在视频里生成这些声音。

提示用界面语言书写，保存在 `assets/audio/sfx/<ep>/audio_cues.json`。

### 音效点位表 {#the-sound-effect-cue-sheet}

当生成的视频里缺了某个音效或音效不对，而为此重新生成整组又不值得时，可以在混音时单独补一个音效。在 **🎚️ 后期处理** 页管理：在 **音效与声音** 里，点 **音效点位表** 旁边的 **打开点位表**。

![ep01 的音效点位表：每条分镜提示都列出时间、组和镜头，来源下拉框设为「未定」，还有文件字段和以 dB 为单位的电平](/images/videoagents/create/music-and-sound-sfx-cue-sheet.webp)

每一行是分镜里的一条提示，带有它在本集中的时间。为每一行选择 **来源**：

| 来源 | 含义 |
| --- | --- |
| **未定** | 还没处理（显示一个红点） |
| **选库** | 用已有的文件：音效库里的条目，或项目里的路径 |
| **生成** | 文件留空；**派单生成缺项** 会让音效 Agent 做出来 |
| **略过** | 有意不做 |

在 **dB** 里设置电平（默认 −12），在 **新增点位** 下加入你自己的提示，然后点 **保存点位表**。**派单生成缺项** 会保存点位表，并把「生成」的行发给音效 Agent。

生成的音效使用生成模型页上的音效渠道：代码合成的声音、在 Openverse 搜索免费（CC0 或公有领域）录音，或 ElevenLabs 等生成渠道。不循环的音效会切掉静音并做响度归一化。如果找到的录音要求署名，会在片尾注明。

## 背景音乐 {#background-music}

**配乐** Agent 读过色彩剧本的情绪曲线和本集的节奏后，为每一集配乐：

1. **音乐放在哪里。** 它挑出值得烘托的时刻：开场、转折、冲突和高潮、结尾、蒙太奇和没有台词的段落。对白密集的段落和日常过渡通常不配乐。音乐覆盖本集的 30–60%。
2. **优先用你的音乐。** `refs/music/` 里的文件会被逐一听过，情绪和速度合适的就用上。可以在 `refs/NOTES.md` 里写明某首曲子该放在哪里。没用上的曲子会列出来，并说明原因。
3. **项目音乐库。** 前几集的音乐保存在项目的音乐库里。反复出现的主题可以原样回归最多三集，之后以变奏形式回归；每一集总会有一些新音乐。见[音乐库](/zh/videoagents/world/music-library)。
4. **新音乐**：剩下的位置用生成模型页上的音乐渠道生成。

每条配乐都有入点、出点和授权记录（生成的、你自己的文件，或来自音乐库），版权审核会检查这些记录。文件和配乐表保存在 `assets/audio/bgm/<ep>/`，新曲子连同情绪、风格、速度和乐器信息加入音乐库。

音乐从不在组视频里生成，它总是单独的一条音轨。

### 审听音乐 {#review-the-music}

在 **🎦 分镜预览** 里，每条配乐在它进入的镜头处显示为一行 🎵：配乐编号、情绪、入点和出点时间，音频生成后还有播放器。没能对应到某个镜头的配乐列在本集的最上方。点某条配乐上的 **✏️ 修改** 提出修改要求。

## 混音 {#the-mix}

**混音师** Agent 用以下素材合成本集音轨：

1. 每段组视频的原生音频（对白、音效、环境声），按顺序拼接，接缝处做短交叉淡化。
2. BGM，按配乐表放置。
3. 旁白（如果开启了旁白）。
4. 画外台词和 V.O. 台词（如果有）。
5. 点位表里的补充音效。

有对白和旁白时，音乐会自动压低。整条音轨统一到 −14 LUFS（±1），真峰值不高于 −1 dBTP，保存为 `assets/audio/final/<ep>.wav`。

混音跟随你在后期处理页采纳的组版本。如果在混音之后缩短了某个组或采纳了新版本，检查会把混音标为过期，并按当前版本重新混音，让音乐和旁白保持在原位。

### 调整声音 {#adjust-the-sound}

在 **🎚️ 后期处理** 页，**音效与声音** 一栏可以做这些调整：

| 调整 | 作用 |
| --- | --- |
| **环境声** | 按设定电平加一层循环的背景底 |
| **BGM 段落** | 给本集的一段标上情绪，让配乐 Agent 重做这部分 |
| **对白 / 旁白电平** | 修正被音乐盖住的台词 |
| **混音目标** | 修改本集的响度目标 |
| **去人声** | 从视频原生音频里去掉人声，保留音效、环境声和音乐 |
| **去环境声** | 只保留人声 |

**去人声** 和 **去环境声** 使用你电脑上的人声分离模型，首次使用时下载（约 64 MB）。提交其中任何一项后，本集需要重新混音，改动才会进入成片；在这条调整上点 **派单重混**。

监视器下方的五条声音轨道（**原声**、**配音**、**旁白**、**BGM**、**音效**）各有一个 🔊 按钮，可以分别单独试听。见[后期处理](/zh/videoagents/create/post-production)。
