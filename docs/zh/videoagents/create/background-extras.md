# 背景群演（NPC）

高峰时段的街道空无一人，看起来就不对。NPC 参与构图会加入无名的背景人物和前景物体（路人、坐在长椅上的人、镜头前一根虚化的路灯杆），让场景有前景、中景和背景三层。剧本拆解时会自动判定每一场，你也可以逐场开关并设置热闹程度。

::: tip 提示
v1.0.39 起可用。
:::

## 项目开关 {#the-project-switch}

在 **🎛️ → 输出设置 → NPC 参与构图** 里设置（新建项目向导里也有）：

| 取值 | 作用 |
| --- | --- |
| **按场次判定（默认）** | 剧本拆解时逐场判定。任何一场都可以手动修改。 |
| **全部关闭** | 所有场次都不加 NPC。各场的标签显示 **总开关关**。 |

剧本里点名的群演（巡逻的卫兵、说话的乘客、有反应的围观者）不算 NPC。他们按点名群演处理，不受这个开关影响。

## 怎样判定一场 {#how-a-scene-is-judged}

剧情时间轴 Agent 制作剧本拆解表时，逐场决定这一场该不该有 NPC、有多少，并引用剧本原文写一句简短理由。

- **开**：在那个时段按常理会有人的公共或热闹场所：街道、集市、广场、码头、车站、酒馆和茶楼、宴会、朝堂、军营、教室。剧本提到人群或喧闹时为热闹；普通公共场所为适中；庭院、走廊、店铺、村巷这类半公共场所为稀疏。
- **关**：剧本写明空无一人或已清场的地方；需要「只有他们」的场次（密谈、潜入、对峙）；私密空间（卧室、密室、马车）、梦境和内心空间；深夜（夜市、灯会和宴会除外）；以及已经满是点名群演的场次。
- 人物独处不等于这个地方没有人。

| 密度 | 效果 |
| --- | --- |
| **稀疏** | 一两个人影，离主体较远 |
| **适中** | 三到五人，不成人群 |
| **热闹** | 人物填满画面纵深，主体前方和视线方向留出空间 |

## 修改某一场 {#change-a-scene}

**📜 剧本预览** 和 **📋 故事板** 页的每个场次头上都有 **🚶 NPC** 标签。它显示这一场当前的取值（例如 **开·适中** 或 **关**）及来源：**自动**、**手动** 或 **未判定**。

1. 点这个标签。
2. 选 **自动**（跟随自动判定）、**开** 或 **关**。
3. 选一个 **密度**，或保持 **跟随自动判定**。
4. 点 **保存**。

![S020 场的 NPC 参与构图弹窗：自动、开、关，自动判定为「开·适中」并附从剧本引用的理由，关键词建议，密度菜单设为「跟随自动判定」，以及「取消」和「保存」](/images/videoagents/create/background-extras-switch.webp)

弹窗里还显示自动判定及其理由，以及根据这一场的措辞给出的关键词建议。你的选择保存在 `story/episodes/<ep>/scene_npc.json`。重新分析剧本不会覆盖它，Agent 也不会改动它。

以哪个取值为准：

1. 输出设置里选了 **全部关闭**，所有场次都关。
2. 否则以你为这一场设的 **开** 或 **关** 为准。
3. 再否则以自动判定为准。
4. 从未判定过的场次（例如 NPC 参与构图功能出现之前就拆解过的项目）按关处理。

密度的优先顺序是：你的选择，然后是自动判定，然后是关键词建议，最后是 **适中**。

## 修改之后 {#after-you-change-a-scene}

改开关不会重做已有的内容。在 **📋 故事板** 页，故事板和新取值不一致的场次会标出 **⚠ 分镜未按此设定**。点这一场的 **✏️ 修改**，要求加上或去掉 NPC。只有这一场的 NPC 行会改，镜头不会重新切分。之后的步骤会按各自的检查要求跟上。如果白模已经签过字，改动后需要重新签字。

## NPC 对下游的影响 {#what-npcs-change-downstream}

只影响开启了 NPC 的场次：

| 步骤 | 发生什么 |
| --- | --- |
| 故事板 | 每个镜头以 **🚶** 行列出 NPC 分层（前景、中景、背景）。按景别安排：远景镜头放中景层和背景层的人物；中景镜头放背景路人，可能加一个虚化的前景物体；近景镜头只放虚化的前景物体或虚化的背景人物；插入镜头不放。 |
| 草图 | NPC 画成粗略、无名的人形。 |
| 分镜表和构图 | 定稿镜头保留同样的 NPC，构图把它们写在对应的层里，比主体更小、更虚，不挡主体。它们不计入出场人物。 |
| 白模 | NPC 变成中性色的群演（`EXTRA-NPC-01` …），图例里标为匿名路人，而不是点名的人物。 |
| 视频提示词 | 固定的 `Background figures (NPC)` 段落逐镜描述它们，「每个人都必须对应一张参考图」的规则收窄到点名的人物。 |
| 环境音 | 一层与密度匹配的人群低语，没有清晰的词句。 |

分镜背景图里始终没有人，也不放前景物体，因为一张背景图由多个镜头共用。

## 几点说明 {#good-to-know}
- 视频模型可能把主角的脸贴到路人身上。小而虚、背对镜头的人影效果最好，提示词也会说明他们不像参考图里的任何人。
- 不开白模时，同一场的两个组之间 NPC 可能跳位，因为只有提示词文字在维持一致。开启白模后，它们的位置有关键帧。
- NPC 的动作不占用镜头时长，也不会从主要动作里抢走节拍。
