# 剪辑、字幕与包装

一集的组视频签字、音频混好之后，剪辑类 Agent 会把它们做成完整的一集：粗剪、转场、字幕、屏幕文字、片头片尾和封面。本页说明每一步、你能开启什么，以及文件保存在哪里。

## 开始之前 {#before-you-start}
- 这一集的组视频已经签字（H3B），音频混音已完成。见[图像与视频生成](/zh/videoagents/create/image-and-video-generation)和[音乐与音效](/zh/videoagents/create/music-and-sound)。
- **🎛️ → 输出设置** 里的 **输出语言**，就是字幕和发布素材使用的语言。

## 剪辑流程 {#the-editing-chain}

每一步由各自的 Agent 完成。文件保存在这一集的 `edit/<ep>/` 文件夹里。

| 步骤 | Agent | 结果 |
| --- | --- | --- |
| 1. 粗剪 | **剪辑师** | `cut_v1.mp4` 和 `timeline.json`：组视频按顺序排好，按本集节奏修剪和调整时长 |
| 2. 转场 | **转场实施** | `cut_v2.mp4`，在组边界渲染了已接受的过场 |
| 3. 字幕 | **字幕** | 对白和旁白的 `subtitles.srt` |
| 4. 花字 | **花字** | 屏幕文字设计（`captions.json`），仅在开启花字时制作 |
| 5. 片头片尾 | **片头片尾** | `intro_outro/` 里的片头、片尾和下集预告，仅在开启时制作 |
| 6. 封面 | **封面** | `thumbnail_*.png`：为每个目标平台的画幅各做两个版本（A 和 B） |
| 7. 最终合成 | **后期精修** | `final.mp4` 及其变体，在你完成后期处理之后合成。见[后期处理](/zh/videoagents/create/post-production) |

粗剪后的时长与本集计划时长相差不超过 5%，帧率 24 fps，没有黑帧或跳帧。如果剪辑师在某段视频里发现小的连戏失误（一只袖子、一个道具），它会开一张缺陷单，用视频到视频的方式修改这段视频，而不是重新生成。

## 字幕 {#subtitles}

字幕 Agent 为每句对白和旁白写字幕，与音频的时间误差在 200 毫秒以内。每行都不超过平台的字数限制。画外台词和 V.O. 台词也有字幕，标为 `(O.S.)` 或 `(V.O.)`。

字幕烧录到画面里时，采用小而不抢眼的样式：底部居中，字高不超过画面的 4%，最多两行，白字黑边，没有大块底框。要改样式，在 **🎚️ 后期处理** 页的 **包装** 一栏加一条 **字幕样式** 调整，监视器里可以预览。

字幕是按不含片头的这一集来写的。加了片头后，最终合成会把字幕（和音频）按片头的实测时长整体后移，写入 `subtitles_final.srt`，让它们和 `final.mp4` 保持同步。

## 包装开关 {#packaging-switches}

包装按项目开启，在 **🎚️ 后期处理** 页的 **包装** 一栏里设置。每个开关都标着 **整集 · 项目设置**：它对每一集都生效。

### 片头片尾 {#intro-outro}

| 开关 | 加入什么 |
| --- | --- |
| **片头** | 一段片头字幕序列 |
| **片尾** | 片尾字幕 |
| **预告** | 下集预告。除非你要求，否则没有旁白：钩子以字卡形式叠在画面上，配画面自带的声音和音乐 |
| **字幕烧录** | 另出一份烧录了字幕的成片 `final_sub.mp4`。干净的 `final.mp4` 保留 |

新项目这四项都是关闭的。勾选 **片头** 或 **片尾** 时，会弹出一个输入框，问你要放什么内容。可以留空，让系统按项目风格设计。演职员名单、网址和版权声明会完全按你写的显示；要用 logo 或二维码，把文件放进 `refs/` 并写上路径。以后要改文字，点开关旁边的 **✎ 内容**。

片头、片尾和预告遵循项目的美术风格。片头放在这一集之前，片尾放在这一集结尾的停留之后。

### 花字 {#fancy-text}

花字是经过设计的屏幕文字：人物介绍、地点标注、生物或道具首次出现时的卡片等。每个设计都包括文案、模板、大小、动画和配套的音效。

- 勾选 **启用花字** 开启（默认关闭）。
- **模式** 选 **自动**：由花字 Agent 按题材选择合适的类型。点 **查看目录** 查看可用的类型。
- **模式** 选 **手动**：打开类型列表，勾选允许使用的类型。勾选的类型只要这一集里有适用的内容就会用上，没用上的类型会说明原因。

文字烧录在组视频的副本上（原视频从不改动），这一集会在干净的 `final.mp4` 旁边多出第二份成片 `final_caption.mp4`。在 **🎦 分镜预览** 里，组卡上的 **✨ 花字** 显示它的设计，组视频显示的是带花字的版本。

花字优先使用 `refs/fonts/` 里你的字体。

### 上下黑边 {#letterbox-bars}

勾选 **启用上下黑边**，并选择 **最终输出画幅**（16:9、9:16、4:3、3:4 或 1:1）。渲染成片时，画面会缩放到适合的大小，再用黑边补成这个比例。制作画幅不变。改了这一项后，要重新渲染成片。

### 水印 {#watermark}

要在整集的某个角落放一个 logo，在 **包装** 里加一条 **水印 / 角标** 调整，并选一个 PNG 文件。它在合成成片时加入，不会加到组版本上。

## 封面 {#thumbnails}

封面 Agent 从这一集最好的画面里，为每个平台画幅做两个封面版本。如果你在 `refs/thumbnail/` 里放了示例封面，它会借鉴它们的构图、版式和文字风格。在 **🎞️ 成片发布** 页用 **设为默认** 选择要发布的那一张。见[成片与发布](/zh/videoagents/create/publishing)。

## 签字 {#sign-offs}

- **H3P**（每一集）：你在 **🎚️ 后期处理** 页上的后期签字。见[后期处理](/zh/videoagents/create/post-production)。
- **H4**（仅第一集）：你审阅第一集成片，之后整季其余各集都以它为准。

见[签字点](/zh/videoagents/concepts/sign-off-gates)。
