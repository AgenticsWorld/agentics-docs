# 对白、配音与旁白

默认情况下，视频模型在生成画面的同时，用人物的嗓音说出每句台词，所以口型和语音是对上的。本页介绍这种默认方式、可替代的后期配音、用于预览的对白语音库、逐句演法、画外和 V.O. 台词，以及旁白。

## 开始之前 {#before-you-start}
- 说话的人物都有嗓音：一张嗓音卡和一段简短的声音样本。见[嗓音](/zh/videoagents/world/voices)。
- 如果要用对白语音库、后期配音或旁白，需要在 **⚙️ → 生成模型** 里设置语音合成（TTS）渠道。见[语音模型](/zh/videoagents/models/voice-models)。

## 相关设置 {#the-settings}

所有对白开关都在 **🎛️ → 输出设置** 里。每个字段的说明见[输出设置](/zh/videoagents/console/output-settings)。

| 设置 | 选项 | 作用 |
| --- | --- | --- |
| **对白配音** | **视频原声(默认)**、**后期配音** | 成片里的对白由谁说出来 |
| **生成对白语音** | 开或关 | 为本集对白维护一份逐句 TTS 语音库，用于预览。后期配音必须开启 |
| **声画分离** | **关(默认)**、**仅剧本标记**、**自动** | 让台词可以在说话人不在画面里时（画外 O.S.）或作为 V.O. 被听到 |
| **旁白** | 开或关（默认关） | 加入一条旁白轨，按本集的旁白稿朗读 |

## 视频原声 {#native-video-audio}

选择 **视频原声** 时，对白是组视频的一部分：

- 提示词把每句台词写在说出它的那个镜头里，放在 `{ }` 花括号中。
- 每个说话人物的声音样本（3–5 秒平静、中性的说话声）作为参考音频附上，让模型在不同组、不同集之间保持嗓音一致。样本只决定嗓音，实际的语音和口型由模型生成。
- 一个组里，画面上最多三个说话人。

这种方式下，画内对白从不叠加 TTS，因为不是从画面里出来的语音对不上口型。某句台词出了问题，就重新生成这个组。**口型同步** Agent 只修正整条声轨和画面错位的视频。

## 后期配音 {#post-production-dubbing}

选择 **后期配音** 时，组视频的生成方式和上面完全一样。生成之后，每句台词用人物的嗓音合成，并放进视频里人物开口的那段时间。对白轨被替换，画面和时长不变。模型原本生成的语音会被去掉，保留音效和环境声。

后期配音需要 **生成对白语音**，所以这个模式下该开关锁定为开启。配好的文件保存在 `assets/audio/voice/<ep>/dub/<group>/`，之后的步骤（超分、剪辑、混音）都用配音后的视频。

## 对白语音库 {#the-dialogue-speech-library}

开启 **生成对白语音** 后，VideoAgents 为每句对白保留一个合成音频文件，放在 `assets/audio/voice/<ep>/tts/`。动态样片、白模样片和后期配音都会用到它。台词或嗓音变了，下次需要时语音库会自动更新。

在 **🎦 分镜预览** 里，**🗣 对白语音** 面板显示语音库的状态：总句数，其中 **一致**、**过期**、**缺失**、**未选角** 各多少句，以及 TTS 渠道和模型。

- **🗣 刷新对白语音** 只合成缺失或有变化的句子。
- **↻ 全部重出** 忽略缓存，把每句都重新合成。每句都计费。
- 说话人没有分配嗓音的句子会被跳过，并给出警告；补上选角或修正说话人后再刷新。

## 为每句台词写演法 {#direct-each-line}

展开 **🗣 对白语音** 面板，可以看到 **台词演法**。本集对白定稿后，**台词指导** Agent 会为每句台词写一条演法；你可以在这里修改。

![展开的「对白语音」面板：上方是语音库状态和按钮，下面是台词演法清单，第一条是 Alice 的一句台词，带演法框、场景字段、语速、目标时长、保存按钮和声源](/images/videoagents/create/dialogue-line-direction.webp)

每句台词可以设置：

- **演法**：状态、怎么演、语速、音量和停顿。
- **场景与对象**：在哪、对谁说、刚发生了什么。
- **语速**（快、中、慢）。选一档后，会按台词长度填入一个以秒为单位的 **目标时长**，上限是这个镜头里可用的时间。你也可以自己输入时长。

点 **保存**，再点 **🗣 刷新对白语音**，重新合成这句台词。如果 TTS 渠道不支持控制时长，演法只作为语气指令使用，场景和时长会被忽略，面板上会注明。

## 画外台词和 V.O. 台词 {#off-screen-and-voice-over-lines}

开启 **声画分离** 后，台词可以被听到，而说话人不在画面上开口：

- **画外 O.S.**：说话人在这场戏里，但不在画面中（打电话、在门后、走出画面、给听者的反应镜头）。
- **V.O.**：来自当下之外的声音（内心独白、读信、回忆里的声音）。

**仅剧本标记** 只认剧本里标了 `(O.S.)` 或 `(V.O.)` 的台词。**自动** 还允许分镜在几种列明的情况下把台词移到画外（例如一句长台词配听者的反应，或边走出画面边说的台词），每次都会记录原因。

画外台词不写进组视频提示词，而是在后期用人物的嗓音合成，作为单独一轨混进去。在台词演法清单里，把 **声源** 设为 **画内**、**画外 O.S.** 或 **V.O.**；对画外台词，还要选择 **声源效果**（**原声**、**电话**、**隔门**、**远处**、**内心**、**回忆**），以及 **偏移(s)**，即从镜头开始到听到这句的时间（默认 0.4 秒）。文件保存在 `assets/audio/voice/<ep>/offscreen/`，字幕会给这些台词标上 `(O.S.)` 或 `(V.O.)`。

### 原生先入 {#native-lead-in}

**原生先入** 让说话人在同一组的上一个镜头里先在画外开口，切镜后在画内说完（由模型自己完成的 J-cut）。只有在 **声画分离** 为 **自动**、**对白配音** 为 **视频原声**、且这个组使用 Seedance 2.5 时才可用。先入最长 1 秒。带先入的台词在分镜预览上显示 **🎧 先入** 标签。

## 旁白 {#narration}

开启 **旁白** 后，这一集会有一份旁白稿（`story/episodes/<ep>/narration.md`），由 **旁白** Agent 用项目的旁白嗓音朗读。旁白是单独的一条后期音轨：从它所挂的镜头开始，延续到后面的镜头。

- 每句旁白在 **🎦 分镜预览** 里显示为起始镜头处的一行 🎙，附有估计时长、位置是否已定，录好后还有播放器。
- 在生成本集视频之前，会用旁白实测的时长去核对画面里留出的空间，所以放不下的旁白会被提前发现。
- 关闭旁白，意味着片子里完全没有旁白者。人物自己的画外台词由 **声画分离** 控制，不受这个开关影响。

## 几点说明 {#good-to-know}
- 一句台词要多长时间，按它的长度估算。英文台词按单词数计算，语速取人物嗓音卡上的设定，没有设定时默认每分钟 160 个单词。
- 对某句台词、某句旁白或它的录音有意见，点旁边的 **✏️ 修改**；请求会交给修改师。
- 在不同年龄出场的人物，可以每个年龄各有一段声音样本，每个组使用与它在故事中所处时间相符的样本。
