# 转场

组视频是一段一段生成的，所以如果不加处理，每个组边界都是硬切，哪怕故事换了地点或跳了时间。过场给这些边界一个把观众带过去的办法：叠化、字卡、定场空镜、地点字幕、声桥。你决定一个项目用多少过场，在分镜预览里审阅每条建议，过场会渲染进成片。

## 选择过场模式 {#choose-a-transition-mode}

在 **🎛️ → 视频节奏 → 过场模式** 里设置项目的模式（新建项目向导里也有）。对话框会显示所选模式的具体做法。

![「视频节奏」对话框里的过场设置：过场模式选为经典并显示它的换场景规则，集尾收束设为淡出到黑，以及声桥默认值](/images/videoagents/create/transitions-settings.webp)

| 边界 | 极简 | 经典 | 电影感 |
| --- | --- | --- | --- |
| 换场景 | 硬切 | 定场空镜 2.5 秒（如果首镜已是远景，改为叠地点字幕） | 定场空镜 + 叠地点字幕 |
| 跳时间 | 硬切 | 时间字卡 2.5 秒 | 时间字卡 + 定场空镜 |
| 进闪回/梦境 | 硬切 | 白场 1.0 秒 + 定格 + 叠「N 日前·地点」+ 回忆调色 | 白场 + 定格 + 叠字（生成式桥接为候选） |
| 出闪回/梦境 | 硬切 | 匹配剪辑，可叠「当下」 | 匹配剪辑，可叠「当下」 |
| 同场景同时段 | 硬切 | 硬切（色差过大时给出定格或叠化候选） | 同经典 |
| 集首 | 硬切 | 淡入 | 淡入 |
| 说明性字卡 | 禁止 | 允许 | 允许 |
| 过场时长预算 | 0% | 最多占本集的 8% | 最多占本集的 10% |
| 生成式过场 | 不用 | 不用 | 允许 |

在 **极简** 模式下，只有导演转场清单里点名的边界会做叠化，或过渡到黑场、白场。新项目默认是 **经典**；在有过场功能之前创建的项目，按 **极简** 处理。

**自定义** 让你为六类边界逐项选择处理方式（可选硬切、叠化、黑场、白场、时间字卡、地点字幕叠加、定场空镜、时光流转、生成式桥接、成对运镜和两种声桥，或 **沿导演清单**），并自己设置四个附属项：**说明性字卡**（允许或禁止）、**过场时长预算**（占本集的百分比）、**生成式过场**，以及 **新场景首镜**（必须是定场镜头）。

插入段（字卡、定场空镜、时光流转、桥接）每段 0.5–4 秒，每个边界最多 6 秒，一集的第一个组前面不能有插入段。插入段会让这一集变长；拼成片时，音频和字幕会相应顺移。

::: warning 注意
生成式过场（由视频模型生成的定场空镜或桥接）是付费的视频调用。每一处都会在过场卡上显示估计费用。不开这个选项时，定场空镜用你已有的全景图或场景图加上缓慢平移或推拉做出来，不产生生成费用。
:::

## 审阅建议 {#review-the-proposals}

模式不是极简时，**过场设计** Agent 会为每一处有变化（场景、时间、出场人物、光线、进出闪回）的组边界提出一个设计。你在 **🎦 分镜预览** 里审阅它们。

### 汇总条 {#the-summary-bar}

在这一集的顶部，**⟿ 过场** 汇总条显示：

- 这一集的模式，默认 **跟随项目**。选别的模式可以只为这一集覆盖；建议会重新生成，但不会自动接受；
- 边界数，其中多少有变化、多少不是硬切、多少还在等你裁决；
- **插入**：插入段总时长与本集预算的对比，以进度条显示；
- **出建议**（或 **重出建议**）：重新生成建议。你已经裁决过的边界保留你的决定。

![分镜预览页上的过场汇总条和集尾一行](/images/videoagents/create/transitions-summary.webp)

### 过场卡 {#transition-cards}

每个边界有变化的组前面，都有一张过场卡。没有变化、只是普通硬切的边界，显示为一条细线。

![从 grp001 到 grp002 的过场卡：边界类型、状态、原因（换场景、出闪回、出场人物变化、光线跳变），上一组结尾和下一组开头的缩略图，中间是一个猛切，下面是声桥一行和操作按钮](/images/videoagents/create/transitions-card.webp)

每张卡显示边界类型、状态、变化了什么、上一组的最后一帧和下一组的第一帧（中间是设计），以及以下操作：

| 操作 | 作用 |
| --- | --- |
| 下拉框 + **✔ 接受** | 接受主设计，或某个候选方案 |
| **⏭ 保持硬切** | 裁定用硬切（或恢复导演原来的设计） |
| **✎ 改字** | 修改字卡或叠字的文字，最多三行 |
| **▶ 出预览** | 渲染一段预览小片：上一组的最后 2 秒、过场和下一组的前 2 秒，滤镜和成片相同。大约需要 10–40 秒 |
| **✏️ 修改** | 把对这处过场的意见发给修改师 |

**🤖** 标签表示这个设计是过场设计 Agent 选的，而不是模式的默认做法；**📜** 表示导演从剧本里采纳的场景衔接。见[场景衔接](/zh/videoagents/create/scene-links)。

给这一集的分镜表签字（H3A）时，你还没裁决的建议会全部被接受。想保持原样的边界，请先点 **⏭ 保持硬切**。

## 声桥 {#sound-bridges}

声桥让声音跨过切点，而画面干净地切过去：

- **声先入（J-cut）**：下一组的声音提前在这一组的结尾响起。
- **声延续（L-cut）**：这一组的声音延续到下一组的开头。

每个声桥有时长（0.1–1.5 秒；默认值在视频节奏的 **声桥默认** 里设置，为 0.5 秒），以及它承载什么：**底床**（去掉人声的环境声，画面和口型保持同步），或 **画外台词**（一句跨过切点的画外台词，需要开启声画分离，且切点旁边有这样一句台词）。

在过场卡上设置 **声桥** 一行，然后点 **应用声桥**。声桥只适用于没有插入段、没有黑场停留的硬切或叠化。电影感模式会在换场景和跳时间处建议声先入；极简和经典模式不建议声桥。

声桥在混音时搭建，所以过场卡的预览是没有声音的。你会在成片里听到它们。

## 集尾 {#episode-end}

**⏹ 集尾** 一行设置这一集最后一个组怎样收尾：**淡出到黑**、**淡出到白**、**切黑(突然黑屏)**、**切白** 或 **不处理(停在末帧)**，之后再停留一段。项目默认值是视频节奏里的 **集尾收束**（淡出到黑 1 秒，然后停留 0.5 秒，音频随画面一起淡出）。在这一行里选别的值可以只覆盖这一集，点 **▶ 预览** 渲染带收尾的最后 2 秒。片尾包装接在停留之后。

## 在后期处理中 {#in-post-production}

**🎚️ 后期处理** 页在本集时间线上用 ◇ 标出不是硬切的过场。点一个，就能作为一条 **组间转场(入)** 调整来编辑它。在 **分镜剪辑** 里用 **插黑 / 定格**，还可以在边界处停在上一组的最后一帧，或插入一小段黑场来控制节奏；超过一秒的黑场容易让人以为是故障。见[后期处理](/zh/videoagents/create/post-production)。

过场在剪辑这一集时由 **转场实施** Agent 渲染。如果 `refs/fonts/` 里有项目字体，字卡和叠字会使用它。
