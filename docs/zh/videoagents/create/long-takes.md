# 长镜头与连贯性

视频模型一次只做一个生成组，所以跨好几个组的一场戏，可能在每个组的交界处跳一下。开启 **长镜头** 后，一场戏里的每个组都接着上一组往下做：接它的最后一帧，或接它最后 2–3 秒的视频。

## 连贯性是怎么保证的 {#how-continuity-works}

组与组之间的连贯，总是从规划开始。每一集，**连续性规划** Agent 都会逐镜记录服装、道具和光线状态，并标出每一处组交界（`directing/<ep>/continuity.json`）：

- **连续**（`continuous`）：同一个动作或运镜跨过交界继续，所以下一组开头不能换新构图，人物也不能跳到新位置。
- **切镜**（`cut`）：同一场里的反打或新构图，沿用场景、光线和人物位置。
- **不衔接**：场与场之间的交界，或带溶化、淡入淡出等转场的交界。这类交界从不续接。

同一场内的交界怎么处理，取决于项目设置：

| 长镜头 | 下一组收到什么 |
| --- | --- |
| 关闭（默认） | 不拿上一段视频的任何东西。连贯性靠提示词文字、人物和场景参考图，以及开启白模时的白模运镜视频。各组可以并行生成 |
| 开启，**尾帧图片** | 上一组的最后一帧，作为参考图 |
| 开启，**尾段视频** | 上一组最后 2–3 秒的视频，由模型接着往后续写 |

标成「连续」还是「切镜」，只影响写进下一组提示词的开场句（是延续动作，还是换个构图继续这场戏），不影响附带哪些素材。

## 开启长镜头 {#turn-on-long-takes}

1. 打开 **🎛️ → 视频节奏**。
2. 勾选 **长镜头**。
3. 选择 **连接方式**：**尾帧图片**（默认）或 **尾段视频**。
4. 点 **确定**。

![「视频节奏」对话框里的长镜头设置：连接方式选为尾帧图片，并附有画质漂移的提醒](/images/videoagents/create/long-takes-setting.webp)

这两项也可以在新建项目向导里设置。保存后，设置对之后写入或更新提示词的组生效。

::: tip 提示
**长镜头** 从 v1.0.28 起可用，**连接方式** 从 v1.0.36 起可用。
:::

## 开启后有什么变化 {#what-changes-when-it-is-on}

- **各组按顺序生成。** 在续接的一场戏里，一个组要等上一组的视频生成出来，因为它需要那段视频的最后一帧或结尾。
- **上一段视频的最后一帧** 保存在视频旁边，名为 `assets/clips/<ep>/<group>.last_frame.png`（不管开没开长镜头都会保存）。
- **尾段视频** 裁到 `assets/continuity/<ep>/<group>.continuation.mp4`：最长 3 秒，保持原分辨率，去掉声音，以免旧对白重复出现。它们和成品视频分开存放，所以永远不会被剪进成片。
- **人物、场景和白模参考保留。** 续接素材是加在它们之外的。使用尾段视频时，不会再同时附上尾帧图片。

### 尾段视频什么时候回退到尾帧 {#when-the-tail-video-falls-back-to-the-last-frame}

尾段视频需要模型接受参考视频，组的视频预算里也要有余量。以下情况，VideoAgents 会回退到尾帧图片，并记下原因：

- 模型不接受参考视频；
- 上一段视频结尾处连续的部分不到 2 秒；
- 组的参考视频预算连 2 秒都放不下（余量不够时，先缩短尾段）。

Fal 的 Kling 4.0 接受参考视频，但要求每段至少 3 秒，所以它总是从尾帧图片续接。只接受首尾帧的接口（例如 Fal 的 Kling 3.0 和 MiniMax H3 Max Turbo）完全不能带参考素材，改用首尾帧方式兜底。

如果上一段视频以黑场结尾，系统会阻止续接，而不是从黑帧接下去。请修好上一组，或者把这个交界改成有意设计的转场。

## 在分镜预览里查看续接链 {#see-the-chain-on-the-storyboard}

在 **🎦 分镜预览** 里，每个组的组头会显示它在续接链中的位置：

| 标签 | 含义 |
| --- | --- |
| **◦ 组链起点** | 第一个组，前面没有组 |
| **⛓ 续接 grp004 尾帧** | 接在尾帧上 |
| **⛓ 续接 grp004 尾段视频** | 接在尾段视频上 |
| **✂ 硬切自 grp001(不传尾帧)** | 断开：什么都不沿用 |
| 标签后面的 **⚠** | 提示词的参考素材和连贯性规划不一致；把鼠标移上去看详情 |

上一段视频生成出来之前，它的尾帧在参考图里显示为一个 **⏳ 待前组出片** 方块。

## 重新生成续接链里的组 {#regenerating-a-group-in-a-chain}

续接链是往前走的：如果你重新生成了一个组，下一组当初是从旧视频的结尾做出来的。

- 还没生成的组，会根据新视频重新准备。
- 已经生成的组，保留旧的续接。请重新看一遍两个组之间的接缝，如果跳了，就重新生成下一组。

保留视频动作的小修改（比如用视频到视频修一个道具或服装细节）几乎不改变结尾，但接缝仍然会被比对。

## 几点说明 {#good-to-know}
- 续接是软衔接，不是逐像素对齐。一次又一次从低分辨率的帧或尾段续接，画质和人物相似度会慢慢下降，所以对话框里有这条提醒。
- 使用火山引擎和 Seedance 2.x 时，渠道可能拒收尾帧或尾段里的真实人脸。如果启用了虚拟人像资产库，VideoAgents 会在提交前先把这些素材登记到库里（v1.0.39 起）。见[虚拟人像资产库](/zh/videoagents/models/virtual-avatar-library)。
- 关闭 **长镜头** 后，下次更新提示词时，会去掉续接素材和相关句子，普通的人物、场景和白模参考保留。
