# 剧本与剧本预览

剧情 Agent 把小说的每一集改编成剧本。**📜 剧本预览** 页把剧本排成两栏表格：左栏是剧本，右栏是对应的时长、情绪、钩子和事件。你不用读 Markdown 就能审完一集，还能把每条修改意见直接发给负责那部分的 Agent。

## 剧本是怎么做出来的 {#how-the-screenplay-is-made}

在剧情阶段，每一集要经过几个剧情 Agent，每个 Agent 在 `story/episodes/<ep>/` 里写自己的文件：

| Agent | 做什么 | 文件 |
| --- | --- | --- |
| 剧本改编 | 写场次：场景标题、动作、对白、音效和转场 | `screenplay.md` |
| 对白优化 | 润色剧本里的对白 | `screenplay.md` |
| 旁白转换 | 项目开启旁白时，写旁白稿 | `narration.md` |
| 钩子设计 | 提出开头、集中和结尾的钩子 | `hooks.json` |
| 节奏控制 | 给每场分配时长、情绪曲线和删减建议 | `pacing.json` |
| 剧情时间轴 | 把以上内容整理成本页读取的结构化表格 | `script_breakdown.json` |

分集规划（`story/episode_plan.json`）和事件卡（`story/events.json`）由更早的剧情 Agent 产出，也会显示在本页。

第一集的剧本是一个签字点（H3）。在本页审完后，到控制台答复签字卡。之后各集按同样的标准执行。见[签字点](/zh/videoagents/concepts/sign-off-gates)。

## 打开剧本预览 {#open-script-preview}

1. 在控制台顶栏点 **📜 剧本预览** 图标，或在任意预览页右上角的页面菜单里选 **📜 剧本预览**。
2. 在分集行里选一集。每集后面的标记表示它的状态：
   - **✅**：已有正式拆解表。
   - **⚠**：有剧本，但还没拆解。
   - **–**：还没有剧本。
3. 用右侧的 **📑 场次** 列表跳到某一场。列表里也显示每场分配的时长。

![ep01 剧本预览页顶部：分集按钮、带预估时长和预算时长的标题、带「重新分析」的拆解状态行，以及右侧的场次列表](/images/videoagents/create/screenplay-header.webp)

标题行显示本集预估时长和预算的对比（例如 **⏱ 537 / 540 s**），旁边有一条进度条，预估偏离预算超过 10% 时变黄，超过 20% 时变红；还显示场次、台词和旁白的条数。

## 状态行 {#the-status-line}

标题下方有一行说明表格的来源：

| 状态 | 含义 |
| --- | --- |
| **✅ 正式拆解表 … · 更新于 …** | 剧情时间轴 Agent 已为本集产出 `script_breakdown.json`。 |
| **⚠ 拆解表已过期：… 在拆解之后又更新过，建议重新分析** | 拆解之后，某个输入文件（剧本、钩子、节奏等）又改过。 |
| **⚠ 推导视图** | 还没有拆解表。本页临时解析剧本、节奏和钩子文件，部分细节可能缺失。 |

**🔁 重新分析** 会给剧情时间轴 Agent 派一张工单，重建本集的拆解表。运行期间状态行显示「运行中」，结束后表格自动重新加载。重新分析只重新整理现有文件，不会改写剧本、对白、旁白、钩子或节奏。它和其他 Agent 任务一样，在你的 Agent 引擎上运行。

## 看懂表格 {#read-the-table}

左栏是剧本，按原顺序切成一个个小块。右栏显示属于每一块的信息。

![剧本预览里的 S01 场：左侧是带场景缩略图和出场人物的场次头；右侧是时长条、情绪、NPC 开关、节拍、事件、钩子、删减建议和改编说明；下面是带情绪和预估秒数的动作块和对白块](/images/videoagents/create/screenplay-scene.webp)

| 行 | 左栏 | 右栏 |
| --- | --- | --- |
| **本集** | 一句话梗概、视角、分集规划里的概要和节拍 | ⏱ 预算和预估时长，📖 章节范围，🧩 覆盖的事件，🪝 选用的钩子，🗂 分集规划，⚠ 拆解时发现的问题 |
| 场次头 | 场号和场名、场景 ID、🏠 内 / 🌳 外、时段、带头像的出场人物、场景缩略图 | ⏱ 时长，分成对白（黄）、旁白（紫）和无声画面（灰），附开始时间；🚶 NPC 开关；🎭 情绪表情、强度和类型，节奏 🐢 慢 / ▶️ 中 / ⚡ 快；🎯 节拍和戏剧目的；🧩 事件卡；🪝 放在本场的钩子；✂️ 删减建议；🔒 不能缩短的内容；📝 改编说明 |
| 动作 | 动作段落 | — |
| 对白 | 连续的台词，每个说话人一个彩色圆点，附括号里的表演提示 | 每句：情绪、预估秒数和 ✓ 风格命中；多句时给出 Σ 合计 |
| 旁白 | 🎙 旁白定稿的文本（剧本里没进定稿的旁白候选会被标出） | N 编号、预估秒数、语气和 📍 锚点 |
| 音效 | ♪ 音效行 | 🔊 |
| 转场 | ⤵ 转场，例如 `CUT TO` | 🔗 编剧起草的场间衔接（如果有）。见[场间衔接](/zh/videoagents/create/scene-links) |

几点说明：

- 点场景缩略图或头像可以放大。大图下方的链接会在对应的预览页打开这个场景、人物或生物。
- 场次头上的 **📋** 和 **🎦** 图标会在[故事板](/zh/videoagents/create/storyboard)页和[分镜预览](/zh/videoagents/create/storyboard-preview)页打开同一场。只有那两个页面已有这一场时才会出现。
- 表格下方的图例说明各种颜色和符号。
- 右下角的 **🖨️** 按钮生成一张可打印的两栏页面（剧本和相关信息），并打开打印对话框，可以打印或存为 PDF。

## 把修改意见发给对应的 Agent {#send-a-change-to-the-right-agent}

每一块都有 **✏️ 修改** 按钮。点开后右下角弹出一个小窗，已经填好这一块的位置和摘录，你只需写要改什么。小窗顶部显示由哪个 Agent 接收：

| 在哪里点 **✏️ 修改** | 发给 |
| --- | --- |
| 场次头、动作、转场、**本集** 行 | 剧本改编 |
| 对白块 | 对白优化 |
| 旁白块 | 旁白转换 |
| 🪝 钩子 | 钩子设计 |
| 🎭 情绪和节奏、✂️ 删减建议 | 节奏控制 |
| 🧩 事件卡 | 事件提取 |
| 🗂 分集规划 | 拆集规划 |
| 分集标题旁的 **✏️ 修改** | 修改师，用于对整集的反馈 |

按 Enter 或点 **发送**。回复会出现在控制台里该 Agent 的对话中。

## 先攒注释，再一次提交 {#collect-notes-and-send-them-at-once}

如果你想先把想法记下来，用任意 **✏️ 修改** 按钮旁的 **🗒 注释**。

1. 点 **🗒 注释**，写下想法（情节走向、动机、台词语气、节奏、必须保留的内容），点 **保存**（或按 Shift+Enter）。
2. 注释以黄色显示在这一块旁边，按钮也变成黄色。注释保存在 `story/episodes/<ep>/script_notes.json`。
3. 写完后，点分集行右端的 **📨 提交注释**。本集所有注释作为一张修改单发给[修改师](/zh/videoagents/concepts/reviser)，注释随后清空。

## 标记必须保留的关键点 {#mark-key-points-that-must-survive}

有些情节或细节，不管故事板怎么切，都必须出现在画面上。把它们标出来：

1. 在剧本栏里选中文字，可以跨多个段落。
2. 在弹出的小工具栏里点 **关键情节**（金色）或 **关键细节**（蓝色）。

![在剧本动作块里选中一段文字，上方出现「关键情节」和「关键细节」按钮](/images/videoagents/create/screenplay-keypoints.webp)

标记的文字会高亮。表格上方的 **剧本关键点（n）** 列表汇总所有标记及其状态：

| 状态 | 含义 |
| --- | --- |
| **已关联分镜** | 故事板和分镜表里写明了哪个镜头怎样呈现这个关键点。 |
| **待分镜体现** | 还没有镜头覆盖它。 |
| **原文已变化，仍须保留** | 剧本改过，找不到原来标记的文字了。这个关键点仍然有效。 |

关键点保存在 `story/episodes/<ep>/keypoints.json`，和拆解表分开，所以重新分析不会删掉它们。每个 Agent 都会在项目指令里看到当前有效的关键点，Agent 不得删除、弱化或改写它们。故事板和镜头规划的运行会检查每个关键点至少关联了一个镜头，缺了就判为失败。要去掉一个关键点，在列表里点 **取消标记** 并确认。

## 其他语言的项目 {#projects-in-other-languages}

当 **🎛️ → 输出设置 → 输出语言** 不是中文时，Agent 用那种语言写整个剧本，但有几个标签固定用英文，以便拆解和检查能读懂。如果你手动编辑 `screenplay.md`，请保留这些标签：

```markdown
## S03 | INT | SCN-0012 Sutra hall | night
**[EVENTS] ev0021 | [CAST] CHAR-0001 | [DURATION] 40s**
ACTION: The lamp gutters. She steps back from the shelf.
CHAR-0001: "Who's there?"
[NARRATION (narrator)]: Nobody had climbed these stairs in years.
SOUND: Rain on the roof tiles.
TRANSITION: CUT TO
```

- 场景标题的最后一段总是按时段读取，不论用什么语言。
- 说话人需要 `CHAR-` 编号。没有台词的场次写 `[NO DIALOGUE]`。
- 旧版的中文标签（`动作:`、`转场:`、`[事件]` …）同样能读，已有项目照常可用。

## 常见问题 {#troubleshooting}

**表格是空的，或者某场没有台词。**
页面多半显示的是推导视图，而剧本里的标签它读不懂。点 **🔁 重新分析**，让剧情时间轴 Agent 产出正式拆解表。

**页面提示拆解表已过期。**
拆解之后有文件改过。点 **🔁 重新分析**。你的关键点和注释不受影响。
