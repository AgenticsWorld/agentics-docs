# 直播生成

**📡 直播** 页在你的项目之外运行一路持续的直播。你给它参考图和提示词，它就向视频模型一段接一段地请求短片段，每段从上一段的结尾开始，并把片段首尾相接地播放出来。可以用它做一个始终在线的角色、一个循环的场景，或者快速试一个模型。

::: tip 提示
直播生成从 v1.0.29 起可用。导演模式、文生视频选项和会话菜单在 v1.0.30 加入，本地 ComfyUI 渠道在 v1.0.35 加入。
:::

## 开始之前 {#before-you-start}
- 在 **⚙️ → 生成模型 → 视频模型 → Fal** 里配好 Fal API Key。直播页使用同一个 Key 和同一份模型列表。见[视频模型](/zh/videoagents/models/video-models)。
- 或者在同一页配好 ComfyUI 服务器，用于 **本地 ComfyUI** 渠道。见 [ComfyUI](/zh/videoagents/models/comfyui)。

::: warning 注意
直播运行期间会一段一段地持续计费，直到你停止。每段通常需要 1–3 分钟生成。
:::

## 打开页面 {#open-the-page}

选择 **⚙️ → 高级 → 直播**。**🎛 输入** 卡片标题下方的一行会说明是否已配置 Fal Key。

![直播页：左侧是输入卡片，包括参考图、提示词、渠道、模型、画幅和单段时长；右侧是空的直播画面](/images/videoagents/create/live.webp)

## 开始直播 {#start-a-stream}

1. 在 **🖼 参考图** 下添加最多 8 张图（PNG、JPG 或 WebP；可多选或拖入）：人物、场景、风格。每一轮它们都会和上一段的尾帧一起发送，以保持人物一致。
2. 在 **✍️ 提示词** 里描述画面主体、动作和氛围。不要写秒数和分辨率。
3. 选择 **渠道**（**Fal** 或 **本地 ComfyUI**）和 **模型**。模型下方的说明列出它接受什么，例如能带几张参考图、支持哪些单段时长。
4. 选择 **画幅**（16:9 横屏或 9:16 竖屏）和以秒为单位的 **单段时长**。片段越长，重播越少，但每段要等得更久。
5. 需要的话，展开 **高级选项**（见下文）。
6. 点 **▶ 启动**。按钮会变成 **⏹ 停止**。

直播运行期间参考图是锁定的，停止后才能修改。提示词随时可以改：点 **✏️ 更新提示词(下一段生效)**。

使用 **本地 ComfyUI** 时，直播只用文字：必须填提示词，不使用参考图，连贯性只能靠提示词。

## 高级选项 {#advanced-options}

![直播页的高级选项：衔接模式、分辨率、待播上限、最多段数、无人观看和生成音频](/images/videoagents/create/live-advanced.webp)

| 选项 | 作用 |
| --- | --- |
| **衔接模式** | 片段怎样衔接：**参考图 + 尾帧一起作参考(默认)**；**尾帧作首帧**（不带参考图；衔接更平滑，但人物容易漂移）；**不衔接**（每段只按提示词生成）；**导演模式**（见下文） |
| **分辨率** | 480p（默认）或 768p；768p 更清晰，但更慢也更贵。Seedance 和 Wan 按 720p 发送；Kling 没有分辨率设置 |
| **待播上限** | 等待播放的片段达到这个数量时暂停生成，播掉一段后继续（1–10，默认 3） |
| **最多段数** | 生成这么多段后停止。0 表示不限 |
| **无人观看** | 连续这么多分钟没人打开本页时自动停止（默认 10）。0 表示从不自动停止 |
| **生成音频** | Seedance、Kling 和 Wan 可以不带声音生成。MiniMax H3 总是随画面生成声音 |
| **从上次直播的尾帧继续** | 有可以接着往下做的上一次会话时才显示 |

**衔接模式** 的可选项跟随所选模型。Kling 3.0 和 MiniMax H3 Max Turbo 不接受参考图：第一轮用第一张参考图作起始帧，之后每一轮都从上一段的尾帧开始。

## 观看直播 {#watch-the-stream}

第一段生成好后，**📺 直播画面** 就开始播放。片段按顺序播放。下一段还没好时，重播最新的一段；新片段会在当前片段播完后接上，不会打断它。生成通常比播放慢，所以有些重播是正常的；片段越长，重播越少。停止后，所有片段循环播放。

如果浏览器以静音方式开始播放，点 **🔇 静音中,点击开启声音**。**⏭ 最新** 跳到最新的片段。

## 导演模式 {#director-mode}

把 **衔接模式** 设为 **导演模式** 后，页面使用 Fal 上的实时接口 MiniMax H3 Max Director。它不是生成完整片段再播放，而是把视频和声音以大约 10 秒一块的方式持续推流到页面里。

- **✏️ 更新提示词(立即生效)** 立刻改变正在生成的内容。
- **记忆段数** 设置模型保留最近多少段提示词作为上下文（1–50，默认 12）。
- 第一张参考图用作首帧。单段时长、待播上限和最多段数不适用。
- Fal 对导演模式按秒计费，最少 60 秒；除非 Fal 批准更长时间，每次会话最长 2 分钟。关闭页面即结束会话。
- 页面会录下直播，以后可以回放这次会话，或从它的尾帧继续。

导演模式需要支持 WebRTC 的浏览器，以及允许 UDP 的网络。

## 对口型直播 {#lip-sync-streams}

选择 **MiniMax H3 Max Lip Sync** 时，提示词框会变成 **💬 台词**：人物要说的话。台词按句切分成大约一个单段时长（5–13 秒）的块。每一块都用生成模型页上的 TTS 设置和默认音色说出来，由语音驱动人物图的口型。台词说完后，直播会等待。**✏️ 更新台词** 会接着说你在末尾新加的文字；整段重写的台词则从头开始。

## 会话与文件 {#sessions-and-files}

顶栏的 **📚 会话** 菜单里有：

- **➕ 新建会话**：清空画面，重置提示词和设置，并移除参考图。之前的会话会保留。
- **📚 历史会话**：列出之前的会话，以及它们的尾帧、模型、设置、片段数和大小。加载一个会话可以回放它，或从它的尾帧继续，还可以选择恢复它的提示词、模型设置和参考图。也可以在这里删除会话。直播运行期间不能加载或删除。

**📂 打开文件夹** 打开直播数据文件夹，即 VideoAgents 数据文件夹里的 `data/live/`。**🗑 清理历史片段** 删除所有已停止会话的片段和尾帧，释放磁盘空间。

## 几点说明 {#good-to-know}
- 它不是实时的：每段要几分钟才能生成，所以直播靠重播来衔接。
- 从低分辨率尾帧一轮轮续接，经过很多轮后，画质和人物相似度会慢慢下降，接缝处的声音或画面也可能跳一下。
- 连续多次失败后，生成会退避并停止。点 **⏹ 停止** 也会取消 Fal 上正在进行的请求。
