# 分镜预览

**🎦 分镜预览** 页按视频模型接收的样子展示一集：镜头打包成生成组，每组带参考图、提示词、设置和生成好的组视频。你在这里检查一个组是否可以生成，为本集的视频提示词签字，并对需要修改的地方发注释。

## 开始之前 {#before-you-start}
- 这一集需要有定稿的分镜表。导演阶段产出分镜表之前，页面会提示本集还没有分镜。
- 流水线推进到哪一步，组才会有对应的提示词、参考图和视频。一集刚开始时只看到镜头和组；之后同样的卡片会逐渐填上图片和视频。

## 打开页面 {#open-the-page}

在控制台顶栏点 **🎦 分镜预览** 图标，或在任意预览页右上角的页面菜单里选 **🎦 分镜预览**。在分集按钮行里选一集（超过 12 集时改为下拉菜单）。

**📜 剧本预览** 和 **📋 故事板** 页上的链接会在本页打开对应的场次、镜头或组。

![ep01 分镜预览页顶部：分集按钮、本集概况、过场栏、白模样片和对白语音板块](/images/videoagents/create/storyboard-preview.webp)

## 页面内容 {#what-the-page-shows}

### 顶栏 {#the-top-bar}

**🎬** 下拉菜单显示本集使用的视频渠道、视频模型和提示词技能，默认都标为 **跟随全局**。在这里修改只影响本集。三个层级（项目、集、组）怎样组合，见[视频提示词与提示词技能](/zh/videoagents/create/video-prompts)。

### 本集概况 {#the-episode-summary}

标题下方显示镜头数和生成组数、总时长，以及进度计数：关键帧、逐镜视频、锚点包和组视频（例如 **已出组视频 5/37**）。

再往下是针对整集的板块：

| 板块 | 用途 | 详见 |
| --- | --- | --- |
| **⟿ 过场** 和 **⏹ 集尾** | 本集的过场模式、组边界数量和结尾方式（淡出到黑、切黑等） | [过场](/zh/videoagents/create/transitions) |
| **🧊 白模样片** | 用 3D 白模摄像机渲染的整集，带字幕 | [3D 白模预演](/zh/videoagents/create/whitebox-previs) |
| **🗣 对白语音** | 逐句的语音库和逐句指导 | [对白、音色与旁白](/zh/videoagents/create/dialogue) |
| **🎵** 配乐提示 | 没能放到某个镜头上的 BGM 提示列在顶部，按提示表顺序排列 | [配乐与音效](/zh/videoagents/create/music-and-sound) |

白模相关的板块只在项目开启白模时出现。对白语音板块只在 **🎛️ → 输出设置** 里开启 **生成对白语音** 或声画分离时出现。

### 场次和组 {#scenes-and-groups}

主栏按顺序贯穿整集。每场以一个标题开头（场号、内景或外景、镜头数和组数、时长），附导演的节拍说明。出现不止一次的场次（例如穿插闪回时）会拆成编号的几段，让组保持播放顺序。

右侧导航栏列出 **📑 场次 / 分镜组**。点一个组跳过去，点小箭头展开它的镜头，或点 **展开分镜** 全部展开。徽标显示组里有什么：🖼 参考图、🎨 草图、📝 注释、💬 对白、🎙 旁白、🎵 配乐提示和 🎬 组视频。

场次、组或镜头编号旁的 **⧉** 按钮复制编号，方便你粘贴到对话消息里。

## 生成组 {#generation-groups}

生成组是同一场里相邻的一串镜头，视频模型一次调用把它们做成一段多镜头视频。组视频是生成、检查、剪辑和版本管理的单位；组内各镜头的时长描述的是预期节奏，具体切点由模型决定。

- 一个组的总时长上限由 **🎛️ → 模型限制** 里的 **最大分镜组时长（秒）** 决定（默认 15 秒，即 Seedance 2.0 的上限；Seedance 2.5 最多 30 秒）。同一个对话框还限制每组参考图、参考视频和参考音频的数量。见[模型限制](/zh/videoagents/console/model-limits)。
- 由许多很短的镜头组成的组会控制在 15 秒以内，让模型跟得上切换。
- 组视频保存为 `assets/clips/<ep>/<group>.mp4`，每组的提示词保存为 `assets/prompts/<ep>/<group>.json`。

![一张生成组卡片：标题栏按钮、人物和服装标签、光照行、两张参考图和生成好的组视频](/images/videoagents/create/storyboard-preview-group.webp)

### 组卡片 {#the-group-card}

标题行显示组编号、包含的镜头和总时长（**Σ**），以及以下标签：

- **声音**：**💬 对白**（有人在画面里说话）、**👻 后期人声**（只有旁白或画外台词，后期再加）或 **🔇 无对白**。
- **叙事段落**：例如 **⏱ 闪回 · 单组**。
- **入场过场**：不是硬切的入场方式，例如 **⟿ 强调硬切 · 出闪回**。
- **组链**：**◦ 组链起点**、**⛓ 续接 grp004 尾帧** 或 **✂ 硬切自 grp001（不传尾帧）**。见[长镜头与连续性](/zh/videoagents/create/long-takes)。
- **🎛**：只在这个组单独设置了视频模型或提示词技能时显示。

接着是按钮：

| 按钮 | 作用 |
| --- | --- |
| **🎛 模型** | 只为这个组选视频渠道、模型和提示词技能 |
| **📄 提示词** | 查看、复制或编辑发给视频模型的文字提示词 |
| **🖼 图片** | 从人物、场景、道具、生物、故事板草图、手机手绘或上传的文件里添加参考图 |
| **🎬 视频** | 列出、播放、上传或删除参考视频，并核对是否超过模型的上限 |
| **✨ 花字** | 查看为这个组设计的屏幕文字（只读） |
| **✏️ 修改** | 把这个组的修改请求发给修改师 |
| **📝 注释** | 写一条导演注释，加进这个组的提示词 |
| **🔞** | 只在开启 NSFW 模式时出现：标记这个组，让它的图片和视频使用备用模型。见[NSFW 模式](/zh/videoagents/models/nsfw-mode) |

标题行下面：

- **人物**：每个人物带一个彩色圆点（和他们在白模视频里人形的颜色相同），服装标签（**👕 Alice: Blue summer frock…**）链接到人物页上的那套服装，以及生物标签。
- **💡 光照**：时段、光照方案、方向、色温和软硬。
- **🖼 参考图**：传给模型的所有内容，按提示词里的顺序排列。鼠标悬停在说明上可以看到它的 `[Image N]` 编号。取自人物、场景、道具或生物页的图片会链接回去。**⏳ 待前组出片** 占位块代表一张还不存在的尾帧。
- **🎬 组视频**：生成的视频，下方是 **✂ 切变边界**（检测到的镜头切点）。有花字版时，显示花字版而不是原片。

组的参考图或参考视频超过模型接受的数量时，会出现黄色警告。用 **🎛 模型** 换一个上限更高的模型（例如 Seedance 2.5），或删掉一些参考，然后重新生成这个组。

### 镜头卡片 {#shot-cards}

组里的每个镜头显示时长、景别和出场人物、镜头描述、🧍 姿态、📷 机位和 🎥 运镜。点运镜那一行可以展开或收起首帧和尾帧描述。开启白模时，每个镜头还显示它的分镜背景图（**🔁 换图**、**✏️ 修改**，见[分镜背景图](/zh/videoagents/create/background-plates)），组的 3D 白模在右侧面板里播放。

旁白（🎙）出现在它开始的镜头上，附预估时长；配乐提示（🎵）出现在它进入的镜头上，音频生成后附播放器。

## 为视频提示词签字 {#sign-off-the-video-prompts}

一集里每个组都有了视频提示词后，总制片会创建一张签字卡。你签字之前，这一集什么都不会生成（没有锚点包，也没有组视频）。

1. 用 **📄 提示词** 读每个组的提示词，用 **🖼 图片** 和 **🎬 视频** 检查参考。
2. 在分集行右侧点 **✅ 签字确认**，或点 **⏸ 暂缓** 先等等。它和控制台里是同一张卡，所以你也可以在控制台或飞书里答复。
3. 签字后，这一行显示 **视频提示词已签字** 和日期。

只要还有组没有提示词，签字就会被拒绝。之后改写单个组（你的编辑、修改师、缺陷修复）不需要重新签字；这一行只显示签字后有多少个组改过。

::: tip 提示
签字标签只出现在工作流包含这一步的集里。这一步引入（v1.0.38）之前就已经开始生成视频的集不会被拦下。
:::

## 发送注释和修改请求 {#send-notes-and-change-requests}

有两种方式提出修改：

- **📝 注释** 为这个组保存一句简短的导演意图（例如「整组放慢；钱包始终在左下角」）。它以 Director's note 的形式加进这个组的提示词，重新生成这个组时生效。保存空注释就是删除它。注释保存在 `assets/notes/<ep>/`。
- **✏️ 修改**（在组、镜头、参考图、组视频、旁白、配乐提示或过场上）会打开发给修改师的消息框，已填好这一项的位置。写下要改什么，然后发送。

要一次交出所有注释，点分集行右侧的 **📨 提交注释**。本集所有组的注释连同场次、镜头和时间信息，作为一张修改单发给修改师，注释随后清空。见[修改师与修改意见](/zh/videoagents/concepts/reviser)。

## 几点说明 {#good-to-know}
- 页面按项目记住你看的集和滚动位置，刷新后回到同一张卡片。
- 顶部的渠道、模型和技能下拉菜单只改当前这一集。组自己的 **🎛 模型** 设置优先于集的设置。
- 你添加的参考图和参考视频在下次生成这个组时使用。修改它们不会自动重新生成任何东西。
