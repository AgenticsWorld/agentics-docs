# 视频提示词与提示词技能

每个生成组发给视频模型的，是一段提示词，加上它的参考图、参考视频和参考音频。本页说明提示词里有什么、提示词技能怎样按你用的模型调整它，以及在哪里查看、修改或覆盖它。

## 开始之前 {#before-you-start}
- 这一集的分镜表已经签字（H3A 签字点）。提示词在签字之后才写。
- 你知道项目用的是哪个视频模型。它在 **⚙️ → 生成模型** 页设置，也可以按集或按组单独更换。见[视频模型](/zh/videoagents/models/video-models)。

## 谁来写提示词 {#who-writes-the-prompt}

**Prompt 工程师** 为每个生成组写一段提示词。它汇总这一组的镜头设计（构图、机位、走位）、世界圣经（美术风格、人物外观、场景、光线）、连戏记录、对白台词，以及声音工位写好的声音提示，按模型自己的结构写成一段多镜头提示词：先是全局部分（风格、光线、氛围、出场人物），然后每个镜头一节（机位、动作和表情、位置、声音）。

每组的提示词保存为 `assets/prompts/<ep>/<group>.json`。除了正文（`video_prompt`），里面还有随提示词一起发送的素材清单：

| 字段 | 内容 | 提示词里怎么引用 |
| --- | --- | --- |
| `refs` | 参考图：人物设定图、服装设定图、场景图、道具、生物 | 按清单顺序写作 `[Image 1]`、`[Image 2]`… |
| `video_refs` | 参考视频，例如本组的白模运镜视频或上一组的结尾 | `[Video 1]`… |
| `audio_refs` | 本组里说话的人物的声音样本 | `[Audio 1]`… |
| `negative` | 模型必须避免的内容 | — |

台词写在 `{ }` 花括号里，模型会把语音和画面一起生成。见[对白、配音与旁白](/zh/videoagents/create/dialogue)。

## 提示词技能 {#prompt-skills}

提示词技能是某个视频模型的官方提示词写法指南。Prompt 工程师写组提示词时必须套用它。

| 技能 | 模型 |
| --- | --- |
| `sd25-pe` | Seedance 2.5 |
| `sd20-pe` | Seedance 2.0 系列 |
| `h3-pe` | MiniMax H3 |
| `wan3-pe` | Wan 3.0 |
| `kling4-pe` | Kling 4.0（Fal） |

另有两个技能不绑定模型：

- **fight-choreography**（武打编排）只用于真正有人交手的组：把分镜表里的打斗写成清楚的「出招、接触、反应」链条。
- **performance-direction**（表演控制）把导演的表演说明写成对白组和情绪高潮处看得见的面部与肢体细节。它默认关闭，在 **🎛️ → 项目技能** 里开启。见[项目技能](/zh/videoagents/console/project-skills)。

在 **项目技能** 里，默认只开启与视频模型对应的提示词技能。你手动改过的设置会保留；没改过的技能继续跟随视频模型。

### 选择提示词技能 {#choose-the-prompt-skill}

技能分三级设置，下级优先于上级。

| 级别 | 位置 | 选项 |
| --- | --- | --- |
| 项目 | **🎛️ → 模型限制 → 提示词技能** | **自动**（按真正跑视频生成的模型解析）、手选一个技能，或跳过 |
| 集 | **🎦 分镜预览** 顶栏的 **🧰** 下拉框 | **跟随全局**、**自动 → 按本集模型**、**手选 →** 某个技能、**跳过** |
| 组 | 组卡上的 **🎛 模型** | **跟随全局**、**自动(按本组视频模型解析)**、某个技能、**跳过(不套用技能)** |

给一集的分镜表签字（H3A）时，签字卡片会再次显示项目的提示词技能。签字后，项目的这项设定就冻结了。

![grp002 的「组视频模型」对话框：视频渠道、视频模型和提示词技能都跟随全局设置，下方显示生效的模型、参考图上限和技能](/images/videoagents/create/video-prompts-group-model.webp)

在控制台的运行面板里，提示词运行会显示一个 **🧰** 标签，写着这次用的技能。标签上出现红色 **✗**，表示这次运行没有读取技能文件，机检会把这次运行退回。

## 提示词里的镜头时间 {#shot-timing-in-the-prompt}

组的总时长另外传给模型。在提示词里，每个镜头一节是否带时间，取决于模型支持什么：

| 模型 | 提示词里写的时间 |
| --- | --- |
| Seedance 2.5、Wan 3.0、Kling 4.0（Fal） | 整秒分段，例如 `Shot 1: 0-2s:`。很短的镜头合并成一段，例如 `Shot 5: 8-10s (Shot 5–Shot 8):` |
| MiniMax H3 | 从第二个镜头起写切换时间，例如 `[Shot 2] At 00:06.000,` |
| Seedance 2.0 | 不写时间。它的指南说精确时间不可靠，所以任何时间标注都会去掉 |

如果把某一集或某一组换到别的模型，更新提示词时会按新模型重写时间。

## 查看和修改提示词 {#read-and-edit-a-prompt}

1. 在 **🎦 分镜预览** 里找到这个组，点 **📄 提示词**。
2. 对话框显示提示词正文、大小、字数，以及随它发送的参考图、音频和参考视频数量。
3. 点 **复制** 复制正文，或点 **编辑** 修改。按钮会变成 **保存**，点它保存你的版本。提示词不能为空。

你的修改在这个组下次生成时生效。要改参考素材，用同一张组卡上的 **🖼 图片** 和 **🎬 视频**。

::: warning 注意
提示词里有些句子由 VideoAgents 自己写入并保持更新，例如长镜头续接、转场处的成对运镜、对白的原生引入和场景衔接。相关设置一改，这些句子就会重写。手动修改时请保留它们。
:::

如果你更想描述改动而不是自己动手改，用 **📝 注释**（在提示词里加一句 Director's note）或 **✏️ 修改**（让修改师重做这个组）。见[分镜预览](/zh/videoagents/create/storyboard-preview#send-notes-and-change-requests)。

## 签字确认一集的提示词 {#sign-off-the-episode-s-prompts}

一集所有组的提示词都写好后，你会收到 **视频提示词签字**（H3V）。签字之前，这一集不会生成任何内容。怎么审阅和签字，见[分镜预览](/zh/videoagents/create/storyboard-preview#sign-off-the-video-prompts)。

## 为单个组换模型 {#override-the-model-for-one-group}

1. 点组卡上的 **🎛 模型**。
2. 选择 **视频渠道**（要先在生成模型页配好 Key）、**视频模型** 和 **提示词技能**。每项默认跟随本集或全局设置。
3. 底部一行显示生效的模型、它的参考图上限和技能。
4. 点 **保存**。重新生成这个组的提示词和视频时生效。

常见的原因是某个组的参考图多于模型能接受的数量：Seedance 2.0 最多 9 张，Seedance 2.5 最多 30 张。单独设置过的组，组头会显示一个 **🎛** 标签。
