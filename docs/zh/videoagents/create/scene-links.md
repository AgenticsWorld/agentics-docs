# 场间衔接

场间衔接把上一场的最后一个画面或声音，和下一场的第一个画面或声音配成一对，让两场之间的剪切是设计好的，而不是临时凑的：同一形状的匹配剪辑，人物从画面右侧跑出、再从左侧跑进，一个声音变成另一个声音。编剧在剧本里起草衔接，导演决定用不用，系统再把导演的决定带进分镜表和两个生成组的提示词。

::: tip 提示
v1.0.39 起可用。场间衔接在所有项目里都能用，没有开关。没写衔接的剧本和以前完全一样。
:::

## 为什么衔接从剧本开始 {#why-links-start-in-the-screenplay}

匹配剪辑的两端是上一场的结尾和下一场的开头，而这两端是什么由剧本决定。等到画故事板时，两端的内容已经定了，只能硬凑。所以剧本改编 Agent 在写剧本时就起草这一对，之后再由导演裁定。

| 谁 | 决定 | 不决定 |
| --- | --- | --- |
| 编剧 | 衔接什么：本场最后的画面或声音、下一场最初的画面或声音，以及衔接的类型 | 镜头长度、景别、镜头焦段、叠化或黑场、字卡、声桥 |
| 导演 | 用不用、变成哪种转场、两侧镜头怎样取景才能接上 | 两端的新内容 |
| 系统 | 把采纳的衔接登记进分镜表，并在两侧组的提示词里各写一句对应的句子 | 两端的内容，以及导演的裁定 |

## 七种类型 {#the-seven-kinds}

| 类型 | 两端必须呈现 | 转场词 | 导演采纳后的默认结果 |
| --- | --- | --- | --- |
| **形状匹配**（试验） | 两个形状相同的物体，处在画面同一位置 | `MATCH CUT TO` | 匹配剪辑 |
| **动作匹配**（试验） | 一个动作在本场开始、在下一场完成 | `MATCH CUT TO` | 匹配剪辑 |
| **同机位** | 同一地点、同一取景，只有一处变化，例如时间流逝 | `MATCH CUT TO` | 匹配剪辑 |
| **运动接力** | 出画方向等于入画方向 | `CUT TO` | 硬切 |
| **声音接力** | 本场的一个声音变成下一场的一个声音 | `CUT TO` | 硬切 |
| **台词接力** | 最后一句台词问到或提到的东西，由下一场第一个画面回答 | `CUT TO` | 硬切 |
| **反差硬切** | 强烈反差：由静到闹、由明到暗 | `SMASH CUT TO` | 强调硬切 |

两种 **试验** 类型要求两个画面逐帧对齐。视频模型根据文字分别生成两段视频，所以对齐没有保证。下游只把它们当作标注：对不上不会记为缺陷，一集里试验类衔接超过两个会给出警告。其余五种可以用流水线现有的手段实现（白模机位检查、运镜方向、音效提示，以及下一场第一个镜头的内容）。

## 衔接在流水线里怎么传递 {#how-a-link-travels-through-the-pipeline}

1. **剧本。** 默认每场以普通的 `CUT TO` 结尾。只有同时满足三个条件时，编剧才加衔接：两端确实写在场次正文里（本场最后的动作、台词或声音，以及下一场最初的），两端有明确的共同元素且符合七种类型之一，并且衔接的是按顺序的下一场。一集的最后一场永远没有衔接。
2. **剧本预览。** 场次末尾的转场块会显示衔接，见下文。
3. **导演计划。** 导演 Agent 把每条衔接列进计划的转场清单，逐条采纳、修改或弃用。采纳和修改要写明变成哪种转场（硬切、匹配剪辑、强调硬切或叠化；不能是淡出或切黑）；修改和弃用要写明理由。有衔接没有裁定，检查会判计划不通过。你可以在[故事板](/zh/videoagents/create/storyboard)页的 **🎬 导演计划** 里读到计划。
4. **故事板和分镜表。** 对于采纳或修改的衔接，故事板把转场设在下一场第一个组的入口，并让上一场最后一个镜头和下一场第一个镜头的取景接得上。检查会确认这个边界带的是导演选定的转场。
5. **过场设计和提示词。** 系统在这个边界上登记衔接，并在两侧的提示词里各加一句 `【场间衔接】` 句：要求前一组的最后一个镜头落在「出」的画面或声音上，后一组的第一个镜头从「入」的画面或声音开始。每种类型有自己的一对句子。每句只描述自己这个镜头，因为两段视频分开生成，互相看不到。形状匹配时，两侧都要求物体处在画面里相同的固定位置和大小。

根据本集的过场模式，衔接还可能带上一个手法：

| 衔接 | 手法 | 电影感 | 经典 / 自定义 | 极简 |
| --- | --- | --- | --- | --- |
| 运动接力 | 沿出画方向的成对运镜 | 自动加上；开启白模时只作为候选提供，因为运镜由白模视频决定 | 作为候选提供 | — |
| 声音接力、台词接力 | 下一场的声音先进来的声桥（J-cut） | 自动加上 | 作为候选提供 | — |
| 形状、动作、同机位、反差 | 无 | — | — | — |

过场模式和过场卡片见[过场](/zh/videoagents/create/transitions)。

## 在剧本预览里查看衔接 {#see-a-link-in-script-preview}

打开[剧本预览](/zh/videoagents/create/screenplay)，滚到这一场的末尾。左栏只显示转场词；右栏显示 **🔗** 加类型、**本场结尾** 和 **下一场开头**。试验类型带 **试验** 标签。

![剧本预览里的转场块：左侧是 CUT TO S020；右侧是「运动接力」标签，「本场结尾」是女孩提着肥皂桶从画面右侧跑出，「下一场开头」是她从画面左侧跑进](/images/videoagents/create/scene-links-script.webp)

在[分镜预览](/zh/videoagents/create/storyboard-preview)页，这个边界的过场卡片把衔接显示为 **🔗 剧本衔接**，附类型和导演的裁定（**导演采纳**、**导演修改** 或 **导演弃用**）；来自剧本衔接的设计带 **📜 剧本衔接** 标签。

## 添加、修改或删除衔接 {#add-change-or-remove-a-link}

- **找编剧改。** 在剧本预览的转场块上点 **✏️ 修改**，描述你想要（或想去掉）的衔接。它会发给剧本改编 Agent。
- **在剪辑点上覆盖。** 在分镜预览的过场卡片上另选一个候选，或保持硬切。以你的选择为准：系统不再为这个边界登记衔接。
- **手动编辑剧本。** 把衔接用花括号写在这一场最后一行转场的末尾：

  ```markdown
  TRANSITION: MATCH CUT TO S04 {link: shape, out: the sigil flares into a ring, in: the same glowing sigil on the gate}
  ```

  键名是 `link`、`out` 和 `in`（中文键名 `衔接`、`出`、`入` 也可以）。`link` 取 `shape`、`action`、`position`、`motion`、`sound`、`line` 或 `contrast` 之一。转场词后面如果写了场号，必须是下一场。

以下情况剧本检查判衔接不通过：类型未知，缺 `out` 或 `in`，最后一场带衔接，衔接到的不是下一场，花括号没写在这一场的最后一行转场上，没有台词的场次用了台词接力，写了 `MATCH CUT` / `SMASH CUT` 却没有花括号。以下情况给出警告：`out` 或 `in` 的文字在场次里找不到，接力配了淡出或黑场，衔接覆盖了一集一半以上的场次边界。场间衔接功能出现之前写的剧本只会收到警告。

如果导演弃用了衔接，或编剧删掉了它，下一次过场设计运行时会撤销登记，下一次同步提示词时两侧的句子也会去掉。
