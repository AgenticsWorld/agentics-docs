# NSFW 模式

很多服务商会拒绝成人向内容，例如裸露或血腥暴力，即使剧情确实需要。NSFW 模式让你为这类场景指定备用模型。被标记的工作直接交给备用模型，主服务商因内容拒收时，也可以自动切换到备用模型。

NSFW 模式只决定用哪套模型。它不会放宽内容安全审核、平台分级检查，也不会绕过任何服务商自己的规则。

## 打开 NSFW 模式 {#open-nsfw-mode}

打开 **⚙️ → 高级 → NSFW 模式**。这个对话框里的设置一改就保存。

![NSFW 模式对话框，包含启用开关、说明和备用模型菜单](/images/videoagents/models/nsfw-mode-dialog.webp)

## 设置 {#set-it-up}

1. 勾选 **启用 NSFW 模式**。旁边的状态不再显示 **已关闭:全部按主模型执行**。
2. 为需要的每类模型设置备用：

   | 行 | 第一个菜单 | 第二个菜单 |
   | --- | --- | --- |
   | **语言模型** | 引擎 | 模型，或 **引擎默认** |
   | **图像模型** | 服务商 | 模型，或 **该渠道默认模型**；ComfyUI 则选运行方式 |
   | **视频模型** | 服务商 | 模型，或 **该渠道默认模型**；ComfyUI 则选运行方式 |

   某一行保持 **不设置**，这一类就继续用主模型。
3. 如果希望被拒收的请求改用备用服务商重试，保持勾选 **审核拒收后自动切换**。

只有已在生成模型页配好 Key 的服务商可以选；其他的显示为灰色，并标注 **(未配 Key)**（Agentics 标注 **(未登录)**）。Agentics 和 RH 作为备用图像服务商时，用的是生成模型页上设定的模型。

## 工作怎样分流 {#how-work-is-routed}

1. **标记优先。** 拆解剧本时，每个事件都会标上内容标记（裸露、性、血腥、极端暴力、毒品、自残）。镜头规划会把包含这些事件的生成组标为 NSFW。你也可以在分镜预览页点组卡片上的 🔞 按钮，手动标记一个组。被标记组的工作从一开始就用备用语言模型，它的图片和视频也用备用服务商。
2. **拒收兜底。** 如果开启了 **审核拒收后自动切换**，而主图像或视频服务商因内容拒收了某个请求，同一个请求会改发给备用服务商一次。这不计入重跑次数。之后这个组会被标为 NSFW，后续尝试直接走备用服务商。
3. **语言模型拒绝。** 语言模型拒绝时，不会在运行中途切换。VideoAgents 记下这次拒绝，下次派发同一个任务时改用备用语言模型。

如果设置了备用服务商却用不了（例如它的 Key 被删了），任务会失败，并请你决定怎么处理。它绝不会改用主模型运行。

如果某个组的文字看起来敏感，但组没有被标记，分镜预览会在它上面显示黄色提示。提示本身不会改变分流；要标记，点 🔞。

## 用审核模型识别拒绝 {#detect-refusals-with-a-moderation-model}

默认情况下，语言模型的拒绝只按套话识别，例如「无法协助」或「违反内容政策」。**拒绝判定用审核模型** 可以识别换了说法的拒绝。

开启后，只有正常结束、回复较短、又没有交付产物的运行（没有写任何文件的工单，或没有提交提示词的画板修图任务），才会把最后一条回复交给审核模型判断一次。只发送回复的结尾部分，绝不发送你的请求或图片。每次判断都要计费，用 Jev 约 $0.00003。

没有设置审核模型之前，这个开关无法打开。开关旁边的一行会显示当前使用的模型。

### 设置审核模型 {#set-up-the-moderation-model}

在 **⚙️ → 生成模型** 里找到 **🛡 审核模型** 卡片。

![审核模型卡片，当前打开 OpenRouter 标签页](/images/videoagents/models/nsfw-mode-moderation.webp)

| 标签页 | 需要填写 |
| --- | --- |
| **Agentics**（默认） | 不用填；使用已登录的桌面端账号 |
| **OpenRouter** | **API Key** |

选择 **模型**：Jev 1.14（默认）或 Jev 1.13，都是 TypeSafe 的决策模型。点 **测试** 判断一条拒绝样例（计费，约 $0.00003）。结果应当显示这条样例被判定为政策拒绝（policy）。

## 画板编辑 {#canvas-edits}

NSFW 模式开启时，画板工具栏会出现 **🔞 NSFW** 按钮。对某张图片打开它后，这张图的编辑和放大都会交给备用图像模型；这个选择按图片保存在你的浏览器里。打开它还会让编辑直接发给图像模型，不经过画板修图师。参见[画板：编辑图片](/zh/videoagents/world/image-canvas)。

## 几点说明 {#good-to-know}
- 用了备用模型的片段会在它的 `.meta.json` 里记录下来。
- NSFW 模式是全局设置，对所有项目生效。
