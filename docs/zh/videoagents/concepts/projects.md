# 项目与项目目录

一个项目就是一个世界和在其中创作的作品，以一个目录的形式保存在你的电脑上。团队为这个项目做出的一切，从小说到成片，都是这个目录里的文件。

## 控制台里的项目 {#a-project-in-the-console}

你正在处理的项目，就是控制台顶栏 **项目** 旁边显示的那个。点它会打开 **项目** 对话框，可以在这里切换项目、新建项目，或者从 zip 导入项目。

![项目对话框：上方是导入项目和新建项目，下面的项目列表显示类型、自动运行、运行中的 Agent、备份和磁盘占用](/images/videoagents/getting-started/open-a-sample-project-dialog.webp)

每个项目都有自己的：

- **类型**，新建时选定，之后不能更改。见[选择项目类型](/zh/videoagents/project-types/choose-a-project-type)。
- **Agent 对话。** 每个 Agent 在每个项目里都有单独的对话记录。
- **设置**，在 **🎛️** 项目设置菜单里。
- **自动运行开关**（运行面板里的 **🤖**）。
- **工作流**，有自己的任务和签字。

**⚙️** 菜单里的设置，例如生成模型、插件和界面语言，对所有项目生效。

| 🎛️ 项目设置（仅当前项目） | ⚙️ 全局设置（所有项目） |
| --- | --- |
| 版本管理、创作定调、视频节奏、输出设置、模型限制、项目技能、审核设置、音乐库、缺陷单 | 生成模型、存储与图库、自动运行、资源消耗、插件、高级、界面语言、账号（桌面应用） |

## 目录在哪里 {#where-the-folder-is}

- **桌面应用：** 在应用自己的数据目录里。
- **从源码运行：** 在仓库内的 `data/projects/<project name>/`。

最快的打开方式是点控制台顶栏的文件夹按钮，它会在访达（Finder）或资源管理器里打开当前项目的目录。

## 目录里有什么 {#what-is-in-the-folder}

| 目录或文件 | 内容 |
| --- | --- |
| `novel/` | 原文，分成按章节的文件 |
| `refs/` | 你的参考素材：风格、人物、场景、生物和道具图片，3D 模型、音乐、视频、封面示例、字体、文本和其他文件，你的注释在 `NOTES.md` 里 |
| `brief.md` | 你的创作定调：内容定位、画面风格和叙事节奏 |
| `settings.json` | 🎛️ 菜单里的项目设置 |
| `story/` | 结构化的故事、事件、时间线、拆集规划，以及每集的剧本、对白、旁白、钩子、节奏和剧本拆解 |
| `bible/` | 世界圣经：世界、时间线、地理、文化、人物、生物、场景、道具、服装、风格、色彩剧本和变更日志 |
| `directing/` | 每集的导演方案、故事板、分镜表、连续性方案，以及每个镜头的运镜、构图和人物调度 |
| `assets/` | 生成的媒体及其记录：概念图、提示词、关键帧、组视频、草图、画板版本、配音、音乐和音效 |
| `edit/` | 每集的时间线、粗剪、字幕、花字、片头片尾、封面和成片 |
| `qa/` | 审核报告和缺陷单 |
| `publish/` | 各平台的发布包、SEO 文案和元数据 |
| `code/` | Agent 为这个项目写的一次性脚本 |
| `runs/` | 工单、评分、日志和工作流状态 |

逐个文件的完整结构见[项目目录](/zh/videoagents/reference/project-folder)。

## 处理这些文件 {#working-with-the-files}

任何文件你都可以打开阅读。有少数文件是供你修改的，而且大多数在控制台里都有对应的页面替你完成：

- **参考素材：** 用 **参考文件** 页，不要手动把文件复制进 `refs/`。它会把文件放进正确的目录，并把你的注释写进 `refs/NOTES.md`，设计和配乐 Agent 会先读这个文件。见[参考文件](/zh/videoagents/world/reference-files)。
- **小说：** 在新建项目向导里粘贴，或者把文本文件放进 `novel/`。
- **创作定调和设置：** 用 **🎛️ → 创作定调** 和其他 🎛️ 对话框。
- **Agent 做出的一切：** 用预览页上的 **✏️ 修改** 按钮提出修改。[修改师](/zh/videoagents/concepts/reviser)会按正确的格式改好并记录下来。
- **工作流：** 在工作流预览页用 **✏️ 修改** 请总制片修改，不要自己编辑 `runs/dag.json`。

Agent 写的每个文件，文件名都只用英文字母、数字、`-`、`_` 和 `.`，因为其他字符会让视频工具和下载链接出错。你自己放进 `novel/` 和 `refs/` 的文件可以随便命名；需要时 Agent 会在使用前重命名。

## 复制、备份和移动 {#copies-backups-and-moving}

| 想要 | 这样做 |
| --- | --- |
| 试点新东西，又不想冒险动原项目 | **🎛️ → 版本管理 → 📋 复制项目**。副本会出现在 **项目** 对话框 **备份** 列里、源项目的下方。 |
| 每次签字都留一份备份 | 在版本管理页打开 **💾 自动备份**。每次签字都会把项目压缩成 zip，存到你选的目录里。 |
| 把项目搬到另一台电脑 | 压缩项目目录，然后在另一台电脑上用 **› 导入项目…**。对话记录不在项目目录里，所以不会跟着一起搬走。 |
| 删除项目 | **🎛️ → 版本管理**。见[复制与删除项目](/zh/videoagents/console/project-versions)。 |

在 Agent 处理项目之前，VideoAgents 还会自动给项目拍快照。见[文件、运行记录与版本](/zh/videoagents/concepts/files-and-runs)。
