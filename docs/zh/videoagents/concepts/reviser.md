# 修改师与修改意见

想改什么东西时，在预览页上指向它，写下你想要的效果。**修改师** 就是接收这些意见的 Agent。它会马上亲自把整个修改做完，用的是负责该对象的那些 Agent 的格式，然后告诉总制片这次修改影响了哪些地方。

## 为什么要有修改师 {#why-a-reviser}

没有修改师时，一条意见要先发给总制片，排在正在运行的流水线后面，变成一张工单，依次交给一个或几个专职 Agent，最后还要评分。一处修改如果牵涉两三个 Agent，就意味着好几次缓慢的交接。

修改师一次就能做完。它不用等总制片，多个修改可以同时进行；而且你的意见就算作你的决定，所以之后不再进行评分或审核。

## 发送修改意见 {#send-a-revision-note}

1. 打开一个预览页，找到要改的对象，例如 **人物预览** 里的某个人物。
2. 点它的 **✏️ 修改** 按钮。
3. 右下角会打开 **✏️ 修改意见** 浮窗。**发给:** 显示谁会收到这条意见，通常是 **修改师**。
4. 写下你想改什么。要保留什么，也请写清楚。
5. 可选：
   - 点 **+** 附加参考文件。文件在你电脑上的路径会加进意见里，让 Agent 能读取；文件不会上传到任何地方。
   - 如果打开了语音输入，可以点麦克风口述。见[语音输入](/zh/videoagents/console/voice-input)。
   - 勾选 **顺带重跑受影响的下游任务**（见[下游会怎样](#what-happens-downstream)）。
6. 按 Enter 或点 **发送**。按 Shift+Enter 换行。

![人物预览中的爱丽丝，右下角打开了修改意见浮窗，发给修改师，意见要求把裙子改成更深的蓝色](/images/videoagents/concepts/reviser-popup.webp)

浮窗显示 **✅ 已发送给 修改师** 后关闭。修改师的回复会出现在控制台里它的对话中，位置是 **00-调度层 → 修改师**。

如果关于同一个对象的任务正在运行，浮窗会提醒你这次修改可能和它冲突。你仍然可以发送。

::: warning 注意
一次修改可能会重新生成图片、配音或视频，这些费用由服务商收取。重新生成按草稿分辨率进行。
:::

## 修改师做什么 {#what-the-reviser-does}

修改师会代替负责你所指对象的那些 Agent。VideoAgents 把这些 Agent 的角色文件交给它，所以它会按它们的格式写，并运行它们的检查。

| 你指向 | 所在页面 | 修改师代替的 Agent |
| --- | --- | --- |
| 一个人物 | 人物预览 | 外观设定、角色概念 |
| 一个声音 | 人物预览 | 声纹设定、配音 |
| 一套服装 | 人物预览 | 服装、服装概念 |
| 一个场景 | 场景预览 | 场景户籍官、场景概念 |
| 一件道具 | 道具预览 | 道具 |
| 一种生物 | 生物预览 | 生物图鉴、生物概念 |
| 世界圣经的一个章节 | 世界观预览 | 世界总览 |
| 整个剧本（标题行） | 剧本预览 | 剧本改编、对白优化 |
| 故事板 | 故事板 | 分镜师 |
| 一个镜头、一个生成组、它的媒体或一张分镜背景图 | 分镜预览 | 视情况为镜头规划、Prompt 工程师、视频生成、图像生成或分镜背景 |
| 花字、旁白、旁白音频或配乐 | 分镜预览 | 花字、旁白转换、旁白或配乐 |

其他对象，修改师会自己判断由哪个 Agent 负责，并按它的角色文件来做。

然后它会：

1. 编辑文件或重新生成媒体。
2. 运行负责该对象的 Agent 的机检。
3. 直接把改动写进世界圣经，并记入 `bible/changelog.md`。
4. 在回复末尾附上变更记录：改了哪些文件、哪些下游任务需要重做、哪些签字因此过期，以及运行了哪些检查。

### 它遵守的规则 {#rules-it-keeps}

- 重新生成人物、场景或道具时，它以现有的概念图和项目的美术风格为锚点，不会另起一个新造型。
- 它按草稿分辨率生成。
- 它不修改工作流，不给其他 Agent 派单，也不切换引擎。
- 对于分镜背景图，它会根据你的意见，以当前这张为基础生成一张新图，只替换这一个镜头的背景图，并保留原图。使用原图的其他镜头不受影响。

## 下游会怎样 {#what-happens-downstream}

一处修改可能让后面的工作过时。VideoAgents 把每次修改记录在 `runs/revisions/` 里，并交给总制片，由它把受影响的任务标记为需要重做。

| **顺带重跑受影响的下游任务** | 会怎样 |
| --- | --- |
| 不勾选（默认） | 受影响的任务只会被标记，暂时不重做。这条记录会在[自动运行](/zh/videoagents/console/auto-run)下一次检查状态时，或者下一条唤醒总制片的消息到来时，交到总制片手里。 |
| 勾选 | 修改师一完成，记录就交给总制片，由它重新派出受影响的任务。 |

如果这次修改让某个签字过期，例如你已经在 H3S 签过字的故事板，你会收到桌面通知，总制片也会发起新的签字卡片。见[签字点](/zh/videoagents/concepts/sign-off-gates#when-a-signed-step-changes)。

## 先记注释，再一起提交 {#collect-notes-and-submit-them-together}

在有些页面上，你可以先记下注释，再一次性全部发送：

- **故事板**：分集、每一场和每个镜头上都有 **🗒 注释** 按钮。
- **分镜预览**：每个生成组上有一个 **📝 注释** 按钮。
- **剧本预览**：每个 **✏️ 修改** 按钮旁边有一个 **🗒 注释** 按钮。

准备好后，点分集行右端的 **📨 提交注释**。这一集的全部注释会作为一次修改发给修改师，并附上每条注释对应的位置。注释发送后会被清空。修改师会逐条处理，并分别汇报。

## 发给别处的按钮 {#buttons-that-go-elsewhere}

不是所有修改按钮都发给修改师。浮窗里的 **发给:** 一行始终显示接收人。

- **工作流预览** 页上的 **✏️ 修改** 发给总制片，由它修改计划。
- **剧本预览** 里各个段落上的 **✏️ 修改** 按钮直接发给负责该段落的 Agent。
- 故事板页的草图重绘、全景图锚点和白模面板，发给各自的专职 Agent。
- **场景预览** 中分镜背景图区域的 **✏️ 修改** 直接发给分镜背景 Agent。

## 几点说明 {#good-to-know}
- 修改师在两次修改之间没有记忆。每次修改都会列出同一对象最近的几条修改记录，让它可以在此基础上继续。
- 它和其他工作同时运行，占用一个普通的工作位，所以不用等流水线。
- 要改修改师改不了的东西，例如任务的顺序，请在总制片的对话里告诉它。
