# 工作流

工作流是团队遵循的计划：有哪些任务，每个任务要等哪些任务，在哪里停下来等你签字。它是事先写好的，所以总制片随时知道下一步能做什么，你也能在一个页面上看到整个计划。

## 阶段 {#phases}

影视项目要经过十二个阶段。前五个阶段构建世界并写出第一集剧本；从第 6 阶段起，工作按集进行。

| 阶段 | 名称 | 做什么 | 结束于 |
| --- | --- | --- | --- |
| p0 | **摄入与立项** | 初始化项目，建立工作流，按章节分批扫描和解析小说。 | 自动闸门 |
| p1 | **剧情理解** | 并行梳理故事结构、事件和时间线。 | 自动闸门 |
| p2 | **世界圣经** | 九个世界设定 Agent 并行工作，记忆圣经管理者合并它们的结果。 | **H1** 世界圣经确认 |
| p3 | **角色与资产** | 人物（外貌、性格、关系、成长、声音、说话方式）、生物和坐骑、场景、环境、建筑和光照。 | **H1A** 角色与资产确认 |
| p4 | **美术风格** | 美术指导、人物和服装概念图、道具卡、服装、色彩剧本和画幅。 | **H2** 美术风格锁定 |
| p5 | **剧本改编** | 和 p4 同时进行。先做拆集规划，再为每集写剧本、对白、旁白、钩子、节奏和剧本拆解。 | **H3** 剧本确认（第 1 集） |
| p6 | **导演分镜** | 每集：本集需要的场景、道具和生物图片，导演方案，故事板，分镜表，每个镜头的运镜、构图、镜头语言和人物调度，可选的 3D 白模，连续性和过场。 | **H3S**、**H3W**（仅白模）、**H3A** |
| p7 | **视觉生成** | 每集：视频提示词、锚点图、角色一致性、带原生声音的组视频，可选的配音、口型同步和超分。 | **H3V**、**H3B** |
| p8 | **音频** | 每集：音效和环境音提示表、声音样本和旁白音轨（在视频之前），然后是配乐和最终混音。 | 自动闸门 |
| p9 | **剪辑合成** | 每集：剪辑、转场、字幕、花字、片头片尾、封面和后期处理。 | **H3P**、**H4** 首集成片确认（第 1 集） |
| p10 | **终审** | 每集：并行进行八项审核。 | **H5** 发布签字 |
| p11 | **发布** | 各平台的发布包、SEO 文案和元数据，然后发布。 | |

每个签字点要检查什么，见[签字点](/zh/videoagents/concepts/sign-off-gates)。其他项目类型有各自的工作流和阶段，见[项目类型](/zh/videoagents/project-types/)。

## 任务和依赖 {#tasks-and-dependencies}

每个阶段里，工作被拆成若干任务。每个任务属于一个 Agent，产出已知的文件，并列出它依赖的任务。依赖全部完成的任务可以同时运行，其余的等待。这张由任务和依赖组成的网，就是项目的工作流图。

总制片按这张图推进：派出已就绪的任务，等待结果，记录每个任务的状态，到达签字点时发起签字卡片。

有些任务只在某项设置打开时才存在。例如，3D 白模相关步骤和 H3W 签字只在 **🎛️ → 输出设置** 里打开白模时出现；过场设计只在过场模式不是「极简」时出现。

## 每集一份计划 {#one-plan-per-episode}

项目开始时，按集进行的阶段只是占位。拆集规划通过之后，总制片会把它们展开成每一集的实际任务，任务名带上集数，例如 `p6-shots-ep01`，每集都有自己的签字。

默认按顺序一次做一集：当前这一集的所有任务都完成后，下一集才开始。同一集内部的任务仍然并行。在 **⚙️ → 高级 → Agent 高级设置** 里打开 **多集并行** 后，第 1 集会先作为试播集走完整条流程，之后的几集再并行制作。

## 在工作流预览页跟进 {#follow-it-on-the-workflow-preview-page}

打开预览菜单（顶栏里的图片图标），选 **工作流预览**。

![工作流预览页：汇总条、状态图例，世界圣经阶段已展开，显示并行任务、合并任务和 g2 闸门](/images/videoagents/concepts/workflow-preview.webp)

- **汇总条** 显示总体进度、正在运行的任务数、已花费的时间、预估剩余时间、关键路径，以及消耗的语言、视频和图片 tokens。
- **图例** 说明各种颜色：已通过、执行中、已派单、等待签字、待执行、部分完成、失败、受阻、跳过/取消和待扇出模板。**✍️** 表示需要签字，**✔** 表示实际用时，**≈** 表示预估。
- **每个阶段** 是一行，可以展开和收起。已完成的阶段默认收起。展开后，任务按层排列：同一层的任务可以并行，连线表示依赖。
- **带 ×N 的任务** 代表同一任务的 N 个实例，例如每个生成组一个，旁边的小进度条显示完成了几个。

点一个任务，右侧会显示它的详情：状态、Agent、阶段、实际和预估用时、依赖（点击可跳转过去）、输出文件和备注。

![导演分镜阶段：虚线框的模板步骤和 ep01 的分集任务，右侧是 p6-shots-ep01 的详情](/images/videoagents/concepts/workflow-directing-phase.webp)

紫色虚线框的是模板步骤；旁边实线框的是第 1 集的实际任务。

## 修改计划 {#change-the-plan}

- 汇总条里的 **✏️ 修改** 会把针对整个工作流的修改请求发给总制片，由它修改计划。
- 任务详情里的 **✏️ 修改** 会把关于这个任务的意见发给总制片。

要修改某个 Agent 产出的东西，请改用预览页上的 **✏️ 修改** 按钮。见[修改师与修改意见](/zh/videoagents/concepts/reviser)。

## 让工作持续推进 {#keep-it-moving}

工作流不按定时器运行。总制片收到消息时才工作，在等你处理或没有可派的任务时停下。

| 想要 | 使用 |
| --- | --- |
| 让它现在就继续 | 运行面板里的 **▶ 继续** |
| 项目闲置一段时间后让它自己继续 | 运行面板里的 **🤖** 自动运行。见[自动运行](/zh/videoagents/console/auto-run)。 |
| 停止所有正在运行和排队中的任务 | 运行面板里的 **⏹ 停止**，或发 `/stop all` |
| 这个项目不再需要人工签字 | 工作流预览页上的 **全自动模式**。见[签字点](/zh/videoagents/concepts/sign-off-gates#full-auto-mode)。 |

## 一路上的质量检查 {#quality-checks-along-the-way}

每个任务的结果在被下一个任务使用之前，最多经过三道检查：

1. **机检**：文件格式、时长、分辨率、必填字段等可以自动检测的规则。
2. **评分**：质量评委按评分标准打分。只在 **🎛️ → 审核设置** 里的 **质量评委** 大于 0 时进行。
3. **审核**：审核 Agent 按审核设置里为每个方面设定的力度进行审核。

不通过的工作会带着意见退回重做，次数以重跑次数为上限（默认 0），然后交给你处理。只有当没有未关闭的阻断级或严重级缺陷，或者你已经豁免了它们，签字点才会通过。
