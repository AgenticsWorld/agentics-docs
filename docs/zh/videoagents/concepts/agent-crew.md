# Agent 团队

VideoAgents 像一个制片厂的摄制组那样工作。119 个专职 Agent 分成 17 个部门，每个 Agent 只做一类工作，例如写对白、设计服装或规划运镜。总制片分派工作，由你批准结果。

## 控制台里的团队 {#the-crew-in-the-console}

控制台左栏按部门列出 Agent。点部门展开它，点某个 Agent 打开和它的对话。

![控制台的 Agent 列表：顶部是管理组，07-导演 部门已展开，显示其中 12 个 Agent](/images/videoagents/concepts/agent-crew-roster.webp)

顶部的 **⭐ 管理组** 里是 **总制片**，标有 **调度**。它是你打交道最多的 Agent。列表只显示你的项目类型用到的 Agent：影视项目显示 00 到 12 号部门。

## 各个部门 {#the-departments}

| 部门 | Agent 数 | 做什么 |
| --- | --- | --- |
| **00-调度层** | 4 | 统筹制作。**总制片** 规划和分派工作、发起签字；**记忆圣经管理者** 是唯一能写世界圣经的 Agent；**质量评委** 按质量评分标准给工作打分；**修改师** 执行你在预览页上提出的修改。 |
| **01-剧情** | 10 | 读小说，把它变成一集一集：小说解析、结构分析、事件提取、剧情时间轴、拆集规划、剧本改编、对白优化、旁白、钩子和节奏。 |
| **02-世界设定** | 9 | 写世界圣经：世界观总纲、时间线、地理、宗教、文化、政治、经济、魔法或修炼体系，以及术语词典。 |
| **03-角色** | 7 | 定义每个人物：角色索引、外貌、性格、关系、成长、声纹和语言风格。 |
| **04-生物资产** | 2 | 生物和坐骑。 |
| **05-场景资产** | 5 | 场景、环境、建筑、光照和场景建模。 |
| **06-美术资产** | 10 | 整部剧的视觉：美术指导，人物、环境、生物和服装概念图，服装卡和道具卡，色彩剧本，画幅，以及在画板上修图。 |
| **07-导演** | 12 | 把每集剧本变成镜头：导演方案、故事板和草图、镜头规划、运镜、构图、镜头语言、人物调度、连续性、台词指导、过场设计和 3D 白模调度。 |
| **08-视频生成** | 9 | 生成画面：视频提示词、图像生成、角色一致性检查、视频生成、口型同步、动作修复、超分、分镜背景图和画板动图。 |
| **09-音频** | 7 | 配音、旁白、配乐、音效、环境音、混音，以及把现有音频转成文字。 |
| **10-剪辑** | 8 | 剪辑、转场、字幕、花字、片头片尾、封面、后期精修和调色方案。 |
| **11-审核** | 12 | 每集的八项审核：逻辑、角色一致性、时间线、世界观一致性、画面、音频、内容安全和版权。另外四个负责其他项目类型的审核（音频配画的音画同步、混剪、数字人同步和动效短片）。 |
| **12-发布** | 4 | 平台适配、SEO、元数据和发布。 |
| **15-音频配画** | 5 | 音频配画项目的团队。 |
| **16-混剪** | 6 | 混剪项目的团队。 |
| **17-数字人** | 5 | 数字人项目的团队。 |
| **18-动效短片** | 4 | 动效短片项目的团队。 |

15 到 18 号部门及其审核 Agent 只在对应类型的项目里出现。插件可以添加更多部门，编号从 13 开始。见[安装插件](/zh/videoagents/extend/install-plugins)。

## Agent 怎样接到工作 {#how-an-agent-gets-its-work}

1. **角色文件。** 每个 Agent 都有一个 `SOUL.md`，规定它是谁、做什么、不能做什么，它的输入和输出，以及质量标准。相邻 Agent 之间的边界写得很清楚，所以没有哪项工作会被做两遍或被漏掉。
2. **工单。** 总制片给 Agent 发一张工单：任务是什么、要读哪些文件、要产出哪个文件、怎样验收。Agent 只读工单里列出的内容。
3. **输出文件。** Agent 把结果写进项目目录，并提交一份简短汇报。见[文件、运行记录与版本](/zh/videoagents/concepts/files-and-runs)。
4. **检查。** 结果最多经过三道检查：自动机检、质量评委打分、审核 Agent 审核。不通过的工作会带着意见退回，或交给你处理。

::: tip 提示
新项目里，质量评委的合格线和每项审核力度初始都是 0，也就是跳过这些检查；机检照常进行。可以在 **🎛️ → 审核设置** 里调高。见[审核设置](/zh/videoagents/console/review-settings)。
:::

## 和 Agent 对话 {#talking-to-agents}

你可以和任何 Agent 对话：在左栏选中它，发一条消息。一条消息会给这个 Agent 启动一个任务。不过大多数时候，你是在和 **总制片** 对话：告诉它你想要什么，由它决定该让哪些 Agent 去做。

- 要修改某个 Agent 做出的东西，用预览页上的 **✏️ 修改** 按钮。它们会发给[修改师](/zh/videoagents/concepts/reviser)。
- 你从飞书、微信或 WhatsApp 发的消息会发给总制片。见[手机消息](/zh/videoagents/console/mobile-messages)。
- `/clear`、`/stop all` 等命令在每个 Agent 的对话框里都能用。见[聊天命令](/zh/videoagents/console/chat-commands)。

更多内容见[与 Agent 对话](/zh/videoagents/console/chat-with-agents)。

## 任务之间的记忆 {#memory-between-tasks}

创作型 Agent 会延续同一段对话：每个新任务都接着这个 Agent 在该项目里的上一次会话，所以它记得之前的工作。会话超过记忆额度（默认 16 KB，在 **⚙️ → 高级 → Agent 高级设置** 里设置）时，会开启新会话。分批并行工作的 Agent，例如审核 Agent 和修改师，每次都从头开始，可以同时运行多个任务。

给某个 Agent 发 `/clear`，它的下一个任务就会开启新会话。

## 每个 Agent 的设置 {#each-agent-s-settings}

每个 Agent 对话框的标题栏都有针对这个 Agent 的按钮：

| 按钮 | 作用 |
| --- | --- |
| **技能** | 列出这个 Agent 已安装的技能，也可以加载更多。一个技能教会一个 Agent 一门手艺。见[安装和使用技能](/zh/videoagents/extend/skills)。 |
| **模型** | 打开 **🧠 Agent 模型配置**，可以给这个 Agent 单独设置引擎和语言模型。见[选择 Agent 引擎](/zh/videoagents/getting-started/choose-an-agent-engine)。 |
| **SOUL.md** | 显示这个 Agent 的角色文件。只在 Debug 模式下出现（**⚙️ → 高级 → Agent 高级设置**）。 |
