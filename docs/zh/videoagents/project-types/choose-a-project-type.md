# 选择项目类型

项目类型是创建项目时第一个要选的。它决定你要提供什么、哪些 Agent 参与这个项目、你要在哪些地方签字，以及最后得到什么。

## 五种类型 {#the-five-types}

| 类型 | 你提供 | 你得到 | 画面来源 | 你的签字点 | 向导步数 |
| --- | --- | --- | --- | --- | --- |
| 🎬 **影视剧**（默认） | 一部小说（可以之后再补） | 多集剧集 | 图像和视频模型 | H1–H5，另外每集还有几个 | 5 |
| 🧑‍💼 **数字人** | 一段对话录音，或者声音样本加台词稿；外加每个说话人一张照片 | 口型同步的人物说话视频 | 你的数字人服务商 | 无 | 3 |
| 🖥️ **动效短片** | 一个主题或一份文稿，加一种风格 | 用代码绘制的短片，30–60 秒最合适 | Agent 编写的网页，逐帧渲染 | CVH1（可选）、CVH2 | 4 |
| 🎙️ **音频配画** | 一段讲述录音和对应的文稿 | 一条视频，声轨就是你的录音，原样不动 | 图像和视频模型 | AVH1–AVH5 | 4 |
| ✂️ **混剪** | 一份文稿、一个素材库，可选一段讲述录音 | 一条用你自己的素材剪成的视频 | 素材库里的片段 | MH1–MH3 | 3 |

**音频配画** 和 **混剪** 收在向导第一步的 **更多** 里。

数字人、动效短片、音频配画和混剪项目各只做一条视频，存为 `ep01` 这一集。要做更多这类视频，就多建几个项目。

## 插件提供的作品 {#works-that-plugins-add}

另外三种作品不是在向导里选的项目类型，而是在已有项目里运行：

| 作品 | 做什么 | 来源 |
| --- | --- | --- |
| [衍生小说](/zh/videoagents/project-types/derivative-fiction) | 根据项目的世界圣经和角色写一部新小说（前传、外传、假如线） | 内置插件，默认关闭，启用后才能用 |
| [融合创作](/zh/videoagents/project-types/fusion-fiction) | 把项目的故事和另一本书的世界融合在一起 | 内置插件，默认关闭，启用后才能用 |
| [有声剧](/zh/videoagents/project-types/audio-drama) | 把项目的剧本和声音做成有声剧或播客 | 插件仓库 |

这三种都要在一个已经有世界圣经的影视剧项目上进行。

## 哪种适合你 {#which-one-fits}

- **你有一部小说或一个故事，想改编成多集：** 影视剧。
- **你有播客、访谈或对话录音，还有说话人的照片：** 数字人。没有录音？把声音来源选为 **克隆声音**，再写好台词稿。
- **你想做发布短片、讲解片、数据叙事或品牌短片，又不想为视频生成付费：** 动效短片。
- **你有一段讲述录音（历史故事、知识讲解、播客），想给它配上 AI 画面：** 音频配画。
- **你有一份文稿和一批自己的视频素材，想剪一条按旁白切换画面的片子：** 混剪。先在[素材库](/zh/videoagents/project-types/footage-library)里建好素材。

## 在向导里选择类型 {#pick-the-type-in-the-wizard}

1. 点顶栏的项目名，打开 **项目** 对话框，再点 **＋ 新建项目…**。
2. 在第 1 步 **项目类型** 里点一张卡片。卡片下方的说明框会介绍所选类型，以及你需要提供什么。

   ![新建项目向导的项目类型步骤，选中了影视剧](/images/videoagents/project-types/choose-a-project-type-wizard.webp)

   要看到 **音频配画** 和 **混剪**，点 **更多**。下面会展开第二行，列出这两种类型；再点一次 **更多** 就收起。选中其中一种时，**更多** 会一直高亮。

   ![展开的「更多」一行，选中了音频配画，下方是它的说明](/images/videoagents/project-types/audio-to-video-type.webp)

3. 点 **下一步**。标题里的总步数随类型变化，后面的步骤只显示这种类型用到的字段。
4. 填完其余步骤，点 **创建**。每种类型的字段见各自的指南。

向导的其他内容见[新建项目向导](/zh/videoagents/console/new-project-wizard)。

## 创建项目之后 {#what-happens-after-you-create-the-project}

- **影视剧：** 总制片马上开始工作。它建好文件夹，清洗小说文本并分章，然后提醒你在 **🖼 参考文件** 页上传参考素材。
- **其他四种类型：** 你在向导里选的文件先上传到项目的参考文件里。总制片随后核对素材，汇报缺了什么。它会等你在对话里回复可以开工，再按这种类型的流程规划并派发工作。

## 几点说明 {#good-to-know}
- **类型之后不能改。** 类型在创建项目时写进项目的 `settings.json`。想换一种类型，就新建一个项目。
- **影视剧专用的开关在其他类型里都关掉了。** 旁白、对白配音、声画分离、背景群演（NPC）、3D 白模、长镜头，以及片头、片尾和预告都关闭。过场模式设为极简、不做集尾收束，每集时长设为自动。这些开关属于小说改编视频的流程，其中有几个会重新编码或挪动一条必须原样保留的音轨。
- **左栏只显示需要的 Agent。** 列出的是共用的 Agent，加上当前项目类型的团队，例如混剪项目里的素材侦察员和选片师。
- **参考文件页随类型调整。** 在非影视剧项目里，**讲述音频** 分类（`refs/audio/`）排在最前面。数字人项目还多一个 **克隆声音** 分类（`refs/voices/`）。
- **项目对话框会显示每个项目的类型**，在 **类型** 一列。
- **旧项目**（在有项目类型之前创建的）会根据里面已有的文件识别类型。都对不上时，按影视剧处理。
