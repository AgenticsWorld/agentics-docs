# 素材库

素材库把你自己的视频变成一组可搜索的片段。上传一个视频文件或粘贴一个 YouTube、Bilibili 链接，它会把视频切分成镜头，把每个镜头导出为一个片段（界面里叫「分镜」），并让你给每个片段加上字幕和 AI 写的画面信息。[混剪](/zh/videoagents/project-types/mashup)项目从这里挑镜头，**🖼 参考文件** 页也可以从这里截取静帧。

素材库由所有项目共用。素材库里的每一项叫一个素材项目，各自放在一个文件夹里：`data/footage/<name>/`。

## 打开素材库 {#open-the-footage-library}

在控制台里打开 **⚙️ → 高级 → 素材库**。页面先显示素材项目列表。右上角的标签显示 AI 分析用的引擎和模型。

## 新建素材项目并导入视频 {#create-a-footage-project-and-import-a-video}

1. 在顶部的输入框里填一个名字（英文字母、数字、`_` 和 `-`），或者留空，自动命名为 `fp20261103-095619` 这样的名字。点 **＋ 新建项目**。
2. 新项目会打开。选择导入视频的方式：
   - **📤 上传视频文件：** 点击上传区域，或者把视频拖进去。常见格式都可以，包括 `.mp4`、`.mov`、`.mkv`、`.webm`、`.m4v`、`.avi`、`.flv` 和 `.ts`。
   - **🔗 YouTube / Bilibili 链接：** 粘贴链接，点 **⬇ 下载并处理**。视频最高按 1080p 下载。站点自带的字幕（中文和英文，优先人工字幕）也会一起下载。能否下载取决于你的网络和站点；Bilibili 高清可能需要登录。

   ![YouTube / Bilibili 链接标签页，带链接输入框和「下载并处理」按钮](/images/videoagents/project-types/footage-library-link.webp)

3. 等待状态标签依次经过 **下载中**（或上传进度）、**处理中** 和 **就绪**。运行过程中可以点 **取消**。处理时会先生成一个低分辨率的小副本用于分析，再检测镜头，然后从原始视频导出每个镜头，生成片段和缩略图。

字幕不会自动生成。需要时用 **🎙 语音转字幕** 添加。

## 项目页 {#the-project-page}

![素材项目页，显示标签、最短镜头和各操作按钮](/images/videoagents/project-types/footage-library-project.webp)

页面顶部显示来源、时长和分辨率、源视频链接、片段数和已分析的数量、字幕文件，以及状态。下面是：

| 控件 | 作用 |
| --- | --- |
| **🏷 标签** | 按 `#标签1 #标签2` 的格式输入，用空格分隔。离开输入框时保存 |
| **🤖 AI 分析问题** | 对这个项目的每个片段提出的问题。离开输入框时保存。**📋 模板** 可以填入三个预设之一：**画面内容分析**（默认：画面、表达的信息、主体、标签）、**分镜设计分析**（景别、光线、运镜、美术风格、手法、布景）和 **画面风格分析**（风格、硬切、稳定区间） |
| **✂ 最短镜头（秒）** | 间隔比这个值近的切点会合并成一个镜头。默认 0.5。快切素材可以调小，再点 **✂ 重新分割** |
| **🤖 全部 AI 分析** | 在后台对所有还没有画面信息的片段做 AI 分析 |
| **🎙 语音转字幕** | 填写每个片段的字幕框。下载了站点字幕时直接使用，否则在你的电脑上做语音识别 |
| **🎙 Whisper 重新识别** | 有站点字幕时显示：不用站点字幕，改用本地语音识别 |
| **✂ 重新分割** | 重新检测镜头 |
| **📤 重新导入** | 上传另一个文件，或粘贴另一个链接 |
| **📂 打开文件夹** | 打开项目文件夹 |
| **🗑 删除项目** | 删除项目及其文件夹 |

输出一行链接到 `clips.json`，里面列出每个片段的文件、缩略图、时间、字幕和画面信息。

## 片段 {#clips}

每个片段有自己的卡片。

![片段卡片，显示缩略图、时间码、AI 分析和删除按钮，以及字幕和画面信息输入框](/images/videoagents/project-types/footage-library-clip.webp)

- 点缩略图播放片段。
- 缩略图下方：起止时间码、时长，以及用来复制片段在项目内路径的 **⧉**。
- **字幕（语音转文字，可编辑）** 和 **画面信息（AI 分析或人工填写，可编辑）** 在离开输入框时保存，也可以按 Ctrl+S / Cmd+S 保存。
- **🤖 AI 自动分析** 从片段的几个时间点截图拼成一张联系图，连同项目的分析问题发给默认引擎。回答以你的界面语言写进 **画面信息**，时间码旁边会出现 **联系图** 链接。
- **🗑 删除** 删除这个片段及其文件、字幕和画面信息。其他片段的编号不变，所以删掉的编号会留下一个空缺。

要打印片段，点右下角的 **🖨️**。它会生成一个两列的页面（片段截图和画面信息），并打开打印对话框，在那里也可以存为 PDF。

## 在列表里查找项目 {#find-projects-in-the-list}

- 列表显示每个项目的来源、状态、片段数和已分析数，以及标签。点一行打开项目。
- 在过滤框里输入 `#标签`，只显示匹配的项目。输入多个标签时，项目必须同时具备所有标签。点标签小块可以把它加入过滤或从过滤中去掉。
- 某一行的 **🏷** 可以直接编辑这个项目的标签；**⧉** 复制项目的文件夹路径。

## 使用片段 {#use-the-clips}

- **混剪项目：** 在新建项目向导里，**素材库** 字段列出所有已完成镜头分割、并且有片段的素材项目。Agent 搜索画面信息和字幕来找镜头，所以先把每个片段都分析一遍。见[混剪](/zh/videoagents/project-types/mashup)。
- **参考文件：** 在 **🖼 参考文件** 页，图片类分类里的 **🎞 素材库** 按钮会打开一个播放器，可以播放任意素材项目的原始视频。找到想要的画面，点 **📸 截图加入参考文件**，以原始分辨率保存到这个分类里。见[参考文件](/zh/videoagents/world/reference-files)。

## 几点说明 {#good-to-know}
- **AI 分析用你的默认引擎。** 它跟随控制台顶栏选择的引擎和模型；使用智能分配时，用该引擎的低档模型。引擎必须能看图。
- **回答语言跟随界面语言。** 预设问题是中文的；你也可以自己写问题，无论用什么语言写，回答都按你的界面语言返回。
- **字幕会被覆盖。** **🎙 语音转字幕** 会替换字幕框里已有的字幕；执行前会先问你。
- **语音识别在本机进行。** 使用 faster-whisper，第一次使用时会下载模型。

::: warning 注意
**✂ 重新分割** 和 **📤 重新导入** 会删除现有的片段，连同你编辑过的字幕和画面信息一起删除。**🗑 删除项目** 会删除整个文件夹，包括源视频。这些操作都不能撤销。
:::
