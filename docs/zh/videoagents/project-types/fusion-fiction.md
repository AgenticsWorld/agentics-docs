# 融合创作

融合创作把两本书融合成一部新剧本。甲本（你的项目）保留它的故事和人物的内在灵魂；乙本提供世界（地理、政治、经济、宗教、文化等）和人物的外在形象。例如：把甲本里的一个黑帮故事放进《西游记》的世界，主角化身孙悟空，敌对帮派变成各路妖怪。

如果乙本是知名的名著或公版作品，就不需要提供它的文本；Agent 凭模型对它的了解来工作（「名著模式」）。否则你需要提供全文。

它作为插件随 VideoAgents 一起提供，默认关闭，启用后才能用。

::: warning 注意
融合创作把结果直接写进项目的 `bible/` 和 `story/` 文件夹，替换世界圣经、角色卡和剧本。它不保留版本，也不能回滚。先用 **🎛️ → 版本管理** 复制项目（见[复制和删除项目](/zh/videoagents/console/project-versions)）。
:::

## 开始之前 {#before-you-start}
项目（甲本）必须已经完成影视剧工作流的剧情、世界圣经、角色和剧本阶段：

- `bible/` 里的世界圣经，包括 `bible/characters/relationship.json`，并且已签字；
- `story/episode_plan.json` 和各集的剧本。

如果缺了哪个阶段，先在影视剧工作流里完成它。

## 启用插件 {#enable-the-plugin}

1. 打开 **⚙️ → 插件**。
2. 找到 **fusion-fiction**，点 **启用**。

   ![Agent 插件对话框，列出 derivative-fiction、digital-human 和 fusion-fiction](/images/videoagents/project-types/plugins-dialog.webp)

3. 关闭对话框。左栏会出现六个 Agent：融合企划、乙本考据、人物映射、世界融合、剧本移植和双源保真审核。

## 开始融合 {#start-a-fusion}

打开项目，选中 **总制片**，说明哪本书提供什么，以及你已经定下的人物对应。例如：

```text
启动 fusion-fiction 工作流。甲本是本项目，提供故事和人物灵魂。
乙本是《西游记》（名著模式），负责人物形象、地理、政治、经济和宗教。
我现在锁定的人物对应：
<你的主角> = 孙悟空
<你的导师型人物> = 唐三藏
其余人物请推荐对应，让我确认。
```

全文模式下，乙本的文本放进项目的 `fusion/source_b/novel/` 文件夹。

## 需要你确认的三份方案 {#the-three-plans-you-agree-on}

| 方案 | 文件 | 内容 |
| --- | --- | --- |
| 维度矩阵 | `fusion/fusion_plan.json` | 每个维度（故事、灵魂、形象、各项世界观维度、美术风格、时代锚点）取自甲本、取自乙本，还是融合 |
| 人物映射表 | `fusion/character_map.json` | 你锁定的对应，加上系统推荐的对应（每对带置信度、理由和三个备选），以及没有对应的人物怎么处理 |
| 概念字典 | `fusion/dictionary.json` | 甲本的器物、制度和黑话，以及它们在乙本中的对应物，外加一份不允许出现的现代词清单 |

## 工作流和签字 {#workflow-and-sign-offs}

| 阶段 | 做什么 | 你的签字 |
| --- | --- | --- |
| fs0 融合立项 | 你和融合企划敲定维度矩阵、时代、名著模式还是全文模式、首批人物对应和红线 | **FH1** 融合蓝图，包括确认将直接修改正史 |
| fs1 乙本摄入 | 名著模式：乙本考据凭模型知识建立乙本的世界和人物档案，并注明依据的版本。全文模式：由内置的解析 Agent 读取文本 | — |
| fs2 人物映射 | 人物映射根据原型、人物关系、性格和阵营推荐对应，并如实标出找不到对应的人物 | **FH2** 人物映射表：锁定、调换、增加或删除对应 |
| fs3 世界融合 | 世界融合把融合后的世界和合成的角色卡（甲本的灵魂、乙本的形象壳）写进 `bible/`，并建立概念字典 | **FH3** 融合后的世界圣经和概念字典 |
| fs4 剧本移植 | 剧本移植逐集保留节拍、更换外壳：所有名字按映射表改，所有替换的概念按字典改。然后精修台词。第一集作为试点先做 | **FH4** 首集试读 |
| fs5 全剧终审 | 逻辑、世界观一致性、角色一致性、对两本书的保真度、版权 | **FH5** 剧本定稿 |
| fs6 可选 | 重跑下游阶段（场景、美术、分镜），让预览页显示融合后的世界；或者交给[衍生小说](/zh/videoagents/project-types/derivative-fiction)改写成小说 | — |

因为结果写进了正史，现有的页面会立即显示：FH3 之后在 **🌍 世界观预览** 和 **👤 人物预览** 里，fs4 之后剧本在 **📜 剧本预览** 里。fs6 重跑多少由你决定；总制片不会自行把它延伸到费用高的视频生成。

## 几点说明 {#good-to-know}
- **原剧本会保留快照。** 每一集改写之前，它的原剧本会保存到 `fusion/episodes/<episode>/source_screenplay.md`。保真审核按它对照，你也可以对照。
- **保真审核看什么：** 灵魂丢失（甲本的人物或故事不再能看出来）、外壳破损（甲本世界的东西混进乙本的世界）、违反映射表，以及偏离字典。
- **一定会做版权审核。** 甲本常常是有版权的作品，所以融合结果要经过版权审核。
- **过程文件**（乙本的档案、各份方案、移植台账、冲突记录）保存在 `fusion/` 里。
- **在 fs6 改写成小说** 需要同时启用 derivative-fiction 插件。
