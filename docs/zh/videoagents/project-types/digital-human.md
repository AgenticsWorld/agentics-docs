# 数字人

数字人项目用一段对话录音（例如播客或访谈）和每个说话人一张照片，生成口型同步的视频。画面始终全屏显示正在说话的人，声轨就是你的原始录音。如果没有录音，也可以写好台词稿，按一小段声音样本克隆每个说话人的声音。

## 开始之前 {#before-you-start}
- 一个已登录的 Agent 引擎。
- 在 **⚙️ → 生成模型 → 🧑 数字人** 里设置并测试好一个数字人服务商：Agentics、HeyGen、Kling AI 或 ComfyUI（本地、Comfy Cloud 或 RunningHub）。见[数字人模型](/zh/videoagents/models/digital-human-models)。
- 每个说话人一张清晰的照片（`.png`、`.jpg`、`.jpeg` 或 `.webp`）。
- 录音（`.mp3`、`.wav`、`.flac`、`.m4a`、`.aac` 或 `.ogg`）；或者用克隆声音时，每个说话人一段声音样本，外加一份台词稿。

## 创建数字人项目 {#create-a-digital-human-project}

1. 点顶栏的项目名，再点 **＋ 新建项目…**。
2. **第 1/3 步 · 项目类型：** 点 **数字人**，再点 **下一步**。
3. **第 2/3 步 · 基础信息：** 先选 **声音来源**，再填写各个字段。

   ![数字人项目的基础信息步骤，选中了原始录音](/images/videoagents/project-types/digital-human-basic.webp)

   | 字段 | 原始录音 | 克隆声音 | 保存到 |
   | --- | --- | --- | --- |
   | **项目名称** | 只能用英文字母和数字 | 同左 | — |
   | **音频母带** | 录好的对话 | — | `refs/audio/` |
   | **克隆声音** | — | 每个说话人一段样本 | `refs/voices/` |
   | **人物照片** | 每个说话人一张照片 | 同左 | `refs/characters/` |
   | **文稿（可选）** / **台词稿** | 选填，见[文稿](#scripts) | 必填：每句一行，格式为 `说话人：台词` | `refs/text/transcript.txt` |
   | **人物对应说明** | 每个说话人用哪张照片 | 每个说话人用哪张照片、哪段声音样本 | `brief.md` |

4. **第 3/3 步 · 输出设置：** 画幅、输出语言、草稿分辨率和成片分辨率。点 **创建**。

每个文件最大 100 MB。现在没选的文件，之后都可以在 **🖼 参考文件** 页上传。

项目创建后，总制片会核对你的文件，告诉你缺什么。在对话里回复可以开工，它就开始跑数字人工作流。你可以在同一条消息里补充说明，例如：「开工。第一个出现的说话人是主持人，用 refs/characters/host.png；第二个是嘉宾，用 refs/characters/guest.png。」

## 人物对应说明 {#speaker-mapping}

用平常的话写清楚哪张照片对应哪个说话人，不需要特殊的文件格式。

```text
主持人用 refs/characters/host.png；嘉宾用 refs/characters/guest.png。
```

没有文稿、又有两个人说话时，还要说明怎么区分他们：按谁先开口的顺序，或者按声音高低：

```text
第一个出现的说话人是主持人，用 host.png；第二个是嘉宾，用 guest.png。
```

```text
声音较低的是主持人，用 host.png；声音较高的是嘉宾，用 guest.png。
```

「第一个」「第二个」指的是每个声音第一次出现的先后，不是一句一句轮流。工作流从不根据照片猜说话人的性别。

## 文稿 {#scripts}

文稿可以留空。这时工作流会在你的电脑上用 faster-whisper 转写录音。模型只下载一次，存到 `data/models/faster-whisper/`；使用的是 **⚙️ → 高级 → 语音输入** 里选中的模型。只有一个说话人时，每句话都归他。有两个或更多说话人时，工作流根据你的人物对应说明和对声音的简单分析来判断谁在什么时候说话。如果把握不大，它会在任何付费生成之前停下来，让你检查转写结果。

如果你提供了文稿，就原样使用，从不覆盖。每一段都要写明起止时间。

一个说话人（人名可写可不写）：

```text
[00:00.000-00:04.200] 欢迎来到今天的节目。
[00:04.200-00:08.600] 今天我们聊聊 AI 电影。
```

两个或更多说话人（每段都要有时间、人名和台词）：

```text
[00:00.000-00:03.200] 主持人：欢迎来到今天的节目。
[00:03.200-00:07.850] 嘉宾：谢谢邀请。
[00:07.850-00:11.400] 主持人：先从数字人说起。
```

第一段从 `00:00.000` 开始，每段从上一段结束的地方开始，不能有空隙或重叠，最后一段在录音的总时长处结束（误差 0.05 秒以内）。没有人名或时间的多人文稿会在生成任何内容之前被拒绝。

## 克隆声音 {#cloned-voices}

没有录音时，把声音来源选为 **克隆声音**。台词稿的每一句都用对应说话人的声音合成，各句拼成一条母带并附带带时间的文稿，之后的工作流和有录音时一样。

![选中克隆声音的基础信息步骤，显示当前 TTS 渠道无法克隆的提示](/images/videoagents/project-types/digital-human-clone.webp)

- **样本：** 每个说话人一段 5–30 秒的干净录音，只有这一个人在说话。短于 2 秒的样本会被拒绝；不在 5–30 秒范围内的会给出提醒。
- **台词稿：** 每句一行，格式为 `说话人：台词`。只有一个说话人时可以不写人名。空行和以 `#` 开头的行会被忽略。
- **对应说明：** 写清楚每个说话人用哪张照片、哪段样本。只有一段样本，或者样本文件以说话人命名时，会自动对应。
- **TTS 渠道：** 只有三种渠道能按样本克隆：Agentics 的 Voice Clone 模型、ComfyUI 的 Voice Clone 工作流，以及火山 Doubao-音频生成 1.0。在 **⚙️ → 生成模型** 里选一个。如果当前渠道不能克隆，向导会显示一条黄色提示；你仍然可以创建项目，在开工之前再切换。其他渠道会报错停下，不会拿声音库里相似的声音代替。
- **修改：** 编辑台词稿或替换样本后，只重新合成新增或改动的句子，视频从那里开始重建。

::: warning 注意
只上传你本人的声音，或者已获授权使用的声音。
:::

## 工作流做什么 {#what-the-workflow-does}

1. **摄入：** 检查工具，确定音频母带和说话人与照片的对应关系。没有文稿时转写音频。
2. **对齐：** 建立谁在什么时候说话的时间轴。
3. **导演：** 每一段规划一个当前说话人的全屏镜头。
4. **生成：** 把每一段作为单独的任务发给你的数字人服务商。
5. **剪辑和检查：** 把各段视频接起来，铺回你的原始音频，并检查音频既没有被重新编码，也没有被截短。

没有签字点。检查不过会自动退回重做；反复不过才交给你。这些 Agent 在左栏的 **数字人** 分组里，外加数字人同步审核。

各段视频保存在 `assets/digital-human/ep01/`，成片是 `edit/ep01/final.mp4`。

## 几点说明 {#good-to-know}
- **你的音频就是声轨。** 服务商返回的音频一律丢弃。
- **中断不会重复付费。** 每一段的服务商任务都有记录，中断之后工作流会接着取回同一个任务，不会再付费新建一个。
- **RunningHub 一次只跑一段。** RunningHub 繁忙时，这一段会等待并重试，最长 2 小时。等待不算失败。
- **很短和很长的句子：** 短于 2 秒的句子显示说话人的静止画面；同一说话人超过 14 秒的段落可能会在标点处拆开。
- **这一版的限制：** 自动识别说话人最多适合两个人；说话重叠、背景音乐太响或置信度低时，会在付费生成之前停下。画面上一次只有一个人：没有双人镜头、反应镜头或运镜。不加背景音乐、降噪、响度调整，也不加片头片尾。

::: warning 注意
每一段都是你的数字人服务商的一个付费任务。
:::

::: tip 提示
数字人在 v1.0.40 成为项目类型，之前是一个插件。克隆声音也是在这一版加入的。
:::
