# 音频配画

音频配画给一段讲述录音配上 AI 生成的画面，适合历史故事、知识讲解、播客这类内容。你的录音原样作为成片的声轨：不转码、不剪裁、不做响度归一。画面按录音的实测时长来规划和切分。

这是把影视剧的流程倒过来。影视剧项目里先有画面，再让旁白去配合画面；这里音频固定不变，由画面来配合。

## 开始之前 {#before-you-start}
- 一个已登录的 Agent 引擎，并在 **⚙️ → 生成模型** 设置好图像和视频服务商。
- 讲述录音（`.mp3`、`.wav`、`.flac`、`.m4a`、`.aac` 或 `.ogg`，在向导里最大 100 MB）。
- 与录音逐字对应的文稿。它用来让画面对上正在说的内容。工作流不会替你把音频转成文字。

## 创建音频配画项目 {#create-an-audio-to-video-project}

1. 点顶栏的项目名，再点 **＋ 新建项目…**。
2. **第 1/4 步 · 项目类型：** 点 **更多**，再点 **音频配画**。点 **下一步**。
3. **第 2/4 步 · 基础信息：**

   | 字段 | 填什么 | 保存到 |
   | --- | --- | --- |
   | **项目名称** | 只能用英文字母和数字 | — |
   | **讲述音频** | 点 **选择文件**，选中录音 | `refs/audio/` |
   | **文稿** | 粘贴与录音对应的文稿 | `refs/text/transcript.txt` |
   | **内容定位** | 题材与时代背景、基调、目标受众、画面里要表现或略去什么 | `brief.md` |
   | **画面风格** | 画面的样子；点 **🎨 选择风格库** 可以从预设开始 | `brief.md` |

   ![音频配画项目的基础信息步骤](/images/videoagents/project-types/audio-to-video-basic.webp)

4. **第 3/4 步 · 模型限制：** 按你的视频模型设置这些上限，或者保留默认值。见[模型限制](/zh/videoagents/console/model-limits)。
5. **第 4/4 步 · 输出设置：** 画幅、输出语言、草稿分辨率和成片分辨率。点 **创建**。

如果现在没选录音，之后可以在 **🖼 参考文件** 页的 **讲述音频** 分类里上传。

## 开始工作 {#start-the-work}

项目创建后，总制片会核对录音和文稿，告诉你缺什么。素材齐了，就在对话里回复可以开工。它会规划工作流，测量并对齐音频，然后把时间轴发给你做第一次签字。

## 画面怎样贴合音频 {#how-the-pictures-fit-the-audio}

1. 精确测出录音的时长，并找出其中的停顿。
2. 把文稿拆成句子，按每句的长度估算时间，再把句子边界吸附到最近的停顿上。
3. 把时间轴切成以整秒为单位的画面组，每组 4–14 秒，优先在段落之间切开。最后一组带上剩下的不足一秒的部分。
4. 每组生成一段正好这么多秒的无声视频，画面不会和声音错开。
5. 把各段视频接起来，再把你的录音不经重新编码直接铺上作为声轨。

字幕几乎是顺带得到的：时间轴里已经有每句话的时间，字幕文件直接从它写出来。

## 工作流和签字 {#workflow-and-sign-offs}

| 阶段 | 做什么 | 你的签字 |
| --- | --- | --- |
| av0 音频立项 | 测量音频，找出停顿，对齐文稿 | **AVH1** 时间轴基线，这是最重要的一次 |
| av1 设定与美术 | 对时代做轻量考据（服饰、建筑、器物、风俗），美术风格、概念图、服装、道具、场景 | **AVH2** 风格与时代考据 |
| av2 画面规划 | 画面编剧决定每段画什么；时间轴规划确定每组多长；规划连续性 | **AVH3** 画面规划与分镜 |
| av3 视觉生成 | 每组的提示词、图片和无声视频，以及角色一致性检查 | **AVH4** 生成的画面 |
| av4 剪辑与封装 | 剪辑、字幕、片名和封面 | — |
| av5 终审 | 音画同步、画面、世界观一致性、内容安全、版权；响度只测量并报告 | **AVH5** 成片 |

团队包括左栏 **音频配画** 分组里的五个 Agent（音频摄入、文本对齐、时代考据、画面编剧、时间轴规划）和音画同步审核，再加上内置的美术、场景、视频生成、剪辑和审核 Agent。

虽然不建完整的世界圣经，美术风格、服装、道具和场景仍然要做：视频提示词必须引用它们，缺了就不允许生成。

## 在哪里看结果 {#where-to-see-the-results}

结果写进常规的项目文件夹，所以现有的页面都能显示：

| 内容 | 页面 |
| --- | --- |
| 时代考据与设定 | **🌍 世界观预览** |
| 人物和场景 | **👤 人物预览**、**🏔 场景预览** |
| 每组的画面脚本、分镜、提示词和图片 | **🎦 分镜预览** |
| 组视频和成片 | **🎞️ 成片发布** |
| 进度和花费 | **🧭 工作流预览**（av0–av5 阶段） |

成片是 `edit/ep01/final.mp4`。

## 几点说明 {#good-to-know}
- **开始之前先复制一份。** 工作流直接写入项目的 `bible/`、`story/` 和 `directing/` 文件夹，自己不保留版本。先用 **🎛️ → 版本管理** 复制项目。见[复制和删除项目](/zh/videoagents/console/project-versions)。
- **响度不做处理。** 音频审核只测量响度和峰值并报告，不会改动你的录音。
- **片头、片尾和预告是关闭的。** 加片头会重新编码音频，并让旁白整体后移。
- **发布时会重新编码。** 发布时生成的各平台版本会转码成各平台的格式，所以「音频原样不动」只保证到 `edit/ep01/final.mp4` 为止。
- **一段录音，一个项目。** 每个项目只做一条视频（`ep01`）。不支持背景音乐、环境声和多集。

::: tip 提示
第一次试用时，用一段 60–90 秒的录音（大约 6–8 个画面组）。在投入一整部之前，它能让你看到真实的花费，以及工作流会卡在哪里。
:::

::: warning 注意
每个画面组都要用你的服务商生成图片和一段视频，每次调用都会计费。
:::
