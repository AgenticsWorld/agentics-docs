# 混剪

混剪项目从你自己的素材库里挑镜头给一段旁白配画，不生成任何画面。文稿的每一句都配上匹配的素材，每个切点都落在正在说出的那个词上，讲述录音原样作为声轨。没有录音时，按文稿合成配音。

## 开始之前 {#before-you-start}
- **一个素材库。** 在[素材库](/zh/videoagents/project-types/footage-library)里导入你的源视频，等镜头分割完成。在那里也跑一遍 **🤖 全部 AI 分析**：Agent 找匹配镜头时搜索的就是画面信息，没有画面信息，它们只能搜字幕。
- **一个能看图的 Agent 引擎**，给选片师用，它靠看图挑镜头。
- **faster-whisper**（强烈建议）。它给旁白的每个词计时。没有它，时间按文字估算，精度较低；第一次签字时会告诉你。
- **一个 TTS 渠道**，在 **⚙️ → 生成模型** 里设置，只在你没有讲述录音时需要。

## 创建混剪项目 {#create-a-mashup-project}

1. 点顶栏的项目名，再点 **＋ 新建项目…**。
2. **第 1/3 步 · 项目类型：** 点 **更多**，再点 **混剪**。点 **下一步**。
3. **第 2/3 步 · 基础信息：**

   | 字段 | 填什么 | 保存到 |
   | --- | --- | --- |
   | **项目名称** | 只能用英文字母和数字 | — |
   | **讲述音频** | 选填。要配画的录音。留空则按文稿合成配音 | `refs/audio/` |
   | **文稿** | 旁白文稿。素材按它逐句匹配 | `refs/text/transcript.txt` 和 `novel/original.txt` |
   | **素材库** | 勾选一个或多个素材库。每个库显示片段数和已分析的数量 | 项目设置 |
   | **内容定位** | 题材与基调、画面偏好；没有录音时，也写配音的声线与语气 | `brief.md` |

   ![混剪项目的基础信息步骤，带素材库列表](/images/videoagents/project-types/mashup-basic.webp)

   列表里只显示已完成镜头分割、并且有片段的素材库。如果一个都没准备好，列表会提示你先准备一个。

4. **第 3/3 步 · 输出设置：** 画幅和输出语言。点 **创建**。

项目创建后，总制片会核对素材，汇报缺什么。在对话里回复可以开工。如果你没勾选素材库，也没有在消息里点名，它会问你用哪个；它从不替你选。

## 素材怎样匹配 {#how-the-footage-is-matched}

- **一句话一拍。** 文稿按句拆分，每句一拍（1–20 秒），边界按旁白的逐词时间测定。
- **每一拍有一个重点和一种模式。** 分镜设计师找出这句话的重点（往往是情绪，而不是语法上的宾语），并在两种模式中选一种：
  - **`literal`（一致）：** 画面就是说的内容。说到某个产品，就看到这个产品。通常是一个较长的镜头。
  - **`render`（相辅相成）：** 没有东西能直接拍出来时，由画面承载情绪，常用 2–6 个 0.8–2.5 秒的快切镜头。节奏就是从这里来的。
- **切点落在词上。** 换镜头的时刻对准那个词说出的瞬间，素材里的动作也和这个词对齐。
- **镜头只来自你的素材库。** 素材侦察员搜索素材库的画面信息和字幕；选片师看缩略图和联系图检查候选，并定下精确的起止。不会从网上搜索或下载任何东西。
- **片段从原始源视频切出**，而不是从素材库的片段文件里切，所以画面只转码一次。
- **兜底手段都在素材库内：** 放宽匹配，延长同一源视频里相邻的镜头，最后才用一帧静止画面加缓慢平移或推拉。
- **默认硬切。** 只有相邻两组用了同一个片段，或者连续两张静止画面之间，才加 0.3 秒的叠化。总时长始终不变。

## 工作流和签字 {#workflow-and-sign-offs}

| 阶段 | 做什么 | 你的签字 |
| --- | --- | --- |
| 剧情理解、mx0 音频立项与分镜 | 从文稿得出故事结构；测量音频，把每拍对齐到词上，逐拍设计镜头 | **MH1** 时间轴与分镜，包括节奏设计、使用的素材库，以及确认素材版权由你负责 |
| mx1 素材检索与选片 | 在素材库里找出候选，再看图检查并挑选 | **MH2** 选片 |
| mx2 切片 | 每一组从源视频切出，并行进行 | — |
| mx3 剪辑封装 | 剪辑、少量叠化、原样铺上你的音频、字幕、封面 | — |
| mx4 终审 | 混剪终审（时间、节奏、重复使用、素材来源清单），外加画面、内容安全和版权审核 | **MH3** 成片，附素材来源说明 |

这些 Agent 在左栏的 **混剪** 分组里：音频摄入员、文稿对齐员、分镜设计师、素材侦察员、选片师和切片师，外加混剪终审官。

## 在分镜预览里调整剪辑 {#adjust-the-edit-in-storyboard-preview}

打开 **🎦 分镜预览** 查看方案。每个场次块是同一主题下的一组拍子，每组显示选片师挑中的画面，切片后还显示片段本身。

| 你想要 | 这样做 | 会重做什么 |
| --- | --- | --- |
| 改某组要表现的内容 | 在该组的 **📝 注释** 里写 | 这一组的检索 |
| 换一个画面、改起止范围或节奏 | 点 **✏️ 修改**，描述要改什么 | 只重做受影响的组；时间轴不变，不用重签 MH1 |
| 改每拍的起止位置 | 告诉总制片 | 重新对齐各拍，时间轴要重新签字 |

## 几点说明 {#good-to-know}
- **没有生成费用。** 画面来自你自己的素材，切片在你的电脑上进行。只有 Agent 引擎，以及没有录音时的 TTS 配音要花钱。
- **版权由你担保。** 用到的每个片段都连同来源、标题、上传者和许可记录在 `mashup/sources.json` 里，版权审核只做报告。你在 MH1 确认版权，MH3 会再次列出来源。
- **重复使用很正常。** 素材库里的片段比文稿的组数少时，片段会被重复使用，但同一段画面不会用两次，相邻的组也不会用几乎一样的素材。
- **素材库决定质量。** 把每个片段都分析一遍，并让素材库的题材和文稿对上：讲产品发布会的文稿需要发布会素材。如果文稿里的某个画面在所有素材库里都没有，Agent 会改用兜底手段或者报告出来，而不是硬配一个不合适的。
- **不要移动素材库的源视频。** 切片读的是原始文件；如果它被移动或删除，就在素材库里重新导入。
- **一份文稿，一个项目。** 每个项目只做一条视频（`ep01`）。背景音乐、音效、片头片尾、调色匹配和变速都不在这个工作流里。
