# 项目技能

技能是 Agent 针对某类任务可以遵循的额外说明，例如为某个视频模型写提示词，或者指导表演。**项目技能** 决定 Agent 在这个项目里自行套用其中哪些，并记录每一次套用。

## 打开项目技能 {#open-project-skills}

打开 **🎛️ → 项目技能**。列表按 Agent 分组显示所有已安装的技能，每个技能附一行说明；只在特定情况下使用的技能，还会写明使用条件。

![项目技能对话框：Prompt 工程师的提示词技能，sd25-pe 和 performance-direction 已勾选](/images/videoagents/console/project-skills.webp)

## 选择技能 {#choose-skills}

1. 勾选你希望 Agent 在这个项目里套用的技能，取消勾选不需要的。在 **搜索 Agent 或技能** 里输入关键词，可以按 Agent、技能名或说明筛选。
2. 看一下底部的计数，例如 **已选 2 / 18 项**。
3. 点 **保存**。只保存你改动过的勾选项。

勾选的技能，在适合当前任务时会被对应的 Agent 读取，Agent 会记录它用了这个技能，或者为什么没用。

### 默认开启哪些 {#what-is-on-by-default}

只有和项目视频模型匹配的提示词技能默认勾选。其他所有技能，包括表演指导，默认都是关闭的，需要你手动开启。你自己的改动会保留；你没动过的提示词技能继续跟随[模型限制](/zh/videoagents/console/model-limits)里的视频模型设置。

### 标签 {#labels}

| 标签 | 含义 |
| --- | --- |
| **已被全局禁用** | 这个技能在整个应用里被关闭了，这里无法勾选 |
| **未安装** | 这个技能在本项目里是勾选的，但它的 `SKILL.md` 不见了（被删除，或在升级中丢失）。Agent 会当作没有勾选。取消勾选并保存，就能把它从项目里移除。 |

这项设置只对当前项目生效，保存在项目的 `settings.json` 里。

## 执行记录 {#execution-records}

点 **执行记录**，查看勾选的技能在这个项目里每一次的使用情况。

![技能执行记录：Agent、技能和版本、开始和结束时间、集数和分镜组、执行状态；触发原因已隐藏](/images/videoagents/console/project-skills-records.webp)

| 列 | 显示内容 |
| --- | --- |
| **Agent** | 使用这个技能的 Agent |
| **技能 / 版本** | 技能名称和版本号的前几位。版本号是运行开始时技能文件的 SHA-256 哈希值，可以据此看出技能文件什么时候改过。 |
| **运行时间** | 开始和结束的时间 |
| **集数 / 分镜组** | 用于哪一集、哪个分镜组（项目级任务为空） |
| **触发原因** | 用 Agent 自己的话说明为什么套用这个技能，例如这个组里有对白 |
| **执行状态** | **待执行**、**执行中**、**已完成**、**已跳过**、**失败** 或 **未验证** |

几点说明：

- 状态来自 Agent 自己的报告。没有正常报告的运行显示 **未验证**；读取了技能文件或运行结束，都不算完成了这个技能。
- 每次新的运行都会为它可能用到的勾选技能建立待执行记录。有执行记录这个功能之前的运行，不会补记。
- 列表一次显示 50 条，点 **加载更多** 查看更早的记录。第一页每隔几秒刷新一次，点 **刷新** 可以立即更新。
- 记录保存在项目的 `runs/skill_records/` 文件夹里，重启后仍在。记录里不包含提示词或产出内容。
- 点 **返回项目技能** 回到列表，尚未保存的勾选不会丢失。
