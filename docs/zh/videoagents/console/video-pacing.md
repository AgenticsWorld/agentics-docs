# 视频节奏

**视频节奏** 控制影视剧项目的节奏：每集和整季的节拍结构，每集和每个镜头有多长，镜头是否串成长镜头，以及场景之间、集与集之间怎么衔接。

这些值在[新建项目向导](/zh/videoagents/console/new-project-wizard)的第 3 步设定。之后可以随时在 **🎛️ → 视频节奏** 里修改，然后点 **确定**。修改对保存之后派发的任务生效，只作用于当前项目。

![视频节奏对话框：单集节奏选了「传统三幕」](/images/videoagents/console/video-pacing.webp)

## 叙事节奏 {#narrative-rhythm}

两个下拉菜单给剧情团队一套可以遵循的节拍结构。选中一项会显示它的节拍、要点和适用题材。选 **自定义** 可以自己写节拍链，例如 `A → B → C`。**不指定** 表示交给 Agent 自己决定。叙事节奏和[创作定调](/zh/videoagents/console/creative-brief)一起保存在项目的 `brief.md` 里。

**单集节奏** 决定每一集的结构：

| 节奏 | 节拍 | 适用 |
| --- | --- | --- |
| **传统三幕** | 铺垫 → 高潮 → 钩子 | 常规剧情片、正剧、小说改编 |
| **短剧倒置** | 冲突 → 好奇 → 补背景 → 更大冲突 | 竖屏微短剧、网文改编 |
| **持续升级** | 小危机 → 小高潮 → 更大危机 → …… → 总爆发 | 悬疑、惊悚、追逐、灾难类 |
| **起承转合** | 起 → 承 → 转 → 合 | 日常、治愈、文艺故事 |
| **憋屈—爽点** | 压抑 → 小爽 → 更憋屈 → 大爽 | 逆袭、复仇、翻盘故事 |
| **黄金三秒** | 3 秒钩子 → 15 秒内冲突或反转 → 中段推进 → 末 10 秒卡点 | 1 分钟以内的竖屏单集、预告 |
| **谜题揭示** | 抛谜 → 线索 → 误导 → 揭示 → 新谜 | 推理、悬疑、解谜故事 |
| **慢热积累** | 低强度日常 → 细节铺陈 → 单点情绪爆发 → 余韵 | 纪录片、情感、家庭、年代剧 |
| **双线交叉** | A 线铺垫 → B 线冲突 → A 线升级 → 两线汇合 | 双主角、多时空并行 |
| **循环环形** | 开场画面 → 变化 → 回到开场画面 | 寓言、诗意短片、单集微电影 |
| **反高潮** | 正常铺垫 → 预期的高潮被抽走 → 留白 | 文艺片、黑色幽默、荒诞短片 |
| **喜剧包袱** | 建立情境 → 强化预期 → 意外转折 → 笑点释放 → 回扣 | 喜剧、情景剧、轻松向短剧 |

**跨集节奏** 决定整季的结构：

| 节奏 | 节拍 | 适用 |
| --- | --- | --- |
| **单元剧** | 每集自成闭环 | 单元故事集、短片集 |
| **连续剧** | 每集末尾留钩子；主线贯穿到底 | 连续剧情、长篇连载 |
| **窗口—发展—收束** | 前段高密度留人 → 中段拉长副线 → 末段集中回收 | 80–100 集微短剧 |
| **季中双峰** | 铺垫 → 季中大高潮 → 放缓 → 季末大高潮 | 8–12 集的剧集 |
| **单元+主线** | 每集一个独立小案；主线每 3–5 集推进一次 | 侦探、职业剧、冒险 |

## 时长 {#length}

| 字段 | 作用 | 范围 | 新项目 |
| --- | --- | --- | --- |
| **每集时长(秒)** | 每集的目标时长。分集规划、节奏和剪辑都以它为准。 | 大于 0 | 300 |
| **根据剧本自动** | 不设固定时长：分集和每集时长按剧本结构决定 | 开 / 关 | 关 |
| **可加长单集** | 一集的内容需要的时间超过每集时长时，这一集最多可以加长这个比例。仍然装不下，就先精简台词，再合并动作短镜。0 = 不允许加长。 | 0–200% | 50% |
| **分镜时长(秒)** | 镜头的最短和最长时长 | 下限大于 0，上限 ≥ 下限 | 0.5–15 |

这些默认值出现之前创建的项目，在你修改之前显示每集 600 秒、镜头 1–10 秒。

## 长镜头 {#long-take}

| 字段 | 作用 |
| --- | --- |
| **长镜头** | 开启：每个视频组都接着上一组往下续，不管是切镜还是连续动作。关闭（默认）：只靠提示词的文字承接连续性。 |
| **连接方式** | **尾帧图片**：下一组把上一组最后一帧的截图作为参考。**尾段视频**：下一组接着上一组视频的最后 2–3 秒往后续写；模型不支持或素材不满足条件时，退回用尾帧。 |

::: warning 注意
用低分辨率的帧或视频尾段反复续接，可能会降低画质和人物一致性。项目的草稿分辨率为 480p 或更低时，对话框会提醒你。
:::

见[长镜头和连续性](/zh/videoagents/create/long-takes)。

## 过场 {#transitions}

**过场模式** 决定每次换场景、跳时间或进出闪回时怎么处理。过场设计 Agent 按这个模式给每个边界提出过场建议；你在分镜预览页逐处预览、接受或修改，出成片时落地。

| 模式 | 作用 |
| --- | --- |
| **极简** | 硬切。只有导演转场清单里点名的边界才做叠化，或黑场、白场。不出字卡，也不出定场空镜。 |
| **经典** | 换场景：2.5 秒定场空镜（如果首镜已经是远景，改为叠地点字幕）。跳时间：2.5 秒时间字卡。进闪回或梦境：白场、定格，并叠上「N 日前·地点」字幕；出闪回：匹配剪辑。同场景：硬切。每集以淡入开场。过场最多占一集时长的 8%。 |
| **电影感** | 和经典类似，但换场景时用定场空镜加地点字幕，跳时间时用时间字卡加定场空镜，闪回时提供生成式桥接作为候选。过场最多占一集时长的 10%；新场景的第一个镜头必须是定场镜头。 |
| **自定义** | 由你为每类边界选择处理方式，并设定下面几项。 |

新项目默认 **经典**。过场模式出现之前创建的项目用 **极简**。

选 **自定义** 时有以下字段：

| 字段 | 作用 | 默认 |
| --- | --- | --- |
| **边界处理** | 为 **换场景**、**跳时间**、**进闪回/梦境**、**出闪回/梦境**、**同场景同时段** 和 **集首** 各选一种处理：沿导演清单、硬切、叠化、黑场、白场、时间字卡、地点字幕叠加、定场空镜、定场+叠字、时光流转、生成式桥接、成对运镜、声先入（J-cut）或声延续（L-cut） | 依次为定场空镜、时间字卡、白场、沿导演清单、硬切、沿导演清单 |
| **说明性字卡** | **禁止** = 整集不出时间、地点或章节文字，过场只用画面手段 | 允许 |
| **过场时长预算** | 插入的过场最多占一集时长的比例。每段插入最长 4 秒，每个边界最长 6 秒。 | 8%（0–30%） |
| **生成式过场** | 允许生成式桥接和图生视频定场镜头 | 关 |
| **新场景首镜** | 必须是定场镜头 | 关 |

::: warning 注意
生成式过场会调用视频模型，按次计费。开启后，每张过场卡在你点击之前会显示预估成本。
:::

## 集尾收束和声桥 {#episode-close-and-sound-bridges}

| 字段 | 作用 | 范围 | 默认 |
| --- | --- | --- | --- |
| **集尾收束** | 每集怎么结束：**淡出到黑**、**淡出到白**、**切黑(突然黑屏)**、**切白** 或 **不处理(停在末帧)**。片尾接在后面。 | — | 淡出到黑 |
| **淡出** | 淡出的时长 | 0.3–3 秒 | 1.0 秒 |
| **停留** | 黑屏或白屏停留多久。切黑或切白时必须大于 0。 | 0–3 秒 | 0.5 秒（切黑、切白为 1.0 秒） |
| **声音** | **随画面淡出** 或 **到黑即静音** | — | 随画面淡出（切黑、切白为静音） |
| **声桥默认** | 在组与组的边界上，声音比切点提前多久进入（J-cut），或延续到切点之后多久（L-cut）。**底床** 只延续环境声；**画外台词** 让切点旁的画外台词跨过切点，需要开启声画分离。极简模式下不显示。 | 0.1–1.5 秒 | 0.5 秒，底床 |

单独某一集可以覆盖集尾收束，每个边界也可以在分镜预览页的过场卡上修改。见[过场](/zh/videoagents/create/transitions)。
