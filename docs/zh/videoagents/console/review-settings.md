# 审核设置

**审核设置** 决定审核团队在每个签字点之前对项目查得多严，以及质量评委是否给每张工单打分。审核越严，发现的问题越多，但花的时间和 token 也越多，退回重做的工作也越多。

打开 **🎛️ → 审核设置**，设好数值后点 **保存**。设置只对当前项目生效，作用于保存之后派发的任务。

![审核设置对话框：质量评委和八个审核维度各有一个滑块和数字，全部为 0](/images/videoagents/console/review-settings.webp)

## 质量评委 {#quality-judge}

**质量评委** 是评估 Agent 给每张工单打分时用的合格分。得分低于它的工作，必须按评委的意见返工。

| 数值 | 效果 |
| --- | --- |
| 0 | 跳过质量评委，完全不派评估工单。 |
| 1–100 | 合格分。越高，被退回的工作越多。 |

对话框的说明里写默认 60，但新项目从 0 开始。

## 审核维度 {#review-dimensions}

其余八个滑块各自设定一个审核 Agent 的力度，范围 0–100：

| 维度 | 审核 Agent 检查什么 |
| --- | --- |
| **音频质量审核** | 响度、削波、口型逐渐错位、角色嗓音变了 |
| **角色一致性审核** | 角色的脸、服装或嗓音在镜头之间发生变化 |
| **内容安全** | 过不了平台审核的内容，以及需要的分级 |
| **版权审核** | 字体、音乐等素材没有登记授权来源 |
| **逻辑审核** | 伏笔没回收、性格突然变化、旁白复述画面 |
| **时间线审核** | 事件顺序不可能成立、季节不对、角色不会变老 |
| **画面质量审核** | 典型的 AI 瑕疵：多手指、重影、闪烁、脸部模糊 |
| **世界观审核** | 画面和世界圣经矛盾 |

| 数值 | 效果 |
| --- | --- |
| 0 | 这个维度不审核（默认） |
| 1–99 | 数值越高越严格 |
| 100 | 最严格的审核 |

非 0 的力度只在每个签字点之前的闸门级审核中生效。迭代草稿期间不审核。

## 怎么设数值 {#choosing-values}

新项目的所有数值都是 0：没有质量评委，也不审核。这样出第一版最快、最省钱。按项目的重点开启审核，例如长篇剧集开 **角色一致性审核**，发布之前开 **内容安全** 和 **版权审核**。

不合格的工作自动重做几次，由 [Agent 高级设置](/zh/videoagents/console/agent-advanced-settings) 里的 **重跑次数** 决定（也可以用 `/retry` 设置）。设为 0 时，不合格的工作会交给你处理。

审核结果以缺陷单的形式保存在项目的 `qa/defects/` 文件夹里。见[审核与缺陷单](/zh/videoagents/create/qa-reviews)。
