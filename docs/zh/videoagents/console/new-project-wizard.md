# 新建项目向导

**新建项目** 向导一次完成项目的创建和初始设置：选类型，给它文本和文件，再定好最初的设置。点 **创建** 后，总制片开始准备项目。

## 打开向导 {#open-the-wizard}

点顶栏的项目名称，再点 **＋ 新建项目…**。

## 第 1 步：项目类型 {#step-1-project-type}

选择你要做什么。类型卡片下方的说明框会写明这个类型做什么、需要你提供什么。

![向导第 1 步：已选中影视剧卡片，「更多」里的类型已展开](/images/videoagents/console/new-project-wizard-type.webp)

| 类型 | 产出 | 你需要提供 | 步数 |
| --- | --- | --- | --- |
| **🎬 影视剧** | 由小说改编的多集视频，过程中在关键节点停下来等你签字 | 小说原文（可以之后再放） | 5 |
| **🧑‍💼 数字人** | 用照片和一段录音生成口型同步的数字人视频 | 音频，以及每个说话人一张照片 | 3 |
| **🖥️ 动效短片** | 写成网页的一段动画短片，逐帧渲染，不用视频模型 | 主题或文稿，以及一种风格 | 4 |
| **🎙️ 音频配画**（在 **⋯ 更多** 里） | 给讲述录音配上 AI 画面，录音原样作为声轨 | 讲述音频和对应文稿 | 4 |
| **✂️ 混剪**（在 **⋯ 更多** 里） | 从你自己的素材库里剪出视频，按文稿逐句配画面 | 文稿和一个准备好的素材库 | 3 |

步数随类型变化。每种类型的详细说明见[选择项目类型](/zh/videoagents/project-types/choose-a-project-type)。

## 第 2 步：基础信息 {#step-2-basic-info}

![影视剧项目的向导第 2 步：项目名称、故事文本、内容定位和画面风格](/images/videoagents/console/new-project-wizard-basic.webp)

| 字段 | 适用类型 | 填什么 |
| --- | --- | --- |
| **项目名称** | 全部 | 只能用英文字母和数字，例如 `MyNovel01`。它会成为项目文件夹的名称。 |
| **故事文本** / **文稿** / **主题 / 文稿** | 全部 | 影视剧：粘贴小说原文，或者留空，之后把文本放进项目的 `novel/` 文件夹。音频配画：和讲述音频逐字对应的文稿。混剪：旁白文稿。动效短片：这部短片讲什么。数字人：可选的文稿，带时间和说话人（没有文稿时会自动转写音频）。 |
| **内容定位** | 全部 | 题材与基调、受众、改编时保留或舍弃什么。数字人项目里这个字段是 **人物对应说明**：写明哪张照片对应哪个说话人。 |
| **画面风格** | 影视剧、音频配画 | 风格提示词。点 **🎨 选择风格库** 可以从预设开始。见[创作定调](/zh/videoagents/console/creative-brief)。 |
| **讲述音频** / **音频母带** | 音频配画、混剪、数字人 | 录音文件（`.mp3`、`.wav`、`.flac`、`.m4a`、`.aac`、`.ogg`）。混剪可以不填：没有录音时，会按文稿合成配音。 |
| **声音来源** | 数字人 | **原始录音** 或 **克隆声音**。选克隆声音时，给每个说话人上传一段 5–30 秒的声音样本，台词稿按 `说话人: 台词` 的格式写；所用的 TTS 服务商必须支持声音克隆。 |
| **人物照片** | 数字人 | 每个说话人一张照片 |
| **素材库** | 混剪 | 勾选一个或多个准备好的素材库。先在 **⚙️ → 高级 → 素材库** 里准备好。 |
| **素材(可选)** | 动效短片 | logo、照片、字体、录音、音乐 |

每个文件最大 100 MB。项目创建后，文件会上传到项目的参考文件里：录音进 **讲述音频**，声音样本进 **克隆声音**，人物照片进 **角色**，动效短片的素材按文件类型分类（图片进 **其他**，字体进 **字体**，音频进 **音频**，视频进 **视频**）。这一步没上传的文件，之后可以在 **参考文件** 页补上。

## 第 3 步（影视剧）：视频节奏 {#step-3-film-series-video-rhythm}

叙事节奏、每集和每个镜头的时长、长镜头和过场。这些字段和 **🎛️ → 视频节奏** 里的完全相同，见[视频节奏](/zh/videoagents/console/video-pacing)。新项目默认每集 300 秒，镜头 0.5–15 秒，过场模式为 **经典**。

## 第 3 步（动效短片）：风格 {#step-3-motion-graphics-style}

从风格里选一种。**完整风格** 带有完整的风格规范和一部样片；**轻量风格 · OPUSCAR 98** 只是一段风格提示词，其余由导演补全。风格决定画面质感、字体、运动和声音；故事和镜头按你的主题来。选定风格还会设定最后一步里的帧率。见[动效短片](/zh/videoagents/project-types/motion-graphics)。

## 第 4 步（影视剧、音频配画）：模型限制 {#step-4-film-series-audio-to-video-model-limits}

一个视频生成组最长多少秒，最多能用几张参考图、几段参考视频和几段参考音频。向导会选中和 **生成模型** 页当前生效视频模型相匹配的预设，你的选择和它不一致时会提醒你。见[模型限制](/zh/videoagents/console/model-limits)。

![向导第 4 步：已选中 Seedance 2.5 预设](/images/videoagents/console/new-project-wizard-model.webp)

对影视剧项目，只有选中 **Seedance 2.5** 预设时，下一步里的 **白模** 才默认开启；选其他预设会把它关闭。你可以在下一步里再改。

## 最后一步：输出设置 {#last-step-output-settings}

画幅、输出语言和分辨率，以及影视剧专用的开关（白模、背景图、NPC 参与构图、旁白、对白配音、声画分离）。这些字段和 **🎛️ → 输出设置** 里的完全相同，见[输出设置](/zh/videoagents/console/output-settings)。

![向导最后一步：输出画幅、语言、分辨率和影视剧开关](/images/videoagents/console/new-project-wizard-output.webp)

新项目的默认值：16:9，输出语言跟随界面语言，草稿 480p，成片 1080p，旁白关闭。

动效短片项目这一步换成 **目标片长(秒)**（5–600，默认 45；30–60 秒效果最好）、**帧率**（24、25、30 或 60 fps）、**旁白**、**字幕**、**先审故事板**（默认都开启）和 **配乐**（默认代码作曲，也可以用音乐模型生成，或从项目音乐库选曲）。

## 创建项目 {#create-the-project}

在最后一步点 **创建**。在 **基础信息** 和最后一步之间的各步，也可以点 **跳过向导创建**：剩下的步骤保持当前值（没改过就是默认值），立即创建项目。

项目创建时：

1. 上传你的文件（按钮显示 **上传中 1/3…**）。
2. 控制台切换到新项目，并打开 **总制片**。
3. 总制片开始准备项目。影视剧项目：它建好文件夹，清洗小说文本并分章，然后提醒你到 **参考文件** 页添加参考图。其他类型：它核对你提供的素材，汇报缺少什么，你回复后开工。

你的内容定位、画面风格和叙事节奏会作为最高创作前提交给每个 Agent。

## 之后可以修改的默认值 {#defaults-you-can-change-later}

向导里设的所有内容，之后都能在 **🎛️** 菜单里修改。另有几项不在向导里，创建时直接取默认值：

- **审核设置** 不在向导里。新项目的每项审核都是 0（不审核，也没有质量评委）。见[审核设置](/zh/videoagents/console/review-settings)。
- 片头、片尾和下集预告默认关闭，在 **后期处理** 页打开。
- 发布渠道之后在 **成片发布** 页选择。

## 常见问题 {#troubleshooting}

**「项目名称只能使用英文字母和数字」。** 把名称里的空格、短横线和其他字符去掉。

**「项目已创建,以下文件上传失败,请到「参考文件」页补传」。** 项目已经建好；到 **参考文件** 页补传列出的文件。

**「请选择一种风格」。** 动效短片需要在第 3 步选一种风格。
