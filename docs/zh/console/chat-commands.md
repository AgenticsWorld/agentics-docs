# 聊天命令

在控制台的对话框里，或在飞书、微信、WhatsApp 里，发一条以 `/` 开头的命令，就能清理会话、开关自动运行、停止任务或修改重跑次数，不用打开设置菜单。

命令由系统直接处理：不会派单给 Agent，也不消耗引擎额度。所以引擎额度用完或 Agent 卡住时，命令照样能用。

## 命令一览

| 命令 | 作用 | 作用范围 | 对应的界面操作 |
| --- | --- | --- | --- |
| `/clear` | 清理当前 Agent 的会话记录，下一条消息开启全新会话 | 当前 Agent、当前项目 | 无 |
| `/auto` | 查看当前项目的自动运行状态 | 当前项目 | 运行面板 **🤖** 按钮 |
| `/auto on`、`/auto off` | 开启、关闭当前项目的自动运行 | 当前项目 | 运行面板 **🤖** 按钮 |
| `/auto off all` | 关闭所有项目的自动运行 | 全部项目 | 无 |
| `/stop` | 查看正在运行和排队中的任务数 | 全部项目 | 无 |
| `/stop all` | 停止所有正在运行和排队中的任务 | 全部项目 | 运行面板 **⏹ 停止** |
| `/retry` | 查看当前重跑次数 | 全局 | **⚙️ → 高级 → Agent 高级设置 → 重跑次数** |
| `/retry N` | 把重跑次数设为 N（0–10） | 全局 | 同上 |

- `/auto`、`/stop`、`/retry` 不区分大小写，`/AUTO ON` 也可以。`/clear` 必须原样发送，后面不能带其他文字。
- 参数写错时（例如 `/auto yes`、`/retry abc`），系统回复「无法识别的命令」并附上用法，设置不会改动。
- 其他以 `/` 开头的文字不是系统命令，会作为普通消息发给 Agent。

## 在控制台里使用

1. 在左栏选一个 Agent。命令在任何 Agent 的对话框里都能用，包括修改师。
2. 在输入框里输入命令，按 Enter 或点 **发送**。
3. 命令和系统的回复都会出现在这个 Agent 的对话记录里。

几点说明：

- **当前项目**是顶栏选中的项目。`/auto on` 等命令作用于这个项目。
- 用 Ctrl+Enter（插话）发命令，效果和 Enter 一样，命令不会插进正在运行的任务里。
- 在 **总制片** 的对话框里发命令，系统的回复也会推送到已绑定的手机消息通道；在其他 Agent 的对话框里发，回复只留在控制台。

## 在飞书里使用

### 准备工作

1. 在[飞书开放平台](https://open.feishu.cn/app)创建应用，并开启机器人能力。
2. 在应用的事件与回调设置中：
   - 事件订阅选「长连接」方式，订阅 **接收消息**（`im.message.receive_v1`）。
   - 回调订阅也选「长连接」方式。确认和签字卡片上的按钮靠它回传。
3. 在权限管理中开通 `im:message`。如果还想收到图片和视频推送，再开通 `im:resource`。
4. 在控制台打开 **⚙️ → 高级 → 手机消息**，在 **✈️ 飞书** 一栏填入 App ID 和 App Secret，选择平台（飞书或 Lark），点 **校验并绑定**。服务端需要装有飞书 SDK：`pip install lark-oapi`。
5. 在飞书里搜索应用名，给机器人随便发一句话。系统收到这条消息后，才知道该把回复推给谁。

### 发送命令

在和机器人的单聊里直接发命令，例如 `/retry 1` 或 `/stop all`。

- 只有单聊里的文字消息会转发。群聊、图片和富文本不会转发。
- 飞书里的消息都发给 **总制片**，项目是控制台顶栏当前选中的项目（没有选中时取第一个项目）。所以在飞书里发 `/clear`，清理的是总制片在这个项目里的会话；发 `/auto on`，开启的是这个项目的自动运行。要换项目，先在控制台顶栏切换。
- 系统的回复会推回飞书，开头标注「🎬 总制片 · 项目名」。单条消息超过 3000 字会被截断，全文在控制台里看。
- 你在飞书里发的命令和收到的回复，也会出现在控制台总制片的对话里，标注「✈️ 来自飞书」。

### 飞书里的其他功能

- **确认和签字卡片**：Agent 发起的确认（例如「重跑还是跳过」）和人工签字会以卡片推到飞书，点卡片上的按钮即可答复，和控制台弹窗是同一份答案。确认卡片高亮的按钮是默认项，倒计时结束仍没人选择时按默认项处理；签字卡片不会超时。答复之后卡片会变成已处理状态，不能再点。
- **素材推送**：新完成的人物、场景、道具主图和分镜组视频会自动推到飞书。超过大小上限（默认 5 MB，可在手机消息页改为 1–30 MB）的文件不推送，只发一条文字提示。
- **系统通知**：设置变更、自动运行唤醒等系统消息也会推送到飞书。

### 微信和 WhatsApp

在 **⚙️ → 高级 → 手机消息** 绑定微信 ClawBot 或 WhatsApp 后，命令的用法和飞书相同：消息发给总制片，作用于控制台顶栏当前选中的项目。WhatsApp 只认「给自己发消息」对话里的文字；微信绑定后也要先发一条消息，系统才能向你推送。

## 各命令详解

### `/clear` 清理会话

清掉当前 Agent 在当前项目里所有引擎的会话记录，下一条消息会开启全新会话。

- 适用场景：会话太长，续接时请求过大被网络断开；或者想丢掉过时的上下文，让 Agent 从头读项目文件。
- 只是不再续接旧会话。引擎那边的历史会话文件不会被删除，控制台的对话记录也会保留。
- 如果这个 Agent 还有正在运行或排队的任务，任务结束时会重新记下它用的会话。回复会提醒你：等任务结束后再发一次 `/clear`。

### `/auto` 自动运行

自动运行开启后，系统每隔一段闲置时间检查一次项目：如果工作流里还有能做的任务，同时没有任务在跑、也没有等你答复的确认，就唤醒总制片继续派单。如果只剩人工签字，系统改为在本机发通知提醒你。

- `/auto`：显示当前项目的开关状态，以及闲置时间（默认 5 分钟）和用量阈值（默认 80%）。总制片所用引擎的会话用量达到阈值时，这一轮不唤醒。这两项在 **⚙️ → 自动运行** 里修改。
- `/auto on`、`/auto off`：开启或关闭当前项目的自动运行。
- `/auto off all`：一次关闭所有项目的自动运行。没有 `/auto on all`。
- 每个项目单独开关，默认关闭，服务重启后保持。
- 和运行面板的 **🤖** 按钮是同一个开关。用命令改了之后，网页上的按钮会立即同步。

### `/stop` 停止任务

- `/stop`：显示所有项目里正在运行和排队中的任务数。
- `/stop all`：停止所有项目里正在运行和排队中的任务，和运行面板的 **⏹ 停止** 按钮相同。回复会列出被停止的 Agent 和它们所属的项目。被停止的任务记为「用户手动停止」，不算出错。
- 停止只针对已有的任务。如果当前项目开着自动运行，闲置一段时间后系统还会再派单，回复会提醒你。要彻底停下来，再发 `/auto off`（或 `/auto off all`）。
- 目前没有只停一个项目或一个 Agent 的命令写法。

### `/retry` 重跑次数

重跑次数是 Agent 自动重做的上限，包括：验收、评分不过时带意见退回重做；生成的图片、视频机检不达标时自动重新生成；Agent 自检不过时重新出图。

- `/retry`：显示当前的重跑次数。
- `/retry N`：设为 N，范围 0–10，默认是 0。
- 设为 0 表示不自动重跑：第一次不过就交给你决定，Agent 不会自己重做。这时「重跑还是跳过」这类确认在倒计时结束、无人答复时默认选「跳过」，不会因为没人回复而一直重跑。
- 这是全局设置，对所有项目生效，和 **⚙️ → 高级 → Agent 高级设置 → 重跑次数** 是同一个设置。
- 新的次数只对之后启动的任务生效。修改时如果还有任务在运行或排队，它们仍按原来的次数执行，回复会提醒你。

::: tip
`/retry` 从 v1.0.44 起可用。
:::

## 回复的语言

`/stop` 和 `/retry` 的回复跟随控制台的界面语言：中文界面回中文，其他语言回英文。`/clear` 和 `/auto` 的回复目前只有中文。

## 常见问题

**在飞书里发了命令，没有收到回复。**
打开 **⚙️ → 高级 → 手机消息**，查看飞书一栏的「互通状态」和「最近错误」。如果提示还在等首条消息，先在飞书里给机器人发一句话。电脑上的服务要保持运行。

**命令作用到了别的项目。**
飞书、微信和 WhatsApp 里的命令作用于控制台顶栏当前选中的项目。先在顶栏切换到要操作的项目，再发命令。

**发了 `/stop all`，过一会儿又开始跑了。**
当前项目开着自动运行。发 `/auto off` 关掉它。
